# 소리 맞추기 가이드

동물 소리 게임의 **소리 맞추기**를 하는 방법을 안내합니다.
동물 소리 **3개가 거의 동시에 겹쳐** 들립니다. 섞인 소리 속에서 어떤 동물들이 있었는지 12마리 중에서 골라 냅니다.

> 들어가는 곳: **다른 소리** 탭 → **동물 소리 게임** → **소리 맞추기** 카드
> 나가는 곳: 오른쪽 아래 **← 나가기** (게임 목록으로), 또는 휴대폰 뒤로가기

```
   🎮 게임시작
        │  동물 소리 3개가 0.2초 간격으로 겹쳐 들림
        ▼
   「게임 시작! 등장한 동물 세 마리를 골라 주세요!」 → 시작하기
        │
        ▼
   12마리 카드 중에서 들린 동물 누르기
        │  맞히면 초록 카드로 잠김 · 틀리면 흔들리고 다시 누를 수 있음
        ▼
   3마리를 다 찾으면 「축하합니다!」 → ⭐ 별 (실수 없으면 ✔ 클리어)
        │  확인
        └──────────▶ 다시 🎮 게임시작
```

---

## 1. 화면 구성

### 시작 전

```
┌───────────────────────────────┐
│                          (❔)  │  ← 미션 아이콘
│        (배경 사진)              │
│                               │
│     ┌───────────────────┐     │
│     │ 🎮  게임시작        │     │
│     └───────────────────┘     │
│                               │
│                    [← 나가기]  │
└───────────────────────────────┘
```

**게임시작**을 누르면 물결 그림과 함께 「소리를 재생하고 있습니다...」가 나오고 소리가 들립니다.

### 게임 중

```
┌───────────────────────────────┐
│                          (❔)  │
│  ┌────┐ ┌────┐ ┌────┐         │
│  │🐱  │ │🐔  │ │🐮  │         │  ← 동물 카드 12장
│  │고양이│ │ 닭 │ │ 소 │         │     (그림 + 이름)
│  └────┘ └────┘ └────┘         │
│  ┌────┐ ┌────┐ ┌────┐         │
│  │🐶  │ │🦆  │ │🐘  │         │
│  │ 개 │ │오리 │ │코끼리│         │
│  └────┘ └────┘ └────┘         │
│            ⋮                  │
│                    [← 나가기]  │
└───────────────────────────────┘
```

카드 순서는 늘 같습니다. 고양이 · 닭 · 소 · 개 · 오리 · 코끼리 · 염소 · 말 · 사자 · 원숭이 · 돼지 · 늑대

---

## 2. 한 판의 흐름

1. **게임시작**을 누릅니다.
2. 12마리 중 **무작위 3마리**의 소리가 **0.2초 간격으로 거의 동시에** 시작됩니다. 소리가 서로 겹쳐 들리는 것이 정상입니다.
3. 소리가 다 나오고 잠시(0.5초) 뒤 카드판이 열리고 「**게임 시작!** 등장한 동물 세 마리를 골라 주세요! 🐾」 창이 뜹니다. **시작하기**를 누릅니다.
4. 들렸다고 생각하는 동물 카드를 누릅니다. 누른 카드는 약 **1.5초** 동안 움직이는 그림으로 바뀝니다.

| 누른 카드 | 일어나는 일 |
|---|---|
| **정답** (들린 동물) | 기뻐하는 움직임 뒤에 카드가 **초록색**으로 바뀌고 잠깁니다. 다시 누를 수 없습니다 |
| **오답** (안 들린 동물) | 카드가 **흔들리고 붉게** 바뀌었다가 원래대로 돌아옵니다. 다시 누를 수 있습니다 |

5. 들린 3마리를 **모두** 찾으면 잠시 뒤 「**축하합니다!** 모든 동물을 맞추셨어요! 🌟」가 뜹니다.
6. **확인**(또는 휴대폰 뒤로가기)을 누르면 별·클리어가 기록되고 다시 **게임시작** 화면으로 돌아갑니다.

- **틀려도 판이 끝나지 않습니다.** 3마리를 다 찾을 때까지 계속 고를 수 있습니다.
- 한 카드가 움직이는 동안에도 **다른 카드는 바로** 누를 수 있습니다.
- 소리를 **다시 듣는 버튼은 없습니다.** 한 번 듣고 기억해서 고릅니다.
- 판이 시작된 뒤 소리가 다 나오기 전에는 카드판이 열리지 않습니다. 소리 도중에 잘못 눌러 오답이 되는 일이 없습니다.

---

## 3. 별과 클리어

| 얻는 것 | 조건 |
|---|---|
| ⭐ **별** | 3마리를 모두 맞히고 축하 창에서 **확인** |
| ✔ **클리어** | 그 판에서 **오답을 한 번도 누르지 않고** 3마리를 모두 맞히기 |

- 미션 아이콘(❔)을 누르면 「**이번 판 실수 여부**」가 보입니다. 오답을 한 번이라도 누르면 「있음」이 되고, 그 판은 클리어가 될 수 없습니다.
- 「있음」이 되어도 끝까지 3마리를 찾으면 **별은** 얻습니다. 클리어는 다음 판에 다시 도전하세요.
- 새 판(게임시작)을 누르면 실수 여부는 「없음」으로 돌아갑니다.

별·미션 아이콘 색에 대한 자세한 설명은 [동물 소리 게임 가이드](동물%20소리%20게임%20가이드.md)를 보세요.

## 4. 내 동작이 기록에 어떻게 남나요?

| 게임에서 내가 한 일 | 기록에 남는 것 |
|---|---|
| 3마리를 모두 찾고 확인을 눌렀다 | 이 게임의 ⭐ 별 (이미 있으면 그대로) |
| 오답 없이 3마리를 모두 찾았다 | ⭐ 별 + ✔ 클리어 |
| 오답을 눌렀다 | 이번 판 「실수 있음」. 따로 점수나 통계는 남지 않습니다 |
| 판 도중에 **나가기**를 눌렀다 | 아무것도 남지 않습니다. 그 판은 버려집니다 |

- 이 게임은 판마다 점수나 정답률을 저장하지 않습니다. 「연습 기록」(📊) 화면에도 나오지 않습니다.
- 남는 것은 게임 목록 카드의 **⭐ · ✔ 배지**뿐입니다.

---

## 5. 잘 하는 요령

- 세 소리가 겹쳐 들리므로 **소리의 결**에 집중하세요. 높은 소리와 낮은 소리, 길게 끄는 소리와 짧게 끊기는 소리처럼 나눠서 들으면 구분하기 쉽습니다.
- 확실한 동물부터 누르세요. 맞힌 카드가 초록으로 잠기면 남은 후보가 줄어듭니다.
- 클리어를 노린다면 **헷갈리는 카드는 누르지 마세요.** 오답 한 번이면 그 판의 클리어는 끝납니다.
- [듣기 준비](../0_공통/듣기%20준비%20가이드.md)에서 볼륨을 맞추고 이어폰으로 하면 겹친 소리를 나눠 듣기 쉽습니다.

## 6. 자주 묻는 질문

**Q. 소리가 동시에 나서 하나도 모르겠어요.**
정상입니다. 이 게임은 일부러 소리를 겹쳐 냅니다. 한 마리씩 차례로 듣는 연습은 [소리 순서](소리%20순서%20가이드.md)나 [강화학습](강화학습%20가이드.md)이 더 쉽습니다.

**Q. 틀린 카드를 다시 누를 수 있나요?**
네. 오답 카드는 잠기지 않습니다. 다시 눌러도 또 오답일 뿐이고, 실수 여부는 이미 「있음」입니다.

**Q. 정답이 뭐였는지 알 수 있나요?**
3마리를 다 찾아야 판이 끝나므로, 끝까지 하면 초록 카드 3장이 정답입니다.

**Q. 「오류 발생 — 오디오 로드 중 문제가 생겼어요」가 떠요.**
**확인**을 누르고 다시 **게임시작**을 누르세요. 계속되면 앱을 다시 켜 보세요.
