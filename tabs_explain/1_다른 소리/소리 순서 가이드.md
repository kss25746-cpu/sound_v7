# 소리 순서 가이드

동물 소리 게임의 **소리 순서**를 하는 방법을 안내합니다.
동물 소리 **3개가 하나씩 차례로** 들립니다. 들린 **순서대로** 동물 그림을 끌어다 세 칸에 놓고 제출합니다.

> 들어가는 곳: **다른 소리** 탭 → **동물 소리 게임** → **소리 순서** 카드
> 나가는 곳: 오른쪽 아래 **← 나가기** (게임 목록으로), 또는 휴대폰 뒤로가기

```
   🎮 게임시작
        │  동물 소리 3개가 약 1.3초 간격으로 하나씩
        ▼
   「🎵 준비 완료! 소리를 듣고 순서를 맞춰보세요!」 → 시작하기
        │
        ▼
   동물 그림을 끌어서 1·2·3번 칸에 놓기 → 정답 제출
        │
        ├─ 틀림 → 「😅 아쉬워요!」 → 칸을 고쳐서 다시 제출
        │
        └─ 맞음 → 「🎉 축하합니다!」 → ⭐ 별 (첫 제출이면 ✔ 클리어)
                   └──────────▶ 다시 🎮 게임시작
```

---

## 1. 화면 구성

### 게임 중

```
┌───────────────────────────────┐
│                          (❔)  │  ← 미션 아이콘
│  🐱  🐔  🐮  🐶                │
│  🦆  🐘  🐐  🐴                │  ← ① 동물 그림 12장
│  🦁  🐵  🐷  🐺                │     (끌어서 옮기기)
│                               │
│  ┌──────┐┌──────┐┌──────┐     │
│  │놓는곳 ││놓는곳 ││놓는곳 │     │  ← ② 칸 3개
│  └──────┘└──────┘└──────┘     │     (왼쪽부터 1·2·3번째)
│                               │
│     ┌───────────────────┐     │
│     │ ✔  정답 제출        │     │  ← ③ 제출
│     └───────────────────┘     │
│                    [← 나가기]  │
└───────────────────────────────┘
```

- 동물 그림에는 **이름이 쓰여 있지 않습니다.** 그림을 보고 고릅니다.
- 그림 순서는 늘 같습니다. 고양이 · 닭 · 소 · 개 · 오리 · 코끼리 · 염소 · 말 · 사자 · 원숭이 · 돼지 · 늑대
- 칸은 **왼쪽이 첫 번째**로 들린 소리, **오른쪽이 마지막**으로 들린 소리입니다.

---

## 2. 한 판의 흐름

1. **게임시작**을 누릅니다. 물결 그림과 「소리를 재생하고 있습니다...」가 나옵니다.
2. 12마리 중 **무작위 3마리**의 소리가 **약 1.3초 간격으로 하나씩** 납니다.
3. 소리가 끝나고 잠시(0.5초) 뒤 「🎵 **준비 완료!** 소리를 듣고 순서를 맞춰보세요! 🔀」 창이 뜹니다. **시작하기**를 누릅니다.
4. 동물 그림을 손가락으로 **끌어서** 칸에 놓습니다.
5. 세 칸을 다 채우고 **정답 제출**을 누릅니다.

- 소리를 **다시 듣는 버튼은 없습니다.** 한 번 듣고 순서를 기억합니다.

### 그림 옮기는 법

| 하고 싶은 것 | 이렇게 하세요 |
|---|---|
| 칸에 놓기 | 위의 그림을 끌어서 빈 칸에 놓습니다. 칸 가장자리 근처에 놓아도 들어갑니다 |
| 칸에 있는 그림 바꾸기 | 다른 그림을 그 칸에 놓으면 **바뀝니다.** 앞에 있던 그림은 위로 돌아갑니다 |
| 두 칸의 그림 맞바꾸기 | 칸에 있는 그림을 **다른 칸으로** 끌어 놓습니다 |
| 칸에서 빼기 | 칸에 있는 그림을 **칸 밖으로** 끌어 놓습니다 |

- 칸에 놓인 동물은 위쪽 그림이 **흐리게** 바뀌고 끌 수 없습니다. 같은 동물을 두 칸에 놓을 수 없습니다.
- 칸에서 빼면 위쪽 그림이 다시 선명해집니다.

### 제출 결과

| 제출했을 때 | 나오는 창 | 다음 |
|---|---|---|
| 빈 칸이 있다 | ⚠️ **확인 필요** — 빈 공간을 모두 채워주세요. | 칸을 채우고 다시 제출. 시도 횟수에 세지 않습니다 |
| 순서가 틀렸다 | 😅 **아쉬워요!** — 다시 시도해보세요! | **다시 시도**를 누르면 놓은 그림이 그대로 있습니다. 고쳐서 다시 제출 |
| 순서가 맞았다 | 🎉 **축하합니다!** — 정답을 맞추셨어요! 정말 대단해요! 🌟 | **확인**을 누르면 다시 게임시작 화면으로 |

- 틀렸을 때 **어느 칸이 틀렸는지는 알려 주지 않습니다.** 세 칸이 모두 맞아야 정답입니다.
- 맞힐 때까지 몇 번이든 다시 제출할 수 있습니다.

---

## 3. 별과 클리어

| 얻는 것 | 조건 |
|---|---|
| ⭐ **별** | 순서를 맞히기 (몇 번째 제출이든) |
| ✔ **클리어** | **첫 번째 제출에서** 순서를 맞히기 |

- 미션 아이콘(❔)을 누르면 「**현재 시도 횟수**」가 보입니다. 정답 제출을 누를 때마다 1씩 늘어납니다. (빈 칸 때문에 막힌 제출은 세지 않습니다)
- 시도 횟수가 1회를 넘으면 그 판은 클리어가 될 수 없습니다. 끝까지 맞히면 **별은** 얻습니다.
- 새 판(게임시작)을 누르면 시도 횟수는 0회로 돌아갑니다.

별·미션 아이콘 색에 대한 자세한 설명은 [동물 소리 게임 가이드](동물%20소리%20게임%20가이드.md)를 보세요.

## 4. 내 동작이 기록에 어떻게 남나요?

| 게임에서 내가 한 일 | 기록에 남는 것 |
|---|---|
| 순서를 맞혔다 | 이 게임의 ⭐ 별 (이미 있으면 그대로) |
| 첫 제출에서 맞혔다 | ⭐ 별 + ✔ 클리어 |
| 틀리게 제출했다 | 시도 횟수 +1. 따로 점수나 통계는 남지 않습니다 |
| 판 도중에 **나가기**를 눌렀다 | 아무것도 남지 않습니다. 그 판은 버려집니다 |

- 이 게임은 판마다 점수나 정답률을 저장하지 않습니다. 「연습 기록」(📊) 화면에도 나오지 않습니다.
- 남는 것은 게임 목록 카드의 **⭐ · ✔ 배지**뿐입니다.

---

## 5. 잘 하는 요령

- 소리가 나는 동안 **마음속으로 이름을 차례로** 불러 두세요. 「개, 소, 말」처럼 말로 바꾸면 순서를 기억하기 쉽습니다.
- 처음 들린 동물과 마지막 동물이 가장 기억에 잘 남습니다. 양쪽 칸부터 채우고 가운데를 채우세요.
- 틀렸다면 한 칸씩만 바꿔 보기보다, **어느 두 동물의 순서가 헷갈렸는지** 떠올려 맞바꿔 보세요.
- 클리어를 노린다면 첫 제출 전에 세 칸을 한 번 더 확인하세요.

---

## 6. 자주 묻는 질문

**Q. 그림을 놓았는데 칸에 안 들어가요.**
칸 안이나 가장자리 가까이에 놓아야 합니다. 화면을 스크롤했다면 잠시 뒤 다시 끌어 보세요.

**Q. 어느 칸이 틀렸는지 알 수 있나요?**
아니요. 맞았는지 틀렸는지만 알려 줍니다.

**Q. 정답을 모르겠는데 넘어갈 수 있나요?**
판을 건너뛰는 버튼은 없습니다. **나가기**로 게임 목록에 갔다가 다시 들어오면 새 판을 시작할 수 있습니다.

**Q. 「⚠️ 음성 로드 실패」가 떠요.**
**확인**을 누르고 다시 **게임시작**을 눌러 보세요. 계속되면 앱을 다시 켜 보세요.
