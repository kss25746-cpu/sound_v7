# 소리 높낮이 가이드

「다른 소리」 탭의 **소리 높낮이**(화면 제목: 높낮이 비교)를 하는 방법을 안내합니다.
「삐—」 소리 두 개를 차례로 듣고, **두 번째 소리가 첫 번째보다 높은지 낮은지** 고르는 연습입니다.
한 판은 **12문항**이고, 12문항을 끝까지 풀면 기록이 남아 통계에서 변화를 볼 수 있습니다.

> 들어가는 곳: **다른 소리** 탭 → **소리 높낮이** 카드
> 나가는 곳: 첫 화면의 **뒤로 가기** 버튼, 또는 휴대폰 뒤로가기

```
   첫 화면에서 난이도 고르기 (쉬움 · 보통 · 어려움)
              │  시작
              ▼
   소리 A → (잠깐 쉼) → 소리 B
              │  B가 「더 낮아요」? 「더 높아요」?
              ▼
   맞았어요 / 아쉬워요 → 다음  ── 12번 반복
              │
              ▼
   결과 화면 (약 ○○% · ○/12) → 기기에 기록
              │
              ▼
   📊 통계 「높낮이 비교」에서 변화 보기
```

---

## 1. 첫 화면

```
┌───────────────────────────────┐
│                     🎧   📊    │  ← 듣기 준비 · 통계
│             (▮▮▮)              │
│           높낮이 비교           │
│  ┌───────┬───────┬───────┐    │
│  │ 쉬움  │ 보통  │ 어려움 │    │  ← ① 난이도 고르기
│  └───────┴───────┴───────┘    │     (처음에는 「보통」)
│        [ 12문항 · 보통 ]        │  ← ② 이번 판 정보
│  난이도를 고르고 시작하면        │
│  12 문항이 이어집니다            │
│                               │
│  [   시작   ]  [ 뒤로 가기 ]    │  ← ③ 버튼
└───────────────────────────────┘
```

- 오른쪽 위 🎧는 [듣기 준비](../0_공통/듣기%20준비%20가이드.md), 📊는 [연습 기록](../0_공통/연습%20기록%20가이드.md)을 엽니다.
  통계는 「높낮이 비교」 칸이 골라진 채로 열립니다.
- 이 두 아이콘은 **첫 화면과 결과 화면에서만** 보입니다. 문제를 푸는 동안에는 숨습니다.

### 난이도

난이도는 **두 소리의 높이 차이**입니다. 차이가 클수록 쉽습니다.

| 난이도 | 두 소리의 차이 | 비유 |
|---|---|---|
| **쉬움** | 크다 | 피아노 건반 **두 칸**(온음) 차이 |
| **보통** | 중간 | 피아노 건반 **한 칸**(반음) 차이 |
| **어려움** | 작다 | 건반 한 칸의 **절반** 차이 |

- 한 판 안에서는 난이도가 **바뀌지 않습니다.** 맞혀도 어려워지지 않고, 틀려도 쉬워지지 않습니다.
- 첫 소리(A)는 항상 **같은 높이**(피아노 「라」 음)입니다. 두 번째 소리(B)만 위나 아래로 달라집니다.
- B가 높을지 낮을지는 매번 **무작위**입니다.

## 2. 한 문항의 흐름

```
┌───────────────────────────────┐
│          높낮이 비교            │
│  웰니스 연습 · 병원 검사·진단을  │
│  대신하지 않아요                 │
│        [ 3/12 · 보통 ]          │  ← 몇 번째 문항인지
│  ████████░░░░░░░░░░░░░░░░░░░  │  ← 진행 막대
│                               │
│            ▮▮▮▮                │  ← 소리 나는 동안 움직임
│  두 번째 소리가 더 높았나요,     │
│  낮았나요?                      │
│                               │
│  ┌─────────┐   ┌─────────┐    │
│  │   ↓     │   │    ↑    │    │
│  │ 더 낮아요│   │ 더 높아요│    │
│  └─────────┘   └─────────┘    │
│                               │
│          [ ■ 중지 ]            │
└───────────────────────────────┘
```

1. **시작**을 누르면 소리 A가 **1초**, 잠깐(0.5초) 쉬고, 소리 B가 **1초** 납니다.
   이때 안내는 「듣는 중… 소리가 끝난 뒤 고르세요」입니다.
2. 소리가 **끝나야** 「더 낮아요 · 더 높아요」 버튼을 누를 수 있습니다. (소리 나는 동안에는 흐리게 잠겨 있습니다)
3. 답을 고르면 바로 **「맞았어요」 또는 「아쉬워요」**가 나옵니다.
4. 아래 버튼이 **다음 · 끝내기**로 바뀝니다. **다음**을 누르면 다음 문항 소리가 납니다.
5. 12번째 문항에서 **다음**을 누르면 결과 화면으로 갑니다.

- 한 문항에 답은 **한 번만** 할 수 있습니다.
- **다시 듣기는 없습니다.** 소리를 한 번 듣고 바로 고르는 연습입니다.

### 중간에 멈추고 싶을 때

| 지금 상태 | 누를 수 있는 것 | 일어나는 일 |
|---|---|---|
| 소리 나는 중 / 답 고르는 중 | **■ 중지** | 소리가 바로 멈추고 「연습 끝내기 — 여기서 끝낼까요?」가 뜹니다 |
| 답을 고른 뒤 | **끝내기** | 같은 확인 창이 뜹니다 |

- 확인 창에서 **끝내기** → 결과 화면으로 갑니다.
- 확인 창에서 **취소**(또는 창 바깥 누르기) → 연습이 이어집니다. 중지로 멈췄다면 **그 문항 소리를 처음부터 다시** 들려줍니다.
- 휴대폰 뒤로가기도 같은 확인 창을 띄웁니다.
- 앱을 내리거나(홈 화면으로 가기) 전화가 오면 소리가 끊기고 진행이 멈춥니다. 듣지 못한 문항이 오답으로 처리되지 않습니다.

## 3. 결과 화면

```
┌───────────────────────────────┐
│                     🎧   📊    │
│          높낮이 비교            │
│        12문항을 마쳤어요         │  ← 끝난 이유
│                               │
│   ✓ 오늘 연습이 끝났어요         │
│ ┌───────────────────────────┐ │
│ │         약 75%             │ │  ← 맞힌 비율
│ │          9/12              │ │  ← 맞힌 수 / 푼 수
│ │        100 cent            │ │  ← 이번 판 난이도(숫자)
│ │  그 간격에서 맞힌 비율 ·     │ │
│ │  점수·청력 검사·진단 결과 아님 │ │
│ └───────────────────────────┘ │
│        기기에 기록했어요         │  ← 저장 결과
│                               │
│ [다시 연습] [처음으로] [뒤로 가기]│
└───────────────────────────────┘
```

### 끝난 이유

| 문구 | 뜻 |
|---|---|
| 12문항을 마쳤어요 | 끝까지 다 풀었습니다 |
| 연습을 끝냈어요 | 중간에 「끝내기」를 눌렀습니다 |

### cent 숫자와 난이도

결과 화면과 통계에는 난이도가 **숫자(cent)**로 나옵니다.

| 숫자 | 난이도 |
|---|---|
| 200 cent | 쉬움 |
| 100 cent | 보통 |
| 50 cent | 어려움 |

### 저장 문구

| 문구 | 뜻 |
|---|---|
| **기기에 기록했어요** | 12문항을 다 풀어서 기록이 남았습니다 |
| **연습이 짧아서 기록에는 안 남겼어요** | 12문항 전에 끝내서 기록하지 않았습니다. 결과 화면에만 보입니다 |
| 기록 저장에 실패했어요 | 저장 중 문제가 생겼습니다. 다시 해 보세요 |

> 💡 **12문항을 끝까지 풀어야 기록됩니다.** 11문항까지 풀고 끝내도 기록에는 남지 않습니다.

### 결과 화면 버튼

| 버튼 | 하는 일 |
|---|---|
| **다시 연습** | 같은 난이도로 바로 새 판을 시작합니다 |
| **처음으로** | 첫 화면으로 돌아가 난이도를 다시 고를 수 있습니다 |
| **뒤로 가기** | 「다른 소리」 탭 목록으로 나갑니다 |

## 4. 내 동작이 기록에 어떻게 남나요?

| 게임에서 내가 한 일 | 기록에 남는 것 |
|---|---|
| 12문항을 끝까지 풀었다 | 한 판 기록 1개: 날짜·시각, 난이도, 맞힌 수/12, 맞힌 비율 |
| 12문항 전에 끝냈다 | **남지 않음** (결과 화면에서만 보임) |
| 답을 맞혔다 / 틀렸다 | 그 판의 맞힌 수에 더해짐. 문항 하나하나는 따로 남지 않습니다 |
| 앱을 내리거나 전화가 와서 끊겼다 | 듣지 못한 문항은 세지 않습니다 |

- 맞힌 비율은 **반올림한 정수**입니다. 예: 9/12 = 75%, 7/12 = 58.3…% → **약 58%**
- 기록은 **최근 50판**까지 기기에 보관됩니다. 그보다 많아지면 오래된 것부터 지워집니다.

## 5. 통계 「높낮이 비교」 읽기

📊 통계 화면에서 **높낮이 비교** 칸을 고르면 아래가 보입니다.

```
┌───────────────────────────────┐
│ (▮▮▮) 높낮이 비교               │
│       기록 5회                  │  ← 남은 기록 수
│ ┌───────────────────────────┐ │
│ │ 맞힌 비율 변화              │ │  ← ① 추이 그래프
│ │ 높을수록 더 많이 맞춤        │ │     (기록 2회부터)
│ │ 100 ┼─────────────────●     │ │
│ │  50 ┼───●───●──●            │ │
│ │   0 ┼──────────────────     │ │
│ │ 10/1     기록 0~100%   10/20 │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 최근 연습                   │ │  ← ② 최근 8판
│ │ 10/20 14:05  100 · 11/12 · 약 92% │
│ │ 10/18 09:30  200 · 9/12 · 약 75%  │
│ └───────────────────────────┘ │
│     높낮이 비교 기록 지우기       │
└───────────────────────────────┘
```

### ① 맞힌 비율 변화 (그래프)

- 기록이 **2회 이상**일 때 나옵니다.
- 위로 갈수록 많이 맞힌 판입니다. 가로는 날짜 순서이고, 왼쪽 아래가 첫 기록 날짜, 오른쪽 아래가 마지막 날짜입니다.
- 맨 오른쪽의 **크게 테두리 친 점**이 가장 최근 판입니다.
- 기록이 12회를 넘으면 중간 점은 숨기고 첫 점과 마지막 점만 찍습니다. 선은 그대로 이어집니다.
- 보관된 판(최대 50판)을 **모두** 그립니다. ② 최근 연습처럼 8판으로 자르지 않습니다.
- 가로 간격은 판 번호가 아니라 **연습한 시각**을 따릅니다. 같은 날 여러 판을 하면 점이 붙고, 며칠 쉬면 간격이 벌어집니다.
- 50판을 넘으면 가장 오래된 판부터 지워지므로 그래프 왼쪽 끝이 앞으로 밀려납니다.

### ② 최근 연습

한 줄이 한 판입니다. `10/20 14:05  100 · 11/12 · 약 92%`는
**10월 20일 오후 2시 5분, 보통(100 cent) 난이도, 12문항 중 11개 맞힘, 약 92%** 라는 뜻입니다.

> **주의:** 그래프는 **난이도를 가리지 않고** 모든 판을 한 줄로 잇습니다.
> 쉬움으로 92%를 받은 뒤 어려움으로 58%를 받으면 그래프가 내려가 보이지만, 실력이 줄어든 것이 아닙니다.
> **최근 연습** 줄의 앞 숫자(200 · 100 · 50)로 난이도를 함께 확인하세요.

## 6. 잘 연습하는 요령

| 지금 상태 | 추천 |
|---|---|
| 처음 해 본다 | **보통**으로 한두 판 해서 감을 잡기. 너무 어려우면 **쉬움** |
| 쉬움에서 대부분 맞힌다 (약 90% 이상) | **보통**으로 올리기 |
| 보통에서 대부분 맞힌다 | **어려움**에 도전 |
| 반쯤만 맞힌다 (약 50% 안팎) | 두 소리를 거의 구분하지 못하는 상태입니다. 한 단계 **쉬운** 난이도로 |

- 답이 두 개뿐이라 **아무렇게나 골라도 절반쯤은** 맞습니다. 그래서 50% 근처는 「잘 모르겠다」에 가깝습니다.
- 그래프는 **같은 난이도로 여러 판** 했을 때 변화를 보기 좋습니다. 한동안 난이도를 하나로 정해 두세요.
- 듣기 준비에서 볼륨을 맞추고, 매번 같은 이어폰으로 하세요.

## 7. 자주 묻는 질문

**Q. 소리를 놓쳤어요. 다시 들을 수 있나요?**
아니요. 이 연습에는 다시 듣기가 없습니다. 감으로 고르거나, ■ 중지 → 취소를 누르면 그 문항 소리를 처음부터 다시 듣습니다.

**Q. 연습 중에 난이도를 바꿀 수 있나요?**
아니요. 난이도는 첫 화면에서만 고릅니다. 결과 화면의 **처음으로**를 눌러 다시 고르세요.

**Q. 끝까지 안 했는데 통계에 없어요.**
정상입니다. 12문항을 다 푼 판만 기록됩니다.

**Q. 계속 맞히는데 어려워지지 않아요.**
이 연습은 한 판 안에서 난이도가 고정입니다. 직접 더 어려운 난이도를 고르세요.

**Q. 통계 그래프가 갑자기 뚝 떨어졌어요.**
그 판만 더 어려운 난이도로 했는지 **최근 연습**의 앞 숫자(200 · 100 · 50)를 확인하세요.

**Q. 이 퍼센트가 청력 검사 결과인가요?**
아니요. 정한 차이에서 맞힌 비율일 뿐입니다. 병원 검사나 진단을 대신하지 않습니다.
