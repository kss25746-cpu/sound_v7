# 강화학습 내 통계 가이드

강화학습 게임의 「내 통계」 화면을 읽는 방법을 안내합니다.
「내 통계」는 **표준 모드**와 **약점 훈련 모드**에서 내가 한 선택이 그대로 쌓인 기록입니다.
게임에서 어떻게 하느냐에 따라 숫자가 어떻게 바뀌는지, 그리고 통계를 보고 다음에 어떤 모드로 연습하면 좋은지 함께 설명합니다.

> 들어가는 곳: 강화학습 첫 화면 → **내 통계 보기** 버튼
> 나가는 곳: 오른쪽 아래 **← 나가기** 버튼, 또는 휴대폰 뒤로가기 → 강화학습 첫 화면으로
>
> 게임 자체의 방법은 [강화학습 가이드](강화학습%20가이드.md)를 보세요.

```
   표준 모드 / 약점 훈련 모드에서 게임
              │  맞힘 · 못 찾음이 동물마다 기록됨
              ▼
         📊 내 통계 화면
              │  약한 동물이 맨 위에 보임
              ▼
   약점 훈련 모드가 그 동물들을 먼저 문제로 냄
              │  다시 게임
              └──────────▶ (처음으로)
```

---

## 1. 화면 구성

화면은 위에서 아래로 세 부분입니다.

```
┌───────────────────────────────┐
│  📊 내 통계                    │
│ ┌───────────────────────────┐ │
│ │        전체 정확도          │ │  ← ① 전체 성적
│ │           78%              │ │
│ │  총 120회 시도 · 94회 정답   │ │
│ └───────────────────────────┘ │
│                               │
│ ┌───────────────────────────┐ │
│ │ 늑대             💪 연습필요 │ │  ← ② 동물별 카드
│ │ ███████░░░░░░░░░░░░░░░░░░  │ │     (약한 동물이 맨 위)
│ │ 40%                5/12회  │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 염소               ⭐ 우수  │ │
│ │ ███████████████████░░░░░░  │ │
│ │ 75%               41/55회  │ │
│ └───────────────────────────┘ │
│              ⋮                │
│                               │
│                    [← 나가기]  │  ← ③ 돌아가기 (첫 화면으로)
└───────────────────────────────┘
```

동물은 고양이, 닭, 소, 개, 오리, 코끼리, 염소, 말, 사자, 원숭이, 돼지, 늑대 모두 12마리입니다.
아직 한 번도 나오지 않은 동물도 카드가 있습니다.

---

## 2. 게임 한 판의 흐름 (두 모드 공통)

통계를 이해하려면 먼저 한 판이 어떻게 흘러가는지 알아야 합니다.

1. 동물 소리 몇 개가 **차례로** 들립니다. (「소리를 재생하고 있습니다...」)
2. 화면에 동물 12마리 버튼이 나옵니다. **들었던 동물을 모두** 고릅니다.
3. 누른 버튼은 맞혔으면 연한 초록, 틀렸으면 연한 빨강으로 바뀌고 다시 누를 수 없습니다. 맞혔으면 점수가 오르고, 틀렸으면 남은 기회가 줄어듭니다.
4. 틀릴 수 있는 기회는 한 판에 **3번**입니다. 화면 위의 「남은 기회」로 보입니다.
5. 판이 끝나는 경우는 두 가지입니다.
   - 들었던 동물을 **모두 찾으면** → 🎉 라운드 성공
   - 기회 3번을 **모두 쓰면** → 😥 라운드 실패. 결과 화면에 못 찾은 정답 동물 이름이 나옵니다.

### 난이도와 소리 개수

| 난이도 | 한 판에 나오는 소리 |
|---|---|
| 1 | 3개 |
| 2 | 4개 |
| 3 | 5개 |
| … | 난이도 + 2개 (최대 12개) |

- 라운드 **성공 → 난이도 1 올라감**, 라운드 **실패 → 난이도 1 내려감** (1 아래로는 안 내려감)
- 난이도는 두 모드가 **함께 씁니다.** 표준 모드에서 올린 난이도로 약점 훈련 모드도 진행됩니다.
- 난이도가 높을수록 한 판에 나오는 동물이 많아서 **통계 숫자도 빨리 쌓입니다.**

---

## 3. 내 동작이 통계에 어떻게 반영되나요?

통계의 숫자는 모두 **동물 하나하나를 따로** 셉니다. 두 모드 모두 **같은 통계**에 쌓입니다.

| 게임에서 내가 한 일 | 통계에 남는 것 |
|---|---|
| 들린 동물을 골라 **맞혔다** | 그 동물: 정답 **+1**, 시도 **+1** |
| 기회 3번을 다 써서 **실패**했고, 끝내 **못 찾은** 동물이 있다 | 못 찾은 동물마다: 정답 그대로, 시도 **+1** |
| 소리가 나지 않은 **엉뚱한 동물**을 골랐다 | 고른 동물의 기록은 **그대로**. 남은 기회만 1번 줄어듭니다 |
| 모두 찾아서 **성공**했다 | 들린 동물 전부 정답·시도 +1 (못 찾은 동물이 없음) |
| 판 **도중에 나가기**를 눌렀다 | 그때까지 **맞힌 것만** 남습니다. 아직 못 찾은 동물은 기록되지 않습니다 |

예를 들어 「염소 41/55회」는 **염소 소리가 문제로 55번 나왔고, 그중 41번 맞혔다**는 뜻입니다.

### 한 판 예시

난이도 2(소리 4개)에서 **개 · 소 · 오리 · 늑대**가 들렸다고 해 봅시다.

| 내 선택 | 결과 | 남은 기회 |
|---|---|---|
| 개 | 정답 → 개 1/1 | 3 |
| 말 | 오답 → 말 기록 변화 없음 | 2 |
| 소 | 정답 → 소 1/1 | 2 |
| 염소 | 오답 → 염소 기록 변화 없음 | 1 |
| 돼지 | 오답 → 기회 끝, **라운드 실패** | 0 |

판이 끝나면 못 찾은 **오리와 늑대**가 각각 0/1로 기록됩니다. 난이도는 1로 내려갑니다.
통계 화면에서는 오리와 늑대가 0%·💪 연습필요로 **맨 위쪽**에 올라옵니다.

> 💡 **오답을 고른 동물이 아니라, 들렸는데 놓친 동물이 약점으로 기록됩니다.**
> 「말을 잘못 눌렀다」가 아니라 「오리 소리를 못 알아들었다」가 기록되는 것입니다.

### 기록은 언제 저장되나요?

판이 **끝났을 때**(결과 화면)와 **나가기로 첫 화면에 돌아갈 때** 기기에 저장됩니다. 앱을 껐다 켜도 이어집니다.
판 도중에 앱을 강제로 끄면 그 판의 기록은 남지 않을 수 있습니다.

## 4. 표준 모드와 통계

**표준 모드**는 12마리 중에서 **무작위로** 문제를 냅니다.

- 모든 동물이 고르게 나오므로 **전체 실력을 고르게 측정**하는 데 알맞습니다.
- 처음 시작할 때, 또는 아직 ❓ 미도전 동물이 많을 때 표준 모드를 먼저 여러 판 하세요.
- 통계 카드에 횟수가 골고루 쌓여야 어떤 동물이 진짜 약한지 믿을 수 있습니다.

**표준 모드를 한 뒤 통계에서 보이는 변화**
- 미도전 동물이 줄어듭니다.
- 동물마다 횟수가 쌓이면서 맨 위(약점) 순서가 점점 뚜렷해집니다.

---

## 5. 약점 훈련 모드와 통계

**약점 훈련 모드**는 **내 통계를 보고** 문제를 고릅니다. 통계 화면의 순서가 곧 출제 순서와 같습니다.

### 어떤 동물이 나오나요?

1. 아래 두 조건에 모두 맞는 동물을 「약점」으로 고릅니다.
   - 시도가 **3회 이상**
   - 정확도가 **100% 미만** (한 번이라도 놓친 적이 있음)
2. 약점 동물을 **정확도가 낮은 순서**로 줄 세웁니다.
3. 이번 판에 필요한 소리 개수(난이도 + 2)만큼 **맨 앞부터** 채웁니다.
4. 자리가 남으면 나머지 동물로 **무작위로** 채웁니다.
5. 재생 순서는 섞어서 들려줍니다.

즉, **통계 화면 맨 위에 있는 동물들이 약점 훈련 모드에서 먼저 나옵니다.**
(시도가 2회 이하인 동물은 맨 위에 있어도 아직 약점으로 치지 않습니다.)

### 통계 화면으로 미리 알아보기

| 통계 화면에서 보이는 것 | 약점 훈련 모드에서 일어나는 일 |
|---|---|
| 맨 위 카드, 시도 3회 이상, 100% 미만 | **먼저** 문제로 나옵니다 |
| 시도 1~2회뿐인 동물 | 약점으로 치지 않습니다. 빈자리가 있을 때만 무작위로 나옵니다 |
| 100%인 동물 (한 번도 안 놓침) | 약점이 아닙니다. 빈자리가 있을 때만 무작위로 나옵니다 |
| 약점 동물이 거의 없음 | 대부분 무작위로 채워져 표준 모드와 비슷해집니다 |

### 약점 훈련을 하면 통계가 이렇게 바뀝니다

- 약한 동물을 **맞히면** 정확도가 오르고, 카드가 **아래로 내려가며** 등급이 올라갑니다.
- 그러면 다음 판에는 **그다음으로 약한 동물**이 앞으로 나옵니다.
- 약한 동물을 또 **놓치면** 정확도가 더 내려가 계속 맨 위에 남고, 다음 판에도 다시 나옵니다.
- 한 번이라도 놓친 동물은 100%로 돌아갈 수 없어 약점 후보에 계속 남습니다. 하지만 정확도가 오르면 **순서가 뒤로 밀려서** 덜 나오게 됩니다.

## 6. 단위 읽는 법

| 화면 글자 | 뜻 | 예 |
|---|---|---|
| **○○%** | 정확도. 나온 횟수 중 맞힌 비율 | 75% = 4번 중 3번 꼴로 맞힘 |
| **○/○회** | 맞힌 횟수 / 나온 횟수 | 41/55회 = 55번 중 41번 맞힘 |
| **총 ○회 시도 · ○회 정답** | 12마리 기록을 모두 더한 값 (두 모드 합계) | 총 120회 시도 · 94회 정답 |
| **N/A** | 아직 기록이 없어 계산할 수 없음 | 한 번도 안 나온 동물 |

- 퍼센트는 **소수점 첫째 자리에서 반올림한 정수**입니다. 41/55는 74.5…%이므로 **75%**로 보입니다.
- **전체 정확도**는 동물별 퍼센트의 평균이 아닙니다. 전체 맞힌 횟수를 전체 시도 횟수로 나눈 값입니다.
  그래서 많이 나온 동물의 성적이 전체 정확도에 더 크게 반영됩니다.
- 게임 중 화면 위의 「점수」나 결과 화면의 「최종 점수」는 **그 판의 점수**이고, 통계와는 따로입니다.

## 7. 등급

카드 오른쪽 위의 이모지와 글자가 등급입니다. **화면에 보이는 퍼센트 숫자 그대로** 정합니다.

| 등급 | 정확도 | 막대 색 | 이렇게 보세요 | 추천 연습 |
|---|---|---|---|---|
| 🔥 **완벽** | 90% 이상 | 빨간 계열(코랄) | 거의 틀리지 않아요 | 표준 모드로 유지 |
| ⭐ **우수** | 75% ~ 89% | 청록색 | 대부분 맞혀요. 가끔 헷갈려요 | 표준 모드 |
| 👍 **보통** | 50% ~ 74% | 연한 민트색 | 맞힐 때와 틀릴 때가 반반쯤이에요 | 약점 훈련 모드 |
| 💪 **연습필요** | 49% 이하 | 노란색 | 자주 놓쳐요 | 약점 훈련 모드 집중 |
| ❓ **미도전** | 기록 없음 | 막대 없음 | 아직 문제로 나오지 않았어요 | 표준 모드로 먼저 기록 쌓기 |

> **주의:** 🔥 완벽의 막대는 **빨간 계열**입니다. 빨간색이라고 나쁜 성적이 아닙니다.
> 가장 좋은 등급입니다. 색보다 **이모지와 글자**를 먼저 보세요.

같은 퍼센트면 항상 같은 등급입니다. 예를 들어 75%는 언제나 ⭐ 우수, 90%는 언제나 🔥 완벽입니다.

---

## 8. 막대 게이지

```
0%                        100%
├─────────────────────────┤
███████████████████░░░░░░    ← 75%: 막대가 4분의 3까지 찼어요
```

- 막대 **길이 = 정확도**입니다. 카드 폭 끝까지 차면 100%입니다.
- 막대 **색 = 등급**입니다. 7번 표의 색과 같습니다.
- 막대 길이는 아래 퍼센트 글자와 같은 숫자로 그립니다.
- 미도전 동물은 막대 대신 「**아직 시도하지 않았습니다**」가 나옵니다.

여러 카드를 위아래로 훑어보면 막대 길이만으로 잘하는 동물과 약한 동물이 바로 구분됩니다.
**짧은 막대가 모여 있는 위쪽이 약점 훈련 모드에서 먼저 나올 동물들**입니다.

---

## 9. 카드 순서

카드는 **정확도가 낮은 동물부터** 위에 놓입니다. 약점 훈련 모드가 문제를 고르는 순서와 같습니다.

- **맨 위에 있는 동물 = 지금 가장 약한 소리**입니다. 화면을 열면 먼저 맨 위 두세 개를 보세요.
- 아래로 갈수록 잘하는 동물입니다.
- 미도전 동물은 100%인 동물과 함께 **맨 아래쪽**에 놓입니다.

---

## 10. 통계를 잘 읽는 요령

### ① 퍼센트와 횟수를 같이 보세요

횟수가 적으면 퍼센트가 쉽게 크게 오르내립니다.

| 카드 | 해석 |
|---|---|
| 개 · 100% · **1/1회** | 한 번 나와서 맞혔을 뿐이에요. 아직 판단하기 일러요 |
| 소 · 92% · **46/50회** | 50번이나 나왔는데도 꾸준히 맞혀요. 정말 잘하는 소리예요 |
| 늑대 · 0% · **0/2회** | 두 번 놓쳤어요. 아직 2회라 약점 훈련 대상은 아니에요. 몇 번 더 해 보세요 |

**시도가 10회쯤 쌓인 뒤의 등급**이 실력을 더 잘 보여 줍니다.

### ② 통계 상태에 맞춰 모드를 고르세요

| 통계 화면 상태 | 추천 |
|---|---|
| ❓ 미도전이 많거나 횟수가 대부분 적음 | **표준 모드**로 고르게 기록 쌓기 |
| 맨 위에 💪 연습필요·👍 보통 동물이 있고 시도 3회 이상 | **약점 훈련 모드**로 그 동물 집중 연습 |
| 거의 모든 동물이 ⭐ 우수·🔥 완벽 | **표준 모드**로 실력 유지 확인 |

### ③ 변화를 보세요

몇 판 한 뒤 다시 열어서 아래를 확인해 보세요.

- 맨 위에 있던 동물이 아래로 내려갔는지
- 💪 연습필요 → 👍 보통 → ⭐ 우수로 등급이 올라갔는지
- 전체 정확도가 올라갔는지

### ④ 연습 순서 (요약)

1. **표준 모드**로 여러 판 해서 동물마다 기록 쌓기
2. **내 통계**에서 전체 정확도와 **맨 위 카드 2~3개** 확인
3. 그 카드의 **횟수**가 3회 이상인지 확인 (적으면 표준 모드를 더 하기)
4. **약점 훈련 모드**로 그 동물들 연습
5. 다시 **내 통계**에서 순서·등급 변화 확인 → 1 또는 4로 돌아가기

## 11. 자주 묻는 질문

**Q. 엉뚱한 동물을 골랐는데 그 동물 점수가 깎이나요?**
아니요. 고른 동물의 기록은 그대로입니다. 대신 기회가 줄어서 판이 실패로 끝나면, **들렸는데 못 찾은 정답 동물**의 시도가 1회씩 늘어납니다.

**Q. 표준 모드와 약점 훈련 모드 통계가 따로 있나요?**
아니요. 두 모드의 기록이 **하나의 통계**에 합쳐집니다. 난이도도 함께 씁니다.

**Q. 약점 훈련 모드인데 약하지 않은 동물도 나와요.**
약점 동물(시도 3회 이상, 100% 미만)이 이번 판에 필요한 소리 개수보다 적으면 나머지 자리를 무작위로 채우기 때문입니다.

**Q. 맨 위에 있는 동물이 약점 훈련 모드에 안 나와요.**
그 동물의 시도가 3회보다 적으면 아직 약점으로 치지 않습니다. 표준 모드로 몇 번 더 만나면 약점 훈련 대상이 됩니다.

**Q. 판 도중에 나가기를 누르면 기록은 어떻게 되나요?**
그때까지 맞힌 동물은 기록됩니다. 아직 못 찾은 동물은 기록되지 않고, 난이도도 그대로입니다.

**Q. 74.5%처럼 애매한 값은 등급이 어떻게 되나요?**
화면에는 반올림해서 75%로 보이고, 등급도 그 75%로 정하므로 ⭐ 우수입니다. 보이는 숫자와 등급은 항상 맞습니다.

**Q. 전체 정확도와 동물별 퍼센트의 평균이 다른데요?**
정상입니다. 전체 정확도는 모든 동물의 횟수를 합쳐서 계산하기 때문에 많이 나온 동물의 영향이 큽니다.

**Q. 미도전 동물이 계속 미도전이에요.**
문제로 나와야 기록이 생깁니다. **표준 모드**는 12마리 중에서 무작위로 내므로 여러 판 하면 차례로 나옵니다.
