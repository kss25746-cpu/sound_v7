# 다른 소리 탭 개요

하단 첫 번째 탭 **다른 소리**(👂 귀 아이콘)입니다. 앱을 켜면 처음 보이는 탭입니다.
말소리·악기가 아닌 소리 — **소리의 높낮이**와 **동물 소리** — 를 듣는 연습이 모여 있습니다.

```
   하단 탭 [다른 소리]
        │
        ▼
   다른 소리 목록
   ├── 🎧 듣기 준비 (오른쪽 위)
   ├── 📊 연습 기록 (오른쪽 위)
   ├── ▮▮▮ 소리 높낮이     → 두 소리 중 두 번째가 높은지 낮은지
   └── 🐾 동물 소리 게임   → 게임 목록
                              ├── 소리 맞추기
                              ├── 소리 순서
                              └── 강화학습 (+ 내 통계)
```

---

## 1. 목록 화면

```
┌───────────────────────────────┐
│ 다른 소리               🎧  📊  │  ← 듣기 준비 · 연습 기록
│ 높낮이·동물 소리를 고릅니다 ·    │
│ 병원 검사가 아니에요             │
│ ┌───────────────────────────┐ │
│ │ (▮▮▮) 소리 높낮이           │ │
│ │       두 소리 중 높은 쪽을   │ │
│ │       고르는 연습            │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ (🐾) 동물 소리 게임          │ │
│ │       동물 소리를 듣고 맞히는 │ │
│ │       게임 셋                │ │
│ └───────────────────────────┘ │
└───────────────────────────────┘
│  다른 소리 │ 말소리 │ 악기 소리 │ 설정 │  ← 하단 탭
```

카드를 누르면 그 연습이 열립니다. 연습 안에서 **뒤로 가기**·**나가기**나 휴대폰 뒤로가기를 누르면 이 목록으로 돌아옵니다.

## 4. 어떤 순서로 해 볼까요?

1. 🎧 **듣기 준비**로 이어폰과 볼륨을 맞춥니다.
2. **소리 높낮이**를 「보통」으로 한 판 해 봅니다. 너무 어려우면 「쉬움」.
3. **동물 소리 게임**은 쉬운 순서로 해 보세요.
   - **소리 순서**(하나씩 들림) → **강화학습**(하나씩, 개수가 늘어남) → **소리 맞추기**(겹쳐 들림)
4. 며칠 연습한 뒤 📊 **연습 기록**과 강화학습 **내 통계**에서 변화를 봅니다.

> 이 탭의 연습은 **웰니스 연습**입니다. 병원 검사나 진단을 대신하지 않습니다.
