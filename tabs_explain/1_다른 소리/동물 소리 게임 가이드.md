# 동물 소리 게임 가이드

「다른 소리」 탭의 **동물 소리 게임**을 고르는 화면(게임 목록)과, 세 게임이 함께 쓰는 **별 · 클리어 · 미션** 표시를 안내합니다.
게임 하나하나의 방법은 각 게임 문서를 보세요.

> 들어가는 곳: **다른 소리** 탭 → **동물 소리 게임** 카드
> 나가는 곳: 오른쪽 아래 **← 나가기** 버튼, 또는 휴대폰 뒤로가기

```
   다른 소리 탭
        │  동물 소리 게임
        ▼
   🐾 청능 훈련 게임 (게임 목록)
        ├── 소리 맞추기  → 들린 동물 3마리 고르기
        ├── 소리 순서    → 들린 순서대로 3마리 놓기
        └── 강화학습     → 난이도가 오르내리고 약점을 연습
        │
        ▼  게임을 해서
   ⭐ 별 · ✔ 클리어가 게임 카드에 붙음
```

| 게임 | 하는 일 | 문서 |
|---|---|---|
| **소리 맞추기** | 동시에 섞여 들리는 동물 소리 3개를 듣고 12마리 중에서 고르기 | [소리 맞추기 가이드](소리%20맞추기%20가이드.md) |
| **소리 순서** | 하나씩 들리는 동물 소리 3개를 **들린 순서대로** 칸에 놓기 | [소리 순서 가이드](소리%20순서%20가이드.md) |
| **강화학습** | 판마다 소리 개수가 늘거나 줄고, 약한 동물을 골라 연습하기 | [강화학습 가이드](강화학습%20가이드.md) |

세 게임 모두 같은 동물 12마리를 씁니다.
**고양이 · 닭 · 소 · 개 · 오리 · 코끼리 · 염소 · 말 · 사자 · 원숭이 · 돼지 · 늑대**

## 1. 게임 목록 화면

```
┌───────────────────────────────┐
│ AUDITORY TRAINING      ⭐2 ✔1  │  ← ② 모은 별 · 클리어 수
│ 👂 청능 훈련 게임               │
│ 원하는 게임을 선택하여 청능 훈련을│  ← 한 글자씩 써지는 안내
│ 시작하세요!|                    │
│                               │
│ ┌─────────┐ ┌─────────┐       │
│ │⭐     ✔ │ │⭐       │       │  ← ① 게임 카드
│ │  (🐾)   │ │  (🔀)   │       │     (별·클리어 배지)
│ │소리 맞추기│ │소리 순서 │       │
│ │들린 동물 │ │들은 순서 │       │
│ │소리를 …  │ │대로 …    │       │
│ └─────────┘ └─────────┘       │
│ ┌─────────┐                   │
│ │  (🚀)   │                   │
│ │ 강화학습 │                   │
│ │AI가 약점을│                   │
│ │분석해 …  │                   │
│ └─────────┘                   │
│                               │
│        🔄 전체 초기화           │  ← ③ 기록 지우기
│                    [← 나가기]  │  ← ④ 나가기
└───────────────────────────────┘
```

### ① 게임 카드

카드를 누르면 그 게임이 열립니다. 카드 모서리의 배지로 지금까지 얻은 것을 알 수 있습니다.

| 카드에 보이는 것 | 뜻 |
|---|---|
| 배지 없음 | 아직 별을 얻지 못했습니다 |
| ⭐ 별 배지 | 그 게임의 **미션**을 한 번 이상 이뤘습니다 |
| ✔ 체크 배지 · 아이콘 테두리가 **금색** | 그 게임을 **클리어**했습니다 (더 어려운 조건) |

### ② 모은 별 · 클리어 수

제목 오른쪽의 ⭐ 숫자는 **별을 얻은 게임 수**, ✔ 숫자는 **클리어한 게임 수**입니다. (최대 3)
하나도 없으면 숫자가 보이지 않습니다.

### ③ 전체 초기화

세 게임의 **별 · 클리어**와 **강화학습 기록**(난이도·동물별 통계)을 모두 지웁니다.
**피아노 · 기타 미션의 별 · 클리어도 함께 지워집니다.** (피아노 · 기타의 레벨별 누적 · 최고 점수는 남습니다)
누르면 「별, 완료, 게임 진행 데이터를 모두 초기화합니다. 계속할까요?」가 뜨고 **초기화**를 눌러야 지워집니다.

> **주의:** 되돌릴 수 없습니다. 특히 강화학습의 「내 통계」와 피아노 · 기타의 별 · 클리어도 함께 사라집니다.

### ④ 나가기

오른쪽 아래 **← 나가기**를 누르면 「다른 소리」 탭 목록으로 돌아갑니다.
이 버튼은 **게임 안에서도 같은 자리**에 있습니다. 게임 안에서 누르면 이 게임 목록으로 돌아옵니다.
(강화학습만 조금 다릅니다. [강화학습 가이드](강화학습%20가이드.md)를 보세요)

## 2. 별과 클리어

게임마다 **별 조건**(미션)과 **클리어 조건**이 있습니다. 클리어가 더 어렵습니다.

| 게임 | ⭐ 별 (미션) | ✔ 클리어 |
|---|---|---|
| 소리 맞추기 | 3마리를 모두 맞히기 | **한 번도 틀리지 않고** 3마리를 모두 맞히기 |
| 소리 순서 | 순서를 맞히기 | **첫 번째 제출에서** 순서를 맞히기 |
| 강화학습 | 난이도 **3**에 닿기 | 첫 화면에서 시작한 뒤 **오답 없이** 난이도 3에 닿기 |

- 별과 클리어는 게임마다 **한 번 얻으면 계속 남습니다.** 여러 번 얻어도 하나입니다.
- 클리어를 이루면 그 판에 별도 함께 얻습니다.
- 앱을 껐다 켜도 남습니다. 지우려면 ③ 전체 초기화를 씁니다.

## 3. 미션 아이콘 (❔)

게임 화면 오른쪽 위의 **❔ 동그라미 물음표**가 미션 안내입니다. 누르면 미션 창이 열립니다.

물음표의 **색**만 봐도 달성 정도를 알 수 있습니다.

| 물음표 색 | 뜻 |
|---|---|
| 회색 | 아직 별을 얻지 못했습니다 |
| 구리색(동메달 색) | 별을 얻었습니다 |
| 금색 | 클리어했습니다 |

```
┌───────────────────────────────┐
│ 소리 맞추기 미션                │
│ ┌────────────┐┌────────────┐  │
│ │ ★ 별 · 획득 ││ ○ 클리어 ·  │  │  ← 별 칸 · 클리어 칸
│ │ 정답 맞추기 ││   미달성    │  │     (달성하면 분홍색)
│ │            ││ 한 번도 틀리 │  │
│ │            ││ 지 않고 …   │  │
│ └────────────┘└────────────┘  │
│ 현재 진행 상황                  │
│ ┌───────────────────────────┐ │
│ │ 이번 판 실수 여부      없음 │ │  ← 지금 판의 상태
│ └───────────────────────────┘ │
│           [ 닫기 ]             │
└───────────────────────────────┘
```

- **닫기**를 누르거나 창 바깥을 누르면 닫힙니다.
- 「현재 진행 상황」은 게임마다 다릅니다.

| 게임 | 현재 진행 상황 |
|---|---|
| 소리 맞추기 | 이번 판 실수 여부 (있음 / 없음) |
| 소리 순서 | 현재 시도 횟수 (○회) |
| 강화학습 | 현재 난이도 · 시작 후 오답 여부 (있음 / 없음) |

## 4. 이 게임들의 기록

- 세 게임은 「연습 기록」(📊 통계) 화면에 **나오지 않습니다.** 게임 카드의 별·클리어로만 보입니다.
- 강화학습만 게임 안에 **내 통계** 화면이 따로 있습니다. → [강화학습 내 통계 가이드](강화학습%20내%20통계%20가이드.md)

## 5. 자주 묻는 질문

**Q. 별을 또 얻으면 숫자가 늘어나나요?**
아니요. 게임마다 별 하나, 클리어 하나뿐입니다. 위 ⭐ 숫자는 「별을 얻은 게임이 몇 개인지」입니다.

**Q. 전체 초기화를 잘못 눌렀어요.**
확인 창에서 **취소**를 누르면 아무것도 지워지지 않습니다. **초기화**까지 눌렀다면 되돌릴 수 없습니다.

**Q. 게임 중에 나가기를 누르면 어떻게 되나요?**
소리가 멈추고 게임 목록으로 돌아옵니다. 그 판은 끝나지 않은 것으로 버려집니다. (강화학습은 맞힌 동물 기록이 남습니다)
