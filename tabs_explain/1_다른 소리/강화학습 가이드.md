# 강화학습 가이드

동물 소리 게임의 **강화학습**(화면 제목: 청능 훈련)을 하는 방법을 안내합니다.
동물 소리 몇 개를 차례로 듣고, 들었던 동물을 **모두** 고르는 게임입니다.
성공하면 다음 판에 소리가 하나 늘고, 실패하면 하나 줄어듭니다. 내가 자주 놓치는 동물은 **약점 훈련 모드**에서 먼저 나옵니다.

> 들어가는 곳: **다른 소리** 탭 → **동물 소리 게임** → **강화학습** 카드
> 나가는 곳: 오른쪽 아래 **← 나가기** (아래 「나가기 버튼」 참고), 또는 휴대폰 뒤로가기

```
   청능 훈련 첫 화면
   ├── 🎮 표준 모드       ─┐
   ├── 🔥 약점 훈련 모드   ─┤  소리 듣기 → 동물 고르기 → 결과
   └── 📊 내 통계 보기     │        │
              ▲             │        │ 계속하기 → 다음 판
              │             └────────┘
              └──── ← 나가기 (어느 화면에서든 첫 화면으로)
```

---

## 1. 첫 화면

```
┌───────────────────────────────┐
│          👂 청능 훈련           │
│                               │
│   ┌───────────────────────┐   │
│   │ 🎮  표준 모드           │   │  ← 12마리 중 무작위로 출제
│   └───────────────────────┘   │
│   ┌───────────────────────┐   │
│   │ 🔥  약점 훈련 모드      │   │  ← 내가 약한 동물을 먼저 출제
│   └───────────────────────┘   │
│   ┌───────────────────────┐   │
│   │ 📊  내 통계 보기        │   │  ← 동물별 정확도
│   └───────────────────────┘   │
│                               │
│                    [← 나가기]  │  ← 게임 목록으로
└───────────────────────────────┘
```

| 버튼 | 하는 일 |
|---|---|
| **표준 모드** | 12마리 중에서 **무작위로** 문제를 냅니다. 고르게 기록을 쌓을 때 |
| **약점 훈련 모드** | 내 통계에서 **자주 놓친 동물부터** 문제를 냅니다 |
| **내 통계 보기** | 동물마다 몇 번 나와서 몇 번 맞혔는지 봅니다 → [강화학습 내 통계 가이드](강화학습%20내%20통계%20가이드.md) |

- 첫 화면과 내 통계 화면에는 미션 아이콘(❔)이 보이지 않습니다. 게임이 시작되면 오른쪽 위에 나타납니다.
- 앱을 켜고 처음 들어오면 기록을 불러오는 동안 잠깐 동그라미가 돕니다.

---

## 2. 한 판의 흐름

### ① 소리 듣기

모드 버튼을 누르면 물결 그림과 「소리를 재생하고 있습니다...」가 나오고 동물 소리가 **하나씩 차례로** 들립니다.

- 소리는 **약 0.8초 간격으로** 하나씩 시작합니다. 소리가 긴 동물은 다음 소리와 살짝 겹칠 수 있습니다.
- 몇 마리가 나오는지는 **난이도**가 정합니다. (아래 3절)

### ② 동물 고르기

```
┌───────────────────────────────┐
│                          (❔)  │
│ 난이도: 2 | 남은 기회: 3 | 점수: 20│  ← 지금 상태
│   들었던 소리를 모두 선택하세요   │
│                               │
│  [고양이] [ 닭 ] [ 소 ] [ 개 ]  │  ← 동물 이름 버튼 12개
│  [ 오리 ] [코끼리] [염소] [ 말 ] │     (그림 없이 이름만)
│  [ 사자 ] [원숭이] [돼지] [늑대] │
│                               │
│                    [← 나가기]  │
└───────────────────────────────┘
```

들었던 동물 버튼을 **모두** 누릅니다. 순서는 상관없습니다.

| 누른 버튼 | 일어나는 일 |
|---|---|
| **정답** (들린 동물) | 버튼이 **연한 초록**으로 바뀌고 잠깁니다. 위의 **점수**가 **10 × 난이도**만큼 오릅니다 |
| **오답** (안 들린 동물) | 버튼이 **연한 빨강**으로 바뀌고 잠깁니다. 위의 **남은 기회**가 1 줄어듭니다 |

- 버튼 색으로 맞았는지 바로 알 수 있습니다. 위의 **점수**(올랐으면 정답)와 **남은 기회**(줄었으면 오답)로도 확인할 수 있습니다.
- 한 판에 틀릴 수 있는 기회는 **3번**입니다.
- 한 번 누른 버튼은 다시 누를 수 없습니다.
- 소리를 **다시 듣는 버튼은 없습니다.**

### ③ 결과

| 판이 끝나는 경우 | 결과 화면 |
|---|---|
| 들린 동물을 **모두 찾았다** | 🎉 **라운드 성공!** 🎉 · 최종 점수 |
| 기회 3번을 **모두 썼다** | 😥 **라운드 실패** 😥 · 최종 점수 · **정답: (끝내 못 찾은 동물)** |

```
┌───────────────────────────────┐
│                          (❔)  │
│        😥 라운드 실패 😥         │
│         최종 점수: 20           │
│        정답: 오리, 늑대          │  ← 실패했을 때만
│   ┌───────────────────────┐   │
│   │ ▶  계속하기             │   │
│   └───────────────────────┘   │
│                    [← 나가기]  │
└───────────────────────────────┘
```

- **계속하기**를 누르면 **같은 모드로** 다음 판이 바로 시작됩니다. 바뀐 난이도가 적용됩니다.
- 「정답」에는 들린 동물 전부가 아니라 **끝내 못 찾은 동물만** 나옵니다.
- 「최종 점수」는 그 판의 점수입니다. 판마다 0에서 다시 시작하고, 따로 저장되지 않습니다.

## 3. 난이도

| 난이도 | 한 판에 나오는 소리 | 정답 1개당 점수 |
|---|---|---|
| 1 | 3개 | 10점 |
| 2 | 4개 | 20점 |
| 3 | 5개 | 30점 |
| … | 난이도 + 2개 (최대 12개) | 10 × 난이도 |

- 라운드 **성공 → 난이도 1 올라감**, 라운드 **실패 → 난이도 1 내려감** (1 아래로는 안 내려감)
- 판 도중에 나가면 난이도는 **그대로**입니다.
- 난이도는 **기기에 저장**됩니다. 앱을 껐다 켜도, 내일 다시 해도 이어집니다.
- 표준 모드와 약점 훈련 모드는 난이도를 **함께 씁니다.**

---

## 4. 표준 모드와 약점 훈련 모드

| | 표준 모드 | 약점 훈련 모드 |
|---|---|---|
| 문제 고르는 법 | 12마리 중 **무작위** | 약점 동물을 **정확도 낮은 순서로** 먼저, 남는 자리는 무작위 |
| 이럴 때 | 처음 시작할 때, 기록을 고르게 쌓을 때 | 내 통계에서 약한 동물이 보일 때 |
| 기록 | 내 통계에 쌓임 | **같은** 내 통계에 쌓임 |

약점 동물이 되려면 **시도 3회 이상, 정확도 100% 미만**이어야 합니다.
자세한 규칙은 [강화학습 내 통계 가이드](강화학습%20내%20통계%20가이드.md) 5절을 보세요.

---

## 5. 나가기 버튼

오른쪽 아래 **← 나가기**는 **지금 어느 화면이냐에 따라** 가는 곳이 다릅니다. 휴대폰 뒤로가기도 같습니다.

| 지금 화면 | 나가기를 누르면 |
|---|---|
| 소리 듣는 중 · 동물 고르는 중 | 소리가 멈추고 **청능 훈련 첫 화면**으로 |
| 결과 화면 | **청능 훈련 첫 화면**으로 |
| 내 통계 | **청능 훈련 첫 화면**으로 |
| 청능 훈련 첫 화면 | **동물 소리 게임 목록**으로 |

즉, 게임 목록까지 나가려면 **첫 화면에서 한 번 더** 누릅니다.
결과 화면과 내 통계 화면에는 따로 「홈으로」 버튼이 없습니다. 나가기 버튼이 그 역할을 합니다.

## 6. 별과 클리어

| 얻는 것 | 조건 |
|---|---|
| ⭐ **별** | 난이도가 **2에서 3으로** 오르는 순간 |
| ✔ **클리어** | 첫 화면에서 모드를 눌러 시작한 뒤, **오답을 한 번도 누르지 않고** 난이도 3에 닿기 |

- 미션 아이콘(❔)을 누르면 「**현재 난이도**」와 「**시작 후 오답 여부**」가 보입니다.
- 「시작 후 오답 여부」는 **첫 화면에서 모드 버튼을 누를 때만** 「없음」으로 돌아갑니다. 결과 화면의 **계속하기**로 이어 가는 동안에는 한 번 「있음」이 되면 계속 「있음」입니다.
- 클리어에 다시 도전하려면 **나가기로 첫 화면에 돌아가서** 모드를 다시 누르세요.
- 난이도가 이미 3 이상으로 저장되어 있으면, 별·클리어를 얻으려면 **2까지 내려갔다가 다시 3으로** 올라가야 합니다.

별·미션 아이콘 색에 대한 자세한 설명은 [동물 소리 게임 가이드](동물%20소리%20게임%20가이드.md)를 보세요.

## 7. 내 동작이 기록에 어떻게 남나요?

| 게임에서 내가 한 일 | 기록에 남는 것 |
|---|---|
| 들린 동물을 맞혔다 | 그 동물: 정답 +1, 시도 +1 |
| 기회를 다 써서 실패했다 | 끝내 못 찾은 동물마다: 시도 +1 (정답은 그대로) |
| 안 들린 동물을 골랐다 | 고른 동물의 기록은 **그대로**. 남은 기회만 1 줄어듭니다 |
| 성공 / 실패로 판이 끝났다 | 난이도 ±1, 동물별 기록이 기기에 저장됩니다 |
| 판 도중에 **나가기** | 그때까지 **맞힌 동물만** 남습니다. 난이도는 그대로 |

- 기록은 판이 끝났을 때(결과 화면)와 첫 화면으로 돌아왔을 때 기기에 저장됩니다.
- 이 게임의 기록은 「연습 기록」(📊) 화면에는 나오지 않고, 게임 안의 **내 통계**에서만 봅니다.
- 게임 목록의 **전체 초기화**를 누르면 난이도와 내 통계가 모두 지워집니다.

---

## 8. 잘 하는 요령

1. 처음에는 **표준 모드**로 여러 판 해서 동물마다 기록을 쌓습니다.
2. **내 통계 보기**로 맨 위(가장 약한) 동물 2~3마리를 확인합니다.
3. 그 동물들의 시도가 3회 이상이면 **약점 훈련 모드**로 연습합니다.
4. 몇 판 뒤 다시 내 통계를 열어 순서와 등급이 바뀌었는지 봅니다.

- 확실한 동물부터 누르세요. 헷갈리는 동물을 찍으면 기회가 줄어듭니다.
- 남은 기회가 1번일 때는 특히 신중하게 고르세요. 한 번 더 틀리면 판이 끝나고 난이도가 내려갑니다.

## 9. 자주 묻는 질문

**Q. 난이도가 자꾸 1로 떨어져요.**
실패하면 1씩 내려갑니다. 난이도 1(소리 3개)에서 차분히 성공을 쌓으면 다시 올라갑니다.

**Q. 계속하기를 누르면 모드가 바뀌나요?**
아니요. 방금 한 모드 그대로 이어 갑니다. 모드를 바꾸려면 나가기로 첫 화면에 가세요.

**Q. 별을 이미 받았는데 난이도 3에 또 닿았어요.**
별과 클리어는 한 번만 얻습니다. 다시 닿아도 바뀌지 않습니다.

**Q. 결과 화면에서 정답 동물이 다 안 나와요.**
「정답」에는 **못 찾은 동물만** 나옵니다. 이미 맞힌 동물은 목록에서 빠집니다.

**Q. 점수는 어디에 남나요?**
남지 않습니다. 점수는 그 판에서만 보이는 숫자입니다. 오래 남는 것은 난이도와 동물별 통계입니다.
