# 한국어 음성 안내 가이드

「말소리」 탭의 **한 글자 · 두 글자 · 빙고**는 휴대폰의 **한국어 음성 읽기(TTS, 텍스트 음성 변환)** 로 단어를 읽어 줍니다.
기기에 한국어 음성이 없으면 연습 대신 「**한국어 음성이 없어요**」 화면이 열립니다. 이 문서는 그 화면과 음성을 받는 방법을 안내합니다.

> 나오는 곳: **말소리** 탭 → **한 글자 · 두 글자 · 빙고** 카드를 눌렀을 때, 기기에 한국어 음성이 없으면
> 나가는 곳: **뒤로 가기** 버튼, 또는 휴대폰 뒤로가기 → 말소리 탭 목록

```
   한 글자 / 두 글자 / 빙고 카드
        │  앱이 한국어 음성이 있는지 확인
        ├── 있음 → 그 연습 첫 화면
        └── 없음 → 🔈 한국어 음성이 없어요
                     │  휴대폰 설정에서 한국어 음성 받기
                     ▼
                  다시 확인 → 있으면 원래 가려던 연습으로
```

---

## 1. 왜 이 화면이 나오나요?

- 휴대폰의 음성 읽기 기능은 **엔진**과 **언어 데이터**가 따로 설치됩니다. 엔진이 있어도 한국어 데이터가 없으면 단어를 읽지 못합니다.
- 소리 없이 진행되면 보기를 찍게 되어 연습이 되지 않습니다. 그래서 시작 전에 막고 안내합니다.
- 소리 찾기 · 소리 구분 · 단어 카드 · 문장 듣기는 미리 녹음된 소리를 쓰므로 이 화면이 나오지 않습니다.

---

## 2. 화면 구성

```
┌───────────────────────────────┐
│            (🔈)                │
│      한국어 음성이 없어요         │
│  이 기기에 한국어 음성이 깔려 있지 │
│  않아 단어를 읽어 줄 수 없어요.   │
│  한 번만 받아 두면 다음부터는     │
│  바로 연습할 수 있어요.          │
│ ┌───────────────────────────┐ │
│ │ 받는 방법                   │ │
│ │ ① 휴대폰 «설정»을 열고       │ │
│ │   «음성 변환»으로 검색하세요   │ │
│ │ ② «텍스트 음성 변환 출력»을   │ │
│ │   누르세요                   │ │
│ │ ③ «Google 텍스트 음성 변환»  │ │
│ │   옆 톱니바퀴를 누르세요       │ │
│ │ ④ «음성 데이터 설치»에서      │ │
│ │   «한국어»를 받으세요         │ │
│ └───────────────────────────┘ │
│  메뉴가 안 보이면 Play 스토어에서 │
│  «Google 음성 서비스»를 설치하거나│
│  업데이트한 뒤 다시 확인해 주세요. │
│                               │
│  [  다시 확인  ]  [ 뒤로 가기 ]  │
└───────────────────────────────┘
```

---

## 3. 이렇게 하세요

1. 화면의 **받는 방법** 네 단계를 따라 휴대폰 설정에서 한국어 음성을 받습니다.
   - 제조사마다 메뉴 이름이 조금씩 달라서, 설정 맨 위 **검색**에 「음성 변환」을 입력해 찾는 것이 가장 빠릅니다.
2. 앱으로 돌아와 **다시 확인**을 누릅니다. 확인하는 동안 버튼이 「확인 중…」으로 바뀌고 잠깁니다.
3. 한국어 음성이 확인되면 **원래 누른 연습**(한 글자 · 두 글자 · 빙고)이 바로 열립니다.
4. 아직 없으면 이 화면에 그대로 남습니다.

| 버튼 | 하는 일 |
|---|---|
| **다시 확인** | 한국어 음성이 생겼는지 다시 확인. 있으면 원래 가려던 연습으로 |
| **뒤로 가기** | 말소리 탭 목록으로 |

---

## 4. 자주 묻는 질문

**Q. 설정에 «음성 데이터 설치» 메뉴가 없어요.**
Play 스토어에서 **Google 음성 서비스**(Speech Services by Google)를 설치하거나 업데이트한 뒤 다시 찾아보세요.

**Q. 한국어를 받았는데 계속 이 화면이 나와요.**
받기가 끝날 때까지 잠시 기다린 뒤 **다시 확인**을 누르세요. 그래도 안 되면 앱을 껐다 켜 보세요.

**Q. 이 화면은 안 나왔는데 연습 중에 「단어를 읽지 못했어요」가 떠요.**
음성 엔진이 잠시 응답하지 않은 경우입니다. 그 판을 끝내고 다시 시작해 보세요. 계속되면 위 방법으로 한국어 음성이 제대로 깔렸는지 확인하세요.

**Q. 목소리가 기계음이라 어색해요.**
휴대폰의 음성 읽기 기능을 쓰기 때문에 사람 목소리와 다를 수 있습니다. 같은 기기로 꾸준히 연습하면 목소리가 같아 기록을 비교하기 쉽습니다.
