# 듣기 준비 가이드

연습을 시작하기 전에 **소리가 제대로 나는지** 확인하는 화면입니다.
이어폰이 잘 연결됐는지, 무음이나 볼륨 0으로 되어 있지 않은지, 듣기 편한 크기인지를 미리 알아봅니다.

> 들어가는 곳: **다른 소리 · 말소리 · 악기 소리** 탭 목록 화면 → 오른쪽 위 🎧 **헤드폰 아이콘**
> 나가는 곳: 화면 맨 아래 **뒤로 가기** 버튼, 또는 휴대폰 뒤로가기

```
   탭 목록 화면
        │  🎧 아이콘
        ▼
   🎧 듣기 준비 화면
        │  「볼륨 조정하기」로 소리 듣기 → 휴대폰 볼륨 맞추기
        ▼
   뒤로 가기 → 탭 목록 → 연습 고르기
```

---

## 1. 화면 구성

```
┌───────────────────────────────┐
│             (🎧)               │  ← 헤드폰 그림
│           듣기 준비             │
│ ┌───────────────────────────┐ │
│ │ 🎧 이어폰이나 헤드폰을       │ │  ← ① 듣는 환경 안내
│ │    쓰는 게 좋아요            │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 🔈 더 정확하게 듣기 위한     │ │  ← ② 젠더(연결 단자) 팁
│ │    팁                        │ │
│ │ • 초저가형 C타입 젠더는 …     │ │
│ │ • 정품 젠더나 무선 이어폰 …   │ │
│ │ ┌───────────────────────┐ │ │
│ │ │     볼륨 조정하기        │ │ │  ← ③ 점검음 버튼
│ │ └───────────────────────┘ │ │
│ └───────────────────────────┘ │
│  웰니스 연습 · 병원 검사·진단을  │
│  대신하지 않아요                 │
│                               │
│ ┌───────────────────────────┐ │
│ │        뒤로 가기            │ │  ← ④ 돌아가기 (항상 화면에 고정)
│ └───────────────────────────┘ │
└───────────────────────────────┘
```

맨 위 그림은 어느 탭에서 열어도 🎧 헤드폰입니다. 내용도 세 탭 모두 같습니다.

---

## 2. 이렇게 쓰세요

1. 이어폰이나 헤드폰을 꽂습니다. (스피커로도 되지만 이어폰을 권합니다)
2. **볼륨 조정하기**를 누릅니다.
3. 「삐—」 하는 소리가 **1.5초** 동안 납니다. 버튼 글자가 「재생 중…」으로 바뀌고 막대가 움직입니다.
4. 소리가 너무 작거나 크면 **휴대폰 옆 볼륨 버튼**으로 맞추고 다시 누릅니다.
5. 편안하게 들리면 **뒤로 가기**를 눌러 연습을 고릅니다.

- 재생 중에는 버튼을 다시 눌러도 겹쳐 나지 않습니다. 끝나면 다시 누를 수 있습니다.
- 소리가 안 나면 「소리를 재생하지 못했어요. 기기 소리 설정을 확인해 주세요」가 아래에 나옵니다.
  무음 모드, 블루투스 연결, 다른 앱이 소리를 잡고 있는지 확인하세요.

---

## 3. 알아 두면 좋은 점

| 궁금한 점 | 답 |
|---|---|
| 앱이 볼륨을 대신 바꿔 주나요? | 아니요. 볼륨은 **휴대폰 볼륨 버튼**으로 직접 맞춥니다 |
| 여기서 맞춘 크기가 연습 소리 크기로 저장되나요? | 아니요. 점검음은 확인용일 뿐, 연습 소리 크기와 이어지지 않습니다. 연습은 휴대폰 볼륨 그대로 들립니다 |
| 어떤 소리가 나요? | 중간 높이의 「삐—」 소리 하나입니다. 어느 탭에서 열어도 같습니다 |
| 꼭 해야 하나요? | 아니요. 연습을 시작하는 관문이 아니라, 필요할 때 여는 안내입니다 |
| 기록이 남나요? | 아니요. 이 화면은 아무것도 저장하지 않습니다 |

### 젠더(C타입 연결 단자) 팁

- 아주 싼 C타입 젠더는 전기를 아끼려고 **소리 첫 부분을 잘라** 낼 수 있습니다.
  짧은 소리를 듣는 연습에서는 첫 부분이 잘리면 문제를 놓치기 쉽습니다.
- 휴대폰 제조사 **정품 젠더**(삼성·애플 등)나 **무선 이어폰**을 권합니다.

### 같은 환경에서 연습하세요

조용한 곳에서, **매번 같은 기기와 같은 이어폰**으로 연습하면 지난 기록과 비교하기 쉽습니다.
이어폰이나 볼륨이 바뀌면 같은 실력이어도 결과가 달라질 수 있습니다.

## 4. 자주 묻는 질문

**Q. 소리가 한쪽 귀에서만 들려요.**
이어폰이 덜 꽂혔거나 젠더 접촉이 나쁠 수 있습니다. 다시 꽂고 「볼륨 조정하기」를 눌러 확인하세요.

**Q. 소리 시작이 살짝 늦게 들리거나 앞부분이 잘려요.**
위의 젠더 팁을 보세요. 블루투스 이어폰은 연결 직후 첫 소리가 늦을 수 있으니 한두 번 더 눌러 보세요.

**Q. 이 화면이 청력 검사인가요?**
아니요. 소리가 나는지 확인하는 화면입니다. 병원 검사나 진단을 대신하지 않습니다.
