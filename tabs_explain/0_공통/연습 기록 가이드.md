# 연습 기록 가이드

연습 결과가 쌓이는 **연습 기록**(통계) 화면을 읽는 방법을 안내합니다.
어느 탭에서 열어도 **같은 화면**이고, 위쪽 칸에서 연습 종류(종목)를 골라 봅니다.
종목마다 그래프와 목록의 자세한 읽는 법은 각 연습 문서에 있습니다. 이 문서는 화면 전체의 틀을 설명합니다.

> 들어가는 곳: **다른 소리 · 말소리 · 악기 소리** 탭 목록의 오른쪽 위 📊, 또는 각 연습 첫 화면 · 결과 화면의 📊
> 나가는 곳: 화면 맨 아래 **뒤로 가기**, 또는 휴대폰 뒤로가기 → 📊를 누른 곳으로

```
   연습을 끝까지 마침
        │  기기에 기록
        ▼
   📊 연습 기록
   ├── 위: 종목 칸 7개 (좌우로 밀기)
   ├── 가운데: 고른 종목의 기록 (그래프 · 최근 목록)
   └── 맨 아래: 「○○ 기록 지우기」
```

---

## 1. 화면 구성

```
┌───────────────────────────────┐
│ 연습 기록                        │
│ 이 기기에만 저장 · 점수·청력 검사· │
│ 진단 결과 아님                   │
│                               │
│ [높낮이 비교][소리 찾기][소리 구분] …│  ← ① 종목 칸 (좌우로 밀림)
│       ▼                        │     고른 칸은 파란색 + ▼ 꼬리
│ ┌──┐                          │
│ │▮▮│ 높낮이 비교                 │  ← ② 제목줄 (종목 · 기록 수)
│ └──┘ 기록 5회                   │
│ ┌───────────────────────────┐ │
│ │   (그래프 · 최근 연습 …)     │ │  ← ③ 종목별 기록
│ └───────────────────────────┘ │
│        높낮이 비교 기록 지우기     │  ← ④ 맨 아래까지 내려야 보임
│                               │
│ ┌───────────────────────────┐ │
│ │        뒤로 가기            │ │  ← ⑤ 항상 고정
│ └───────────────────────────┘ │
└───────────────────────────────┘
```

### ① 종목 칸

| 칸 | 어떤 연습 | 탭 | 문서 |
|---|---|---|---|
| **높낮이 비교** | 소리 높낮이 | 다른 소리 | [소리 높낮이 가이드](../1_다른%20소리/소리%20높낮이%20가이드.md) 5절 |
| **소리 찾기** | 소리를 찾는 바다 | 말소리 | [소리 찾기 가이드](../2_말소리/소리%20찾기%20가이드.md) 8절 |
| **소리 구분** | 음·우·아·이·쉬·스 | 말소리 | [소리 구분 가이드](../2_말소리/소리%20구분%20가이드.md) 6절 |
| **한 글자** | 한 글자 | 말소리 | [한 글자 가이드](../2_말소리/한%20글자%20가이드.md) 6절 |
| **두 글자** | 두 글자 | 말소리 | [두 글자 가이드](../2_말소리/두%20글자%20가이드.md) 7절 |
| **문장 듣기** | 문장 듣기 | 말소리 | [문장 듣기 가이드](../2_말소리/문장%20듣기%20가이드.md) 6절 |
| **듣고 고르기** | 악기 듣고 고르기 | 악기 소리 | [듣고 고르기 가이드](../3_악기%20소리/듣고%20고르기%20가이드.md) 6절 |

- 칸은 7개라 한 화면에 다 들어가지 않습니다. **좌우로 밀어** 찾으세요.
- 칸을 누르면 그 종목 기록이 **누른 방향에서 밀려 들어오고**, 목록은 맨 위부터 다시 보입니다.

### 어느 칸이 먼저 열리나요?

📊를 누른 곳에 따라 처음 골라진 칸이 다릅니다.

| 📊를 누른 곳 | 처음 열리는 칸 |
|---|---|
| 다른 소리 탭 목록 · 소리 높낮이 화면 | 높낮이 비교 |
| 말소리 탭 목록 · 소리 찾기 화면 | 소리 찾기 |
| 소리 구분 화면 | 소리 구분 |
| 한 글자 화면 | 한 글자 |
| 두 글자 화면 | 두 글자 |
| 문장 듣기 화면 | 문장 듣기 |
| 악기 소리 탭 목록 · 듣고 고르기 화면 | 듣고 고르기 |

### ② 제목줄

지금 보고 있는 종목의 그림 · 이름과 **기록 ○회**(기기에 남은 기록 수)가 나옵니다. 기록이 없으면 「기록 없음」.

### ③ 종목별 기록

- 기록이 없으면 「**아직 ○○ 기록이 없어요**」가 나옵니다.
- 대부분의 종목은 **「맞힌 비율 변화」 그래프**(기록 2회부터)와 **「최근 연습」 목록**(최근 8판)으로 되어 있습니다.
- **소리 찾기**는 「누적 탐사 요약 · 최근 수심별 청취 상태 · 탐사 기록 이력」, **소리 구분**은 「최근 7번 · 맞힌 개수 변화」로 모양이 다릅니다.

### ④ 기록 지우기

1. 기록을 **맨 아래까지** 내리면 빨간 글자 「**○○ 기록 지우기**」가 있습니다.
2. 누르면 「**기록 삭제** — ○○ 연습 기록을 모두 지울까요? 다른 연습 기록은 그대로예요. 되돌릴 수 없어요.」가 뜹니다.
3. **삭제**를 누르면 **그 종목 기록만** 모두 지워지고 「완료 — ○○ 연습 기록을 지웠어요.」가 뜹니다.

- 다른 종목 기록은 지워지지 않습니다.
- 실수로 누르지 않게 일부러 맨 아래에 두었습니다. 되돌릴 수 없습니다.

### ⑤ 뒤로 가기

화면 맨 아래에 늘 고정되어 있습니다. 📊를 누른 곳으로 돌아갑니다.

## 2. 무엇이 기록되고 무엇이 안 되나요?

| 연습 | 기록되는 때 | 연습 기록에 |
|---|---|---|
| 소리 높낮이 | 12문항을 끝까지 | ✅ 높낮이 비교 |
| 소리 찾기 | 결과 화면까지 | ✅ 소리 찾기 |
| 소리 구분 | 여섯 소리를 다 풀었을 때 (하루 1건) | ✅ 소리 구분 |
| 한 글자 | 12 / 25문항을 끝까지 | ✅ 한 글자 |
| 두 글자 | 12문항을 끝까지 | ✅ 두 글자 |
| 문장 듣기 | 9 / 18문항을 끝까지 | ✅ 문장 듣기 |
| 듣고 고르기 | 12문항을 끝까지 | ✅ 듣고 고르기 |
| 동물 소리 게임 · 빙고 · 단어 카드 · 피아노 · 기타 · 드럼 | — | ❌ 나오지 않음 (게임 안의 별 · 미션 · 내 통계로 봄) |

- 중간에 끝낸 판은 기록되지 않습니다. 결과 화면에서만 보입니다.
- 종목마다 **최근 50판**(소리 구분은 50일)까지 보관합니다. 넘으면 오래된 것부터 지워집니다.

---

## 3. 「맞힌 비율 변화」 그래프 읽기

여러 종목이 같은 모양의 그래프를 씁니다.

```
100 ┼──────────────────────●   ← 맨 오른쪽 큰 점 = 가장 최근
 50 ┼────●────●──────●
  0 ┼────────────────────────
   10/1     기록 0~100%     10/20
   ↑ 첫 기록 날짜              ↑ 마지막 기록 날짜
```

- 가로는 **날짜 순서**, 세로는 그 판의 **맞힌 비율(0 ~ 100%)** 입니다. 위로 갈수록 많이 맞힌 판입니다.
- 날짜 간격대로 점이 놓입니다. 며칠 쉬면 그만큼 간격이 벌어집니다.
- 기록이 **12개 이하**면 판마다 점을 찍고, 더 많으면 **첫 점과 마지막 점만** 찍고 선으로 잇습니다.
- 기록이 1회뿐이면 그래프가 나오지 않습니다.

---

## 4. 알아 두면 좋은 점

- 기록은 **이 기기에만** 저장됩니다. 다른 휴대폰으로 옮겨지지 않고, 앱을 지우면 사라집니다.
- 여기 숫자는 **연습 기록**입니다. 점수 · 청력 검사 · 진단 결과가 아닙니다.
- 같은 종목이라도 **문항 수나 난이도가 다른 판**이 섞이면 그래프가 출렁입니다. 각 연습 문서의 「통계 읽기」를 함께 보세요.
- 연습을 하고 돌아와 📊를 다시 열면 최신 기록이 반영됩니다.

---

## 5. 자주 묻는 질문

**Q. 방금 한 연습이 안 보여요.**
끝까지 마친 판만 기록됩니다. 결과 화면의 저장 문구(「기기에 기록했어요」인지)를 확인하세요. 칸이 맞는지도 확인하세요.

**Q. 피아노 · 드럼 기록은 어디 있나요?**
연습 기록에는 없습니다. 피아노 · 기타는 화면 안의 **미션 창**, 동물 게임은 **별 · 클리어**, 강화학습은 **내 통계**에서 봅니다.

**Q. 기록을 하나만 지울 수 있나요?**
아니요. 「기록 지우기」는 **그 종목 전체**를 지웁니다.

**Q. 「기록을 불러오지 못했어요」가 떠요.**
뒤로 가기 후 다시 📊를 눌러 보세요. 한 종목 기록이 깨져도 다른 종목은 그대로 보입니다.
