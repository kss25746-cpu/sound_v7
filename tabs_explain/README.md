# 사운드퀘스트 화면 가이드

앱 **사운드퀘스트**의 화면을 사용자 눈높이에서 설명하는 문서 모음입니다.
하단 탭 4개와 그 안의 연습 콘텐츠마다 문서가 하나씩 있습니다. 각 문서는 화면 구성, 하는 방법, 내 동작이 기록에 남는 방식, 기록 읽는 법, 요령, 자주 묻는 질문을 담고 있습니다.

```
   앱 켜기 → (처음이면) 로그인
        │
        ▼
   ┌──────────┬──────────┬──────────┬──────────┐
   │ 다른 소리 │  말소리   │ 악기 소리 │   설정    │  ← 하단 탭
   └──────────┴──────────┴──────────┴──────────┘
     탭마다 오른쪽 위: 🎧 듣기 준비 · 📊 연습 기록
```

## 한눈에 보는 기록 위치

| 콘텐츠 | 기록을 보는 곳 |
|---|---|
| 소리 높낮이 · 소리 찾기 · 소리 구분 · 한 글자 · 두 글자 · 문장 듣기 · 듣고 고르기 | 📊 [연습 기록](0_공통/연습%20기록%20가이드.md) |
| 소리 맞추기 · 소리 순서 · 강화학습 | 동물 소리 게임 카드의 ⭐ · ✔ |
| 강화학습 동물별 정확도 | 강화학습 「내 통계 보기」 |
| 피아노 · 기타 | 화면 안의 미션 창 (난이도별 ⭐ · ✔ · 최고 점수) |
| 단어 카드 | 「○ 개 익힘」 배지 |
| 빙고 · 드럼 · 피아노 노래 연주 | 남지 않음 (결과 화면에서만) |
