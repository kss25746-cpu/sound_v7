# 기타 가이드

「악기 소리」 탭의 **기타**를 하는 방법을 안내합니다.
화면이 **가로로** 바뀌고 기타 줄 6개와 프렛(칸)이 나옵니다. 칸을 누르면 그 음이 납니다.
**훈련 모드**에서는 문제 음을 듣고 **같은 음 칸**을 찾아 누릅니다. 난이도는 4단계입니다.

> 들어가는 곳: **악기 소리** 탭 → **기타** 카드 (화면이 가로로 돌아가고 하단 탭이 숨습니다)
> 나가는 곳: 아래 제어반 왼쪽 **←** 버튼, 또는 휴대폰 뒤로가기 → 악기 소리 목록 (화면이 다시 세로로)

```
   기타 (가로 화면) — 대기: 칸을 눌러 자유 연주
        │  난이도 1단계 ~ 4단계 고르기
        ▼
   [훈련 모드] → 문제 음이 바로 남
        │  같은 음 칸 누르기
        │  정답 → 초록 칸 · 점수 +1 → 자동으로 다음 문제
        │  오답 → 빨간 칸 · 점수 −1 → 다시 들어보고 다시 누르기
        ▼
   [훈련 종료] → 대기
```

---

## 1. 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│ 1번줄(E) ║ E4  │ F4  │ F#4 │ G4  │                          │
│ 2번줄(B) ║ B3  │ C4  │ C#4 │ D4  │                          │
│ 3번줄(G) ║ G3  │ G#3 │ A3 ●│ A#3 │   ← 칸 = 누르는 자리        │
│ 4번줄(D) ║ D3  │ D#3 │ E3  │ F3  │     (맨 왼쪽 = 줄을 그냥 튕긴 음)│
│ 5번줄(A) ║ A2  │ A#2 │ B2  │ C3  │                          │
│ 6번줄(E) ║ E2  │ F2  │ F#2 │ G2  │                          │
├──────────────────────────────────────────────────────────┤
│ ←  점수 0      [1단계|2단계|3단계|4단계]   (◯)  [ 훈련 모드 ] │
│    자유 연주 중                           ↑ 미션 고리         │
└──────────────────────────────────────────────────────────┘
```

| 부분 | 하는 일 |
|---|---|
| **줄 이름** | 1번줄(가장 가는 줄, 높은 소리) ~ 6번줄(가장 굵은 줄, 낮은 소리) |
| **칸** | 누르면 그 음이 나고 줄이 떨립니다. 칸마다 **음 이름**(E2 · F#3 …)이 쓰여 있습니다 |
| **맨 왼쪽 칸** | 그 줄을 누르지 않고 튕긴 음(개방현) |
| **←** | 악기 소리 목록으로 나가기 |
| **점수 · 안내 글** | 훈련 점수와 지금 상태(「자유 연주 중」 · 「훈련 시작!」 · 「정답입니다! 🎸」 · 「틀렸습니다! 다시 들어보세요.」) |
| **1단계 ~ 4단계** | 난이도 고르기. **훈련 중에는 🔒 자물쇠로 잠겨** 바꿀 수 없습니다 |
| **미션 고리 (◯)** | 미션 진행도. 누르면 미션 창 (4절) |
| **훈련 모드** | 훈련 시작. 훈련 중에는 **다시 듣기 · 훈련 종료**로 바뀝니다 |

- 기타 줄 6개 × 4칸 = **24개 음**이 있습니다. 가장 낮은 음은 6번줄 E2, 가장 높은 음은 1번줄 G4입니다.
- 3번줄 · 4번줄 사이, 세 번째 칸 가운데의 **점**은 실제 기타의 자리 표시를 흉내 낸 장식입니다.

## 2. 난이도 — 누를 수 있는 칸이 달라집니다

고른 난이도에 따라 **누를 수 있는 칸**이 정해집니다. 나머지 칸은 흐리게 잠깁니다. **대기 화면(자유 연주)에서도 같습니다.**

| 난이도 | 문제로 나오는 음 · 누를 수 있는 칸 | 칸 수 |
|---|---|---|
| **1단계** | 여섯 줄을 **그냥 튕긴 음**만 (E2 · A2 · D3 · G3 · B3 · E4) | 6 |
| **2단계** | **샵(#)이 없는 음**만 (피아노의 흰 건반 음) | 17 |
| **3단계** | **낮은 쪽 음** E2 ~ A3 (샵 포함) | 15 |
| **4단계** | **모든 칸** | 24 |

> 💡 처음 들어오면 **1단계**가 골라져 있어 맨 왼쪽 칸만 눌립니다. 모든 칸을 자유롭게 쳐 보고 싶으면 **4단계**를 고르세요.

---

## 3. 훈련 모드 — 음 찾기

### 한 문제의 흐름

1. 난이도를 고르고 **훈련 모드**를 누르면 「훈련 시작!」과 함께 **바로 첫 문제 음**이 납니다.
2. 들은 음과 **같은 음 칸**을 누릅니다. 누르는 칸도 소리가 나므로 비교하며 찾을 수 있습니다.
3. 헷갈리면 **다시 듣기**를 누릅니다. 몇 번이든 됩니다.

| 누른 칸 | 일어나는 일 |
|---|---|
| **정답** | 칸이 **초록색**으로 빛나고 「**정답입니다! 🎸**」 · 색종이 · **점수 +1**. 약 2초 뒤 **새 문제 음이 자동으로** 납니다 |
| **오답** | 칸이 **빨간색**으로 빛나고 「**틀렸습니다! 다시 들어보세요.**」 · **점수 −1** (0 아래로는 안 내려감). **같은 문제**가 그대로 남습니다 |

- 정답을 누른 뒤 다음 문제가 나오기 전까지는 칸을 눌러도 채점하지 않습니다. (소리는 납니다)
- **훈련 종료**를 누르면 대기(자유 연주)로 돌아가고 점수는 사라집니다.
- 문제는 그 난이도의 음 중에서 무작위로 나옵니다. 이 화면의 24칸은 **모두 다른 음**이라 정답 칸은 언제나 하나입니다.

## 4. 미션 — 난이도마다 별과 클리어

제어반의 **미션 고리**가 진행도를 보여 줍니다. 누르면 「기타 미션」 창이 열립니다.

| 얻는 것 | 조건 (난이도마다) |
|---|---|
| ⭐ **별** | 그 난이도에서 **정답을 모두 합쳐 3번** 맞히기 (여러 번에 나눠도 됨) |
| ✔ **클리어** | 그 난이도에서 **한 번의 훈련 중 점수 5점** 만들기 |

### 미션 고리 읽기

| 지금 | 고리가 보여 주는 것 |
|---|---|
| 훈련 중 | 지금 난이도의 **정답 누적 / 3** (별까지) |
| 대기 중 | 지금 고른 난이도의 **최고 점수 / 5** (클리어까지) |

### 미션 창

[피아노 미션 창](피아노%20가이드.md)과 같은 모양입니다. 난이도가 4개입니다.

- 위 네 점: 1단계 → 4단계. 별을 얻은 난이도는 점이 채워집니다.
- 별 · 클리어 칸: **네 난이도를 모두** 얻어야 「획득 · 달성」
- 레벨별 기록: 난이도마다 정답 누적(고리 숫자) · 최고 점수 · 클리어 ✔
- **초기화** 버튼(창 오른쪽 위)을 누르면 **기타의** 레벨별 기록과 별 · 클리어만 지워집니다. 피아노 · 동물 소리 게임 기록은 그대로입니다. 훈련 중이었다면 훈련도 끝납니다. 되돌릴 수 없으니 주의하세요.

## 5. 내 동작이 기록에 어떻게 남나요?

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 훈련 중 정답 | 그 난이도 **정답 누적 +1**, 점수 +1, 최고 점수 갱신 |
| 훈련 중 오답 | 점수 −1. 누적은 그대로 |
| 정답 누적 3 | 그 난이도 ⭐ |
| 한 번의 훈련 중 점수 5점 | 그 난이도 ✔ |
| 자유 연주 | 남지 않음 |

- 기타 기록은 📊 연습 기록에 나오지 **않습니다.** 미션 고리와 미션 창에서만 봅니다.
- 앱을 껐다 켜도 정답 누적 · 최고 점수 · 별 · 클리어는 남습니다.

## 6. 잘 하는 요령

- **1단계**부터 시작하세요. 여섯 줄의 튕긴 소리만 구별하면 됩니다. 굵은 줄일수록 낮은 소리입니다.
- 2단계부터는 칸이 많아집니다. 문제 음이 **높은지 낮은지** 먼저 가늠하고, 위쪽 줄(높은 소리)과 아래쪽 줄(낮은 소리) 중 어디서 찾을지 정하세요.
- 같은 줄에서는 **오른쪽 칸으로 갈수록 높아집니다.** 비슷한 칸을 왼쪽 · 오른쪽으로 눌러 보며 맞춰 가세요.
- 틀리면 점수가 깎이니, 헷갈릴 때는 먼저 **다시 듣기**로 충분히 들으세요.
- 피아노 건반이 더 편하면 [피아노](피아노%20가이드.md) 훈련 모드로 같은 연습을 할 수 있습니다.

## 7. 자주 묻는 질문

**Q. 칸이 흐려서 안 눌려요.**
지금 고른 난이도에서 쓰지 않는 칸입니다. 대기 화면에서도 난이도를 따릅니다. **4단계**를 고르면 모든 칸이 눌립니다.

**Q. 훈련 중에 난이도를 못 바꿔요.**
훈련 중에는 난이도가 🔒 잠깁니다. **훈련 종료** 후 바꾸세요.

**Q. 휴대폰 뒤로가기를 눌렀더니 바로 목록으로 나갔어요.**
기타 화면에서 휴대폰 뒤로가기는 **악기 소리 목록으로 바로** 나갑니다. (미션 창이 떠 있을 때는 그 창만 닫힙니다) 훈련만 끝내려면 **훈련 종료**를 누르세요.

**Q. 처음 누르는 칸 소리가 조금 늦어요.**
칸 소리를 필요할 때 불러오기 때문에, 처음 누르는 음이나 한동안 안 누른 음은 잠깐 늦을 수 있습니다.
