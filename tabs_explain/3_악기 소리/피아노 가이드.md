# 피아노 가이드

「악기 소리」 탭의 **피아노**를 하는 방법을 안내합니다.
화면이 **가로로** 바뀌고 피아노 건반이 펼쳐집니다. 피아노에서 할 수 있는 것은 세 가지입니다.

| 할 수 있는 것 | 하는 일 |
|---|---|
| **그냥 치기** (대기 화면) | 건반을 마음대로 눌러 소리를 들어 봅니다 |
| **훈련 모드** | 문제 음을 듣고, 같은 음 건반을 찾아 누릅니다. 난이도 5단계 |
| **자유 모드** (노래 연주) | 위에서 내려오는 음표에 맞춰 건반을 눌러 노래를 칩니다 |

> 들어가는 곳: **악기 소리** 탭 → **피아노** 카드 (화면이 가로로 돌아가고 하단 탭이 숨습니다)
> 나가는 곳: 아래 제어반 왼쪽 **←** 버튼, 또는 휴대폰 뒤로가기 → 악기 소리 목록 (화면이 다시 세로로)

```
   피아노 (가로 화면) — 대기: 건반 자유롭게 치기
        │
        ├── [◉ 훈련 모드] → 난이도 고르기 → [▶ 문제 재생]
        │        │  음 듣기 → 같은 건반 누르기
        │        │  정답 → 점수 +1 → 자동으로 다음 문제
        │        │  오답 → 점수 −1 → 다시 들어보고 다시 누르기
        │        └── [■ 훈련 종료] → 대기
        │
        └── [▶ 자유 모드] → 고른 노래 연주
                 │  3·2·1·Start → 내려오는 음표에 맞춰 누르기
                 ▼
              곡 끝 → 「한 번 더 연습할까요?」 → 리플레이 / 결과 보기
```

## 1. 대기 화면 (그냥 치기)

```
┌──────────────────────────────────────────────────────────┐
│                                                     (❔)  │ ← 미션
│  ┌──┬─┬──┬─┬──┬──┬─┬──┬─┬──┬─┬──┬──┬─┬──┬─┬──┬──┐       │
│  │  │█│  │█│  │  │█│  │█│  │█│  │  │█│  │█│  │  │ …     │ ← 건반
│  │  └┬┘  └┬┘  │  └┬┘  └┬┘  └┬┘  │  └┬┘  └┬┘  │  │       │   (C3 ~ D5)
│  │C3 │ D3 │E3 │F3 │ G3 │ A3 │B3 │C4 │ D4 │E4 │ …       │
│  └───┴────┴───┴───┴────┴────┴───┴───┴────┴───┴──        │
├──────────────────────────────────────────────────────────┤
│ ←  반짝반짝 작은별 ▲▼  설정 ①②③④⑤  [느림|보통] [5음|8음]  │ ← 제어반
│                          [ ▶ 자유 모드 ]  [ ◉ 훈련 모드 ]   │
└──────────────────────────────────────────────────────────┘
```

- 건반을 누르면 그 음이 나고, 누른 자리에서 빛 알갱이가 퍼집니다.
- 건반에는 **음 이름**(C3 · D3 …)이 쓰여 있습니다. C4가 「가온 도」입니다.
- 대기 화면 건반은 늘 **C3 ~ D5** 범위입니다.

### 제어반

| 부분 | 하는 일 |
|---|---|
| **←** | 악기 소리 목록으로 나가기 |
| **곡 제목 ▲ ▼** | 자유 모드로 칠 노래 고르기. ▲ 이전 곡 · ▼ 다음 곡 |
| **설정 ① ~ ⑤** | **음원**(피아노 소리 색깔) 고르기. 3번이 기본. 고른 값은 저장됩니다 |
| **느림 · 보통** | 자유 모드 노래 속도 |
| **5음 · 8음** | 자유 모드 노래 묶음. 바꾸면 그 묶음의 첫 곡이 골라집니다 |
| **▶ 자유 모드** | 고른 노래 연주 시작 (5절) |
| **◉ 훈련 모드** | 음 찾기 훈련 시작 (2절) |

- **음원 ① ~ ⑤**는 소리 크기는 같고 **밝기(음색)만** 다릅니다. 숫자가 클수록 대체로 밝게 들립니다. 편하게 들리는 것을 고르세요.

## 2. 훈련 모드 — 음 찾기

**◉ 훈련 모드**를 누르면 제어반이 바뀝니다.

```
├──────────────────────────────────────────────────────────┤
│ ←  점수 3   정답!          설정 ①②③④⑤                     │
│            [입문|초급|중급|상급|전문]                      │ ← 난이도
│                          [ ↻ 다시 듣기 ]  [ ■ 훈련 종료 ]   │
└──────────────────────────────────────────────────────────┘
```

### 한 문제의 흐름

1. 난이도를 고르고 **▶ 문제 재생**을 누릅니다. 피아노 음 하나가 납니다.
2. 버튼이 **↻ 다시 듣기**로 바뀝니다. 몇 번이든 다시 들을 수 있습니다.
3. 들은 음과 **같은 건반**을 누릅니다. (누르는 건반도 소리가 나므로 비교하며 찾을 수 있습니다)

| 누른 건반 | 일어나는 일 |
|---|---|
| **정답** | 「**정답!**」 · 색종이가 터지고 **점수 +1**. 약 2초 뒤 「다음 문제」와 함께 **새 문제 음이 자동으로** 납니다 |
| **오답** | 「**오답! 다시 들어보세요.**」 · **점수 −1** (0 아래로는 안 내려감). **같은 문제**가 그대로 남아 다시 찾을 수 있습니다 |

- 정답을 누른 뒤 다음 문제가 나오기 전까지는 건반을 눌러도 채점하지 않습니다. (소리는 납니다)
- 점수 **5점**이 처음 되면 화면 가운데에 「★ **미션 성공!** ★ 자유롭게 계속 도전해보세요!」가 잠깐 뜹니다. (훈련 모드 한 번에 한 번)
- **■ 훈련 종료**를 누르면 대기 화면으로 돌아갑니다.

### 난이도

| 난이도 | 문제로 나오는 음 | 건반 화면 |
|---|---|---|
| **입문** | C3 ~ C4 흰 건반 8개 (도레미파솔라시도 한 옥타브) | 8건반만 |
| **초급** | C3 ~ C5 흰 건반 15개 (두 옥타브) | 15건반 |
| **중급** | C3 ~ B4 흰 · 검은 건반 모두 (24음) | 흰 건반 16개 넓이 |
| **상급** | C1 ~ D#5 **모든 건반** (52음) | 16건반씩 보이고 **옥타브를 옮겨 가며** 찾음 |
| **전문** | **검은 건반만** (전 범위) | 상급과 같이 옮겨 가며 찾음 |

- 문제로 나오지 않는 건반은 **흐리게 잠겨** 누를 수 없습니다. (예: 전문에서는 흰 건반이 잠김)
- 난이도를 바꾸면 지금 문제가 지워지고 **점수가 0**이 됩니다. 「난이도가 ○단계로 변경되었습니다. [문제 재생]을 누르세요.」
- 음원(① ~ ⑤)을 바꾸면 지금 문제가 지워지지만 점수는 그대로입니다.

### 상급 · 전문 — 옥타브 옮기기

```
│  ( ◀ 옥타브 낮춤 )   [▁▁▁▁▁▁▁▁▁▁•▁▁▁▁▁▁▁]   ( 옥타브 높임 ▶ ) │
│                       ↑ 미니 건반 지도                        │
```

- 건반 위에 **◀ 옥타브 낮춤 · 옥타브 높임 ▶** 버튼과 **미니 건반 지도**가 생깁니다.
- 한 번에 흰 건반 16개만 보입니다. 낮은 쪽(C1 ~)과 높은 쪽(C3 ~ D5) 두 화면을 오갑니다.
- 미니 건반 지도를 눌러도 그쪽으로 옮겨집니다. 지도 위 **빛나는 테두리 상자**가 지금 보이는 범위입니다.
- 훈련 중에는 미니 건반 지도에 **문제 음 자리를 알려 주는 점**이 찍힙니다.
- **상급**에서 문제 음이 지금 화면 밖에 있으면 그쪽 **옥타브 버튼이 깜빡이며** 알려 줍니다.

## 3. 미션 (❔) — 난이도마다 별과 클리어

오른쪽 위 **❔**를 누르면 「피아노 미션」 창이 열립니다. 피아노는 **난이도마다** 별과 클리어가 따로 있습니다.

| 얻는 것 | 조건 (난이도마다) |
|---|---|
| ⭐ **별** | 그 난이도에서 **정답을 모두 합쳐 3번** 맞히기 (여러 번에 나눠도 됨) |
| ✔ **클리어** | 그 난이도에서 **한 번의 훈련 중 점수 5점** 만들기 |

```
┌──────────────────────────────────────┐
│ 피아노 미션                    초기화 │
│  ●───●───○───○───○                    │ ← 5단계 진행 (채운 점 = 별 얻음)
│ [★ 별 · 미획득] [○ 클리어 · 미달성]    │ ← 5단계 모두 얻어야 「획득」
│ 레벨별 기록                            │
│  (3) 입문   최고 6점   ✔              │ ← 고리 = 정답 누적 (3이면 별)
│  (2) 초급   최고 2점                   │
│  (0) 중급   최고 0점                   │
│          ⋮                            │
│              [ 닫기 ]                  │
└──────────────────────────────────────┘
```

| 표시 | 뜻 |
|---|---|
| 위의 다섯 점 | 입문 → 전문. 별을 얻은 난이도는 점이 채워지고, 이웃한 두 점이 모두 채워지면 그 사이 선이 밝아집니다 |
| 별 · 클리어 칸 | **다섯 난이도를 모두** 얻어야 「획득 · 달성」으로 바뀝니다 |
| 레벨별 기록의 고리 숫자 | 그 난이도에서 지금까지 **맞힌 정답 수(누적)**. 3이 되면 고리가 차고 ★ |
| 최고 ○점 | 그 난이도에서 한 번의 훈련 중 가장 높았던 점수 |
| ✔ | 그 난이도 클리어 |

- ❔ 물음표 색: 회색(아무것도 없음) → 구리색(별을 하나라도 얻음) → 금색(**모두** 클리어)
- **초기화** 버튼(창 오른쪽 위)을 누르면 **피아노의** 레벨별 기록과 별 · 클리어만 지워집니다. 기타 · 동물 소리 게임 기록은 그대로입니다. 되돌릴 수 없으니 주의하세요.

## 4. 내 동작이 기록에 어떻게 남나요?

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 훈련 모드에서 정답 | 그 난이도 **정답 누적 +1**. 점수 +1. 최고 점수 갱신 |
| 훈련 모드에서 오답 | 점수 −1. 누적은 그대로 |
| 정답 누적 3이 됐다 | 그 난이도 ⭐ |
| 한 번의 훈련 중 점수 5점 | 그 난이도 ✔ |
| 음원(① ~ ⑤)을 골랐다 | 다음에 들어와도 그 음원 |
| 자유 모드(노래 연주) | **남지 않음** (결과 화면에서만 보임) |
| 그냥 치기 | 남지 않음 |

- 피아노 기록은 📊 연습 기록에 나오지 **않습니다.** 미션 창에서만 봅니다.
- 점수는 훈련 모드를 시작할 때, 난이도를 바꿀 때 0으로 돌아갑니다.

## 5. 자유 모드 — 노래 연주

대기 화면에서 노래를 고르고 **▶ 자유 모드**를 누르면 노래 연주가 시작됩니다.

### 노래 목록

| 묶음 | 쓰는 건반 | 노래 |
|---|---|---|
| **5음** | 도 · 레 · 미 · 솔 · 라 (5개) | 핫 크로스 번 · 메리의 어린 양 · 링 어라운드 더 로지 · 아리랑 |
| **8음** | 도 · 레 · 미 · 파 · 솔 · 라 · 시 · 도 (8개) | 나비야 · 반짝반짝 작은별 · 환희의 송가 · 성자의 행진 |

### 연주 화면

```
┌──────────────────────────────────────────────────────────┐
│ ✕ 종료                  12 / 30                     (❔)  │ ← 맞은 음 / 전체 음
│    │    │ ▉  │    │    │                                  │
│    │ ▉  │    │    │ ▉  │   ← 음표가 위에서 내려옴           │
│ ───┼────┼────┼────┼────┼───  ← 판정선                     │
│ ┌────┬────┬────┬────┬────┐                                │
│ │ 도 │ 레 │ 미 │ 솔 │ 라 │  ← 그 노래에 쓰는 건반만 (도레미로 표시)│
│ └────┴────┴────┴────┴────┘                                │
└──────────────────────────────────────────────────────────┘
```

1. 화면 가운데에 **3 · 2 · 1 · Start**가 나옵니다. 숫자를 세는 동안 음표가 내려오기 시작합니다.
2. 음표가 **판정선**에 닿을 때 그 줄 아래 건반을 누릅니다.
   - 판정은 넉넉합니다. 판정선 **앞뒤 0.5초** 안에 **맞는 건반**을 누르면 맞음입니다. 박자보다 **맞는 음**이 중요합니다.
   - 맞으면 그 자리에서 빛이 터지고 휴대폰이 살짝 떨립니다. 위 숫자(맞은 음)가 1 오릅니다.
   - 누르지 못하고 지나가면 틀림으로 처리됩니다.
3. 건반은 그 노래에 쓰는 **5개 또는 8개만** 나오고, **도 · 레 · 미**로 표시됩니다. 줄마다 색이 다릅니다.
4. 왼쪽 위 **✕ 종료**를 누르면 바로 멈추고 대기 화면으로 돌아갑니다.

### 곡이 끝나면

먼저 「**(곡 제목) — 한 번 더 연습할까요?**」 창이 뜹니다.

| 버튼 | 하는 일 |
|---|---|
| **리플레이** | 같은 곡을 바로 다시 연주 |
| **결과 보기** | 결과 창 열기 |
| 휴대폰 뒤로가기 | 결과를 보지 않고 대기 화면으로 |

결과 창:

| 표시 | 뜻 |
|---|---|
| **클리어!** / **연습 필요** | 아래 조건을 넘었는지 |
| 맞은 음 ○ / ○ | 맞은 음 수 / 곡 전체 음 수 |
| 맞음 · 틀림 | 맞은 음 수 · 놓친 음 수 |
| 정확도 ○% | 맞은 음 ÷ 전체 음 |

**클리어 조건**: 정확도 **5음 곡 70% 이상 · 8음 곡 80% 이상**, 그리고 **틀림이 전체 음의 20% 이하(소수점 버림)**.

- 노래 연주 결과는 **저장되지 않고**, 별 · 클리어와도 상관없습니다.
- **느림**을 고르면 같은 곡을 더 천천히 연주합니다. 처음 치는 곡은 느림으로 시작하세요.

## 6. 잘 하는 요령

### 훈련 모드

- **입문 → 초급 → 중급** 순서로 올라가세요. 입문에서 클리어(5점)를 하면 다음 단계로.
- 문제 음을 듣고 바로 누르지 말고, **비슷하다고 생각하는 건반 두세 개를 눌러 비교**해 보세요. 누르는 건반도 소리가 나므로 귀로 맞춰 갈 수 있습니다. 단, 틀리게 누르면 점수가 1 깎입니다.
- 헷갈리면 **↻ 다시 듣기**를 여러 번 쓰세요. 점수에 영향이 없습니다.
- 높은지 낮은지 감이 안 오면 「다른 소리」 탭의 [소리 높낮이](../1_다른%20소리/소리%20높낮이%20가이드.md)로 먼저 연습해 보세요.

### 자유 모드

- 처음에는 **5음 · 느림**으로 시작하세요.
- 건반 색과 음표 줄 색이 같습니다. 색을 보며 누르면 쉽습니다.
- 익숙해지면 소리를 들으며 **어떤 음이 나오는지 귀로 따라가** 보세요.

## 7. 자주 묻는 질문

**Q. 화면이 가로로 바뀌었어요.**
피아노와 기타는 건반·줄이 넓어야 해서 가로 화면입니다. 나가면 다시 세로로 돌아갑니다. 하단 탭도 가로 화면에서는 숨습니다.

**Q. 건반이 흐려서 안 눌려요.**
훈련 모드의 그 난이도에서 문제로 나오지 않는 건반입니다. 난이도를 바꾸면 눌리는 건반이 달라집니다.

**Q. 처음 누르는 건반 소리가 조금 늦게 나요.**
건반 소리를 필요할 때 불러오기 때문에, 처음 누르는 음이나 한동안 안 누른 음은 잠깐 늦을 수 있습니다.

**Q. 별을 얻었는데 미션 창 위쪽 별 칸은 「미획득」이에요.**
위쪽 별 · 클리어 칸은 **다섯 난이도를 모두** 얻어야 바뀝니다. 난이도별로 얻은 것은 아래 「레벨별 기록」과 위쪽 다섯 점에서 확인하세요.

**Q. 훈련이나 노래 연주 중에 휴대폰 뒤로가기를 눌렀더니 목록으로 나갔어요.**
피아노 화면에서는 휴대폰 뒤로가기가 **악기 소리 목록으로 바로** 나갑니다. 확인 창이 없습니다. (곡 끝 안내 · 결과 · 미션 창이 떠 있을 때는 그 창만 닫힙니다) 훈련만 끝내려면 **■ 훈련 종료**, 노래만 멈추려면 **✕ 종료**를 누르세요.

**Q. 노래 연주 기록은 어디서 보나요?**
저장되지 않습니다. 곡이 끝났을 때 **결과 보기**로만 확인할 수 있습니다.
