# 듣고 고르기 가이드

「악기 소리」 탭의 **듣고 고르기**를 하는 방법을 안내합니다.
악기 소리 하나를 듣고 **피아노 · 기타 · 바이올린 · 플루트** 중 어느 악기였는지 고르는 연습입니다.
소리 높이가 매번 달라지므로, 높낮이가 아니라 **소리의 결(음색)** 을 듣고 골라야 합니다.
한 판은 **12문항**이고, 끝까지 풀면 맞힌 비율이 기록됩니다.

> 들어가는 곳: **악기 소리** 탭 → **듣고 고르기** 카드
> 나가는 곳: 첫 화면·결과 화면의 **뒤로 가기**, 또는 휴대폰 뒤로가기

```
   첫 화면 「이렇게 연습해요」 + 악기 4개 미리보기 → 시작
        │
        ▼
   악기 소리 한 음 듣기 → 악기 4개 중 고르기 (다시 듣기 가능)
        │  맞았어요 / 아쉬워요 · 정답은 ○ → 다음   ── 12번
        ▼
   「12개 중 ○개를 맞혔어요」 + 악기별 맞힌 수 + 약한 소리
        │  기기에 기록
        ▼
   📊 통계 「듣고 고르기」에서 변화 보기
```

---

## 1. 네 악기

| 악기 | 화면 설명 | 소리의 결 |
|---|---|---|
| **피아노** | 두드리는 건반 | 톡 치고 나서 점점 사그라지는 소리 |
| **기타** | 퉁기는 줄 | 줄을 튕기는 순간 소리가 나고 금방 잦아드는 소리 |
| **바이올린** | 활로 켜는 줄 | 활로 문질러 길게 이어지는, 약간 거친 소리 |
| **플루트** | 입으로 부는 관 | 숨결이 섞인 부드럽고 맑은 소리 |

- 네 악기는 **치는 · 퉁기는 · 켜는 · 부는** 악기에서 하나씩 골랐습니다. 비슷한 악기끼리 섞여 있지 않습니다.
- 소리는 **실제 악기 연주를 녹음**한 것입니다.
- 높이는 「솔 · 라 · 도 · 미」(G4 · A4 · C5 · E5) 네 음 중 하나로 나옵니다. **네 악기 모두 같은 네 음**을 쓰므로 높이로는 악기를 알 수 없습니다.

## 3. 한 문항의 흐름

```
┌───────────────────────────────┐
│ 듣고 고르기                     │
│ ████████░░░░░░░░░░░░░░░░░░░░  │  ← 진행 막대 (12칸)
│             ▮▮▮                │
│        들은 악기를 고르세요        │
│  ┌───────────┐ ┌───────────┐  │
│  │  (그림)    │ │  (그림)    │  │
│  │  피아노    │ │   기타     │  │  ← 악기 4개
│  │두드리는 건반│ │ 퉁기는 줄  │  │     (자리는 늘 같음)
│  └───────────┘ └───────────┘  │
│  ┌───────────┐ ┌───────────┐  │
│  │ 바이올린   │ │  플루트    │  │
│  │활로 켜는 줄│ │입으로 부는 관│  │
│  └───────────┘ └───────────┘  │
│     [ 다시 듣기 ]  [ 중지 ]      │
└───────────────────────────────┘
```

1. **시작**을 누르면 「곧 들어요…」가 잠깐(0.7초) 나온 뒤 첫 소리가 납니다.
2. 소리가 나는 동안은 「듣는 중… 소리가 끝난 뒤 고르세요」이고 보기가 잠겨 있습니다.
3. 끝나면 「들은 악기를 고르세요」. 악기 하나를 누릅니다.
4. 결과가 나옵니다.
   - 맞았으면 「**맞았어요**」
   - 틀렸으면 「**아쉬워요 · 정답은 ○○**」 그리고 **정답 칸에 파란 테두리**
5. **다음**을 누르면 다음 소리가 납니다.

### 다시 듣기

고르는 중에는 아래에 **다시 듣기** 버튼이 있습니다. 누르면 같은 소리를 바로 다시 들려줍니다. (몇 번이든 됩니다)
말소리 탭의 단어·문장 연습과 달리, 이 연습은 **다시 들어도 됩니다.**

### 문제는 이렇게 나옵니다

- **12문항 = 네 악기 × 3번씩**입니다.
- **같은 악기가 연달아 나오지 않습니다.**
- 한 악기의 세 번은 **서로 다른 높이**로 나옵니다.
- 악기 4칸의 **자리는 늘 같습니다.** (왼쪽 위 피아노 · 오른쪽 위 기타 · 왼쪽 아래 바이올린 · 오른쪽 아래 플루트)

### 중간에 멈추고 싶을 때

| 지금 상태 | 버튼 | 일어나는 일 |
|---|---|---|
| 소리 나는 중 / 고르는 중 | **중지** | 소리가 바로 멈추고 「연습 끝내기 — 여기서 끝낼까요?」. **취소**하면 그 소리를 다시 들려줍니다 |
| 답을 고른 뒤 | **끝내기** | 같은 확인 창 |

- 확인 창에서 **끝내기** → 결과 화면
- 휴대폰 뒤로가기는 진행 중에 같은 확인 창을 띄웁니다.
- 앱을 내리거나 전화가 오면 소리가 끊기고 진행이 멈춥니다.

## 4. 결과 화면

```
┌───────────────────────────────┐
│ 듣고 고르기             🎧  📊  │
│   ✓ 오늘 연습 끝                 │
│ ┌───────────────────────────┐ │
│ │ 12개 중 9개를 맞혔어요       │ │  ← ① 맞힌 수
│ │ 약한 소리  (바이올린 그림)    │ │  ← ② 가장 많이 틀린 악기
│ │ 피아노   3/3                │ │  ← ③ 악기별 맞힌 수
│ │ 기타     2/3                │ │
│ │ 바이올린 1/3                │ │
│ │ 플루트   3/3                │ │
│ │ 연습 기록이에요. 청력 검사·   │ │
│ │ 진단 결과가 아니에요.         │ │
│ │ 기기에 기록했어요            │ │
│ └───────────────────────────┘ │
│ [다시 연습] [뒤로 가기] [처음으로]│
└───────────────────────────────┘
```

| 부분 | 읽는 법 |
|---|---|
| ① 맞힌 수 | 「12개 중 ○개를 맞혔어요」 |
| ② 약한 소리 | 이번 판에서 **가장 많이 틀린 악기** 그림. 여럿이 같으면 함께 나옵니다. 다 맞혔거나 네 악기를 똑같이 틀렸으면 나오지 않습니다 |
| ③ 악기별 맞힌 수 | 악기마다 3번 중 몇 번 맞혔는지 |

| 저장 문구 | 뜻 |
|---|---|
| **기기에 기록했어요** | 12문항을 끝까지 풀어 기록했습니다 |
| 「○개 중 ○개를 맞혔어요. 12개를 다 고르지 않아 기록에는 안 남겼어요」 | 중간에 끝냈습니다 |
| 연습이 짧아서 기록할 내용이 없어요 | 한 문항도 고르지 않았습니다 |

| 버튼 | 하는 일 |
|---|---|
| **다시 연습** | 바로 새 판 |
| **뒤로 가기** | 악기 소리 탭 목록으로 |
| **처음으로** | 첫 화면으로 |

## 5. 내 동작이 기록에 어떻게 남나요?

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 12문항을 끝까지 풀었다 | 한 판 기록 1개: 날짜·시각, 맞힌 수/12, 맞힌 비율 |
| 중간에 끝냈다 | **남지 않음** |
| 다시 듣기를 눌렀다 | 남지 않음. 점수에 불리하지 않습니다 |
| 악기별 맞힌 수 · 약한 소리 | **결과 화면에서만** 보입니다. 기록에는 들어가지 않습니다 |

- 맞힌 비율은 반올림한 정수입니다. 예: 9/12 = 75%
- 기록은 **최근 50판**까지 보관됩니다.

## 6. 통계 「듣고 고르기」 읽기

📊 연습 기록의 **듣고 고르기** 칸은 [한 글자](../2_말소리/한%20글자%20가이드.md)와 같은 모양입니다.

| 카드 | 읽는 법 |
|---|---|
| **맞힌 비율 변화** | 기록 2회부터. 판마다 맞힌 비율을 날짜 순서로 잇는 그래프. 위가 많이 맞힘 |
| **최근 연습** | 최근 8판. `10/20 14:05   9/12 · 약 75%` = 그 날짜·시각에 12문항 중 9개 맞힘 |

- 악기별 결과는 통계에 남지 않습니다. 어떤 악기가 약한지는 **매 판 결과 화면**에서 확인하세요.
- 그래프는 보관된 판(최대 50판)을 **모두** 그립니다. 최근 연습처럼 8판으로 자르지 않습니다.
- 가로축은 판 번호가 아니라 **연습한 시각**입니다. 같은 날 여러 판을 하면 점이 붙고, 며칠 쉬면 간격이 벌어집니다.
- 12판까지는 판마다 점이 찍힙니다. 그보다 많으면 첫 판과 최근 판에만 점이 찍히고 나머지는 선으로만 이어집니다.
- 50판을 넘으면 가장 오래된 판부터 지워지므로 그래프 왼쪽 끝이 앞으로 밀려납니다.

## 7. 잘 하는 요령

- 소리의 **시작**에 집중하세요. 피아노는 「톡」, 기타는 「팅」 하고 시작하고, 바이올린·플루트는 부드럽게 시작해 이어집니다.
- 소리의 **끝**도 들어 보세요. 피아노·기타는 점점 사그라지고, 바이올린·플루트는 고르게 이어지다 멈춥니다.
- 바이올린과 플루트가 헷갈리면: 바이올린은 줄이 떨리는 **거친 결**, 플루트는 **바람이 섞인 맑은 결**입니다.
- 헷갈리면 **다시 듣기**를 여러 번 써도 됩니다.
- 실제 악기 소리를 더 익히고 싶다면 같은 탭의 [피아노](피아노%20가이드.md) · [기타](기타%20가이드.md)를 직접 쳐 보세요.

## 8. 자주 묻는 질문

**Q. 같은 악기인데 소리 높이가 달라요.**
일부러 그렇게 냅니다. 높이를 외워서 맞히지 않고 소리의 결로 고르도록 하기 위해서입니다.

**Q. 악기별 결과를 통계에서 보고 싶어요.**
통계에는 전체 맞힌 비율만 남습니다. 악기별 결과는 결과 화면에서만 보입니다.

**Q. 다시 듣기를 많이 쓰면 기록에 불리한가요?**
아니요. 다시 들은 횟수는 기록하지 않습니다.

**Q. 이 결과가 청력 검사인가요?**
아니요. 연습 기록입니다. 병원 검사나 진단을 대신하지 않습니다.
