# 드럼 가이드

「악기 소리」 탭의 **드럼**을 하는 방법을 안내합니다.
드럼 세트 위의 **캐릭터**를 악기로 옮기면 그 악기 소리가 납니다.
**연주모드**에서 악기 소리를 익히고, **듣기연습**(퀴즈모드)에서 들린 악기에 캐릭터를 가져가 맞힙니다.

> 들어가는 곳: **악기 소리** 탭 → **드럼** 카드 (세로 화면 그대로)
> 나가는 곳: 왼쪽 위 **←** 버튼, 또는 휴대폰 뒤로가기 → 악기 소리 목록

```
   연주모드 — 캐릭터를 악기로 옮기며 소리 듣기
        │  좌우로 밀어 악기 2·3·4·5개 판 고르기 (1/4 ~ 4/4)
        │  ⚙ 문제 수 고르기 (5 · 10 · 15 · 20)
        ▼
   [👂 듣기연습] → 2 · 1 카운트다운 → 퀴즈모드
        │  악기 소리 듣기 → 캐릭터를 그 악기로 끌어 놓기
        │  ⭕ 정답 / ❌ 오답 → 1초 뒤 다음 문제
        ▼
   마지막 문제 뒤 결과 (완벽해요! · 잘했어요! · 아쉬워요!) → 다시 하기 / 나가기
```

---

## 1. 다섯 악기

| 악기 | 화면 설명 | 소리 |
|---|---|---|
| **킥드럼** | 둔탁하고 깊은 저음 | 발로 밟는 큰북. 가장 낮은 「쿵」 |
| **스네어** | 날카롭게 튀는 소리 | 「탁」 하고 튀는 작은북 |
| **하이햇** | 짧고 선명한 금속음 | 「칙」 하는 짧은 쇳소리 |
| **심벌** | 긴 울림의 금속음 | 「챙—」 하고 길게 울리는 쇳소리 |
| **탐** | 중음역의 둥근 소리 | 「둥」 하는 중간 높이 북 |

> **주의:** 킥드럼은 소리가 거의 다 낮은 음이라 **휴대폰 스피커로는 잘 안 들립니다.** 이어폰이나 헤드폰을 쓰세요.

---

## 2. 화면 구성 (연주모드)

```
┌───────────────────────────────┐
│ ←   연주모드     ⚙ 5문제  👂 듣기연습 │  ← 머리줄
│                               │
│            [ 스네어 ]           │  ← 지금 캐릭터가 있는 악기 이름
│                               │
│      ┌─────────────────┐      │
│      │  (드럼 세트 그림) │      │
│      │   ♪        ♪     │      │  ← ♪ 표시 = 악기 자리
│      │       🙂          │      │     (주황 / 지금 악기는 초록)
│      │   ♪        ♪     │      │  ← 🙂 캐릭터 (끌어서 옮기기)
│      └─────────────────┘      │
│                               │
│   (◀ 스틱)    1/4    (스틱 ▶)   │  ← 이전 · 다음 악기 / 판 번호
└───────────────────────────────┘
```

### 악기 판 (1/4 ~ 4/4)

드럼 세트는 **악기 수가 다른 판 4개**가 있습니다. 화면을 **좌우로 밀어** 판을 바꿉니다.

| 판 | 악기 |
|---|---|
| 1/4 | 2개 — 스네어 · 킥드럼 |
| 2/4 | 3개 — 스네어 · 하이햇 · 킥드럼 |
| 3/4 | 4개 — 스네어 · 하이햇 · 심벌 · 킥드럼 |
| 4/4 | 5개 — 스네어 · 하이햇 · 탐 · 심벌 · 킥드럼 |

### 소리 내는 법

| 이렇게 하면 | 일어나는 일 |
|---|---|
| 캐릭터를 **끌어서** 악기 가까이 놓기 | 가장 가까운 악기 자리에 **딱 붙고** 그 악기 소리가 납니다. 휴대폰이 살짝 떨립니다 |
| 아래 **▶ 스틱** 버튼 | 캐릭터가 **다음 악기**로 옮겨 가며 소리가 납니다 |
| 아래 **◀ 스틱** 버튼 | 캐릭터가 **이전 악기**로 옮겨 가며 소리가 납니다 |

- 캐릭터가 있는 악기는 ♪ 표시가 **초록색**이 되고, 위에 **악기 이름**이 나옵니다.
- 악기에서 먼 빈 곳에 놓으면 그 자리에 머물고 소리는 나지 않습니다.

## 3. 듣기연습 (퀴즈모드)

### 시작하기

1. 원하는 **판**(악기 수)으로 넘겨 둡니다. 퀴즈는 **지금 보이는 판의 악기들**로 냅니다.
2. 머리줄의 **⚙ ○문제**를 눌러 문제 수를 고릅니다. (5 · 10 · 15 · 20, 처음에는 5)
   - 아래 바깥을 누르면 고르기 칸이 닫힙니다.
3. **👂 듣기연습**을 누릅니다.

### 한 문제의 흐름

```
┌───────────────────────────────┐
│ ←   퀴즈모드 · 2/5 회   ✕ 그만하기 │
│   들린 악기에 캐릭터를 가져가세요  │  ← 첫 문제에만
│      ┌─────────────────┐      │
│      │  (드럼 세트 그림) │      │
│      │   ♪    🙂   ♪    │      │
│      └─────────────────┘      │
│     ( ↻ )                      │  ← 다시 듣기
└───────────────────────────────┘
```

1. 머리줄이 「**퀴즈모드 · 1/5 회**」로 바뀌고, 캐릭터가 처음 자리로 돌아갑니다.
2. 화면 가운데에 **2 · 1** 카운트다운이 나온 뒤 **첫 문제 악기 소리**가 납니다.
3. 들은 악기 자리로 **캐릭터를 끌어다 놓습니다.** 놓는 순간 그 악기가 답으로 제출되고 소리도 납니다.
4. 화면 가운데에 **⭕**(정답) 또는 **❌**(오답)가 잠깐 나옵니다.
5. **1초 뒤** 캐릭터가 비켜 서고 **다음 문제 소리**가 자동으로 납니다.
6. 정한 문제 수를 다 풀면 결과 창이 뜹니다.

- 왼쪽 아래 버튼이 **↻ 다시 듣기**로 바뀝니다. 문제 소리를 다시 들을 수 있습니다. (⭕ · ❌가 떠 있는 동안에는 흐리게 잠김)
- 퀴즈 중에는 **▶ 스틱 버튼이 사라집니다.** 답은 캐릭터를 **끌어서**만 냅니다.
- 퀴즈 중에는 위의 **악기 이름이 숨습니다.** (정답이 보이지 않게)
- 시간 제한은 없습니다. 천천히 들어도 됩니다.
- 문제마다 지금 판의 악기 중 하나가 **무작위로** 나옵니다. 같은 악기가 연달아 나올 수도 있습니다.

### 중간에 그만두기

| 하는 일 | 결과 |
|---|---|
| 머리줄 **✕ 그만하기** | 퀴즈가 바로 끝나고 연주모드로 돌아갑니다. 결과 창은 나오지 않습니다 |
| 퀴즈 중에 **판을 좌우로 넘김** | 퀴즈가 끝나고 연주모드로 돌아갑니다 |
| **←** 또는 휴대폰 뒤로가기 | 악기 소리 목록으로 나갑니다 |

## 4. 결과 창

```
┌───────────────────────────────┐
│       (진행 게이지 그림)         │
│          잘했어요!              │
│            4/5                 │
│   [  다시 하기  ]  [ 나가기 ]   │
└───────────────────────────────┘
```

| 맞힌 수 | 문구 |
|---|---|
| **모두** 맞힘 | 완벽해요! |
| **70% 이상** | 잘했어요! |
| 70% 미만 | 아쉬워요! |

| 버튼 | 하는 일 |
|---|---|
| **다시 하기** | 같은 판 · 같은 문제 수로 바로 퀴즈 다시 시작 |
| **나가기** (또는 휴대폰 뒤로가기) | 결과를 닫고 **연주모드**로 (드럼 화면에 남습니다) |

---

## 5. 기록은 남나요?

**남지 않습니다.** 드럼은 점수·정답률을 저장하지 않고, 📊 연습 기록에도 나오지 않습니다. 별 · 클리어 미션도 없습니다.
결과 창의 점수는 그 판에서만 보입니다.

- 고른 문제 수와 판은 드럼 화면을 나가면 처음 값(5문제 · 1/4)으로 돌아갑니다.

---

## 6. 잘 하는 요령

- **연주모드에서 먼저 충분히** 소리를 들어 두세요. ◀ ▶ 스틱 버튼으로 악기를 차례로 옮기면 빠르게 비교할 수 있습니다.
- **1/4 판(2개)** 에서 시작해 익숙해지면 악기를 늘리세요.
- 구별 포인트:
  - **북 소리**(킥드럼 · 스네어 · 탐)와 **쇳소리**(하이햇 · 심벌)부터 나누세요.
  - 북: 킥드럼은 가장 낮고, 탐은 중간, 스네어는 「탁」 튑니다.
  - 쇳소리: 하이햇은 **짧고**, 심벌은 **길게** 울립니다.
- 헷갈리면 **↻ 다시 듣기**를 쓰세요. 점수에 불리하지 않습니다.

## 7. 자주 묻는 질문

**Q. 킥드럼 소리가 안 들려요.**
킥드럼은 아주 낮은 소리라 휴대폰 스피커로는 거의 안 들립니다. 이어폰을 쓰세요.

**Q. 퀴즈 중에 화면이 넘어가면서 퀴즈가 끝났어요.**
퀴즈 중에 판을 좌우로 넘기면 퀴즈가 끝납니다. 캐릭터를 끌 때 화면을 옆으로 밀지 않도록 조심하세요.

**Q. ▶ 버튼으로 답할 수 없나요?**
퀴즈 중에는 ▶ 버튼이 사라집니다. 캐릭터를 직접 끌어서 악기에 놓아야 답이 됩니다.

**Q. 처음 누르는 소리 앞부분이 잘려요.**
드럼 소리는 아주 짧아 앞이 잘리면 통째로 사라질 수 있습니다. [듣기 준비](../0_공통/듣기%20준비%20가이드.md)의 젠더 팁을 보세요.
