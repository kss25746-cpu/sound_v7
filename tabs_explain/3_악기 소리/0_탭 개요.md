# 악기 소리 탭 개요

하단 세 번째 탭 **악기 소리**(🎹 건반 아이콘)입니다.
악기 소리를 **듣고 고르거나**, 피아노 · 기타 · 드럼을 **직접 쳐 보며** 소리를 익히는 연습이 모여 있습니다.

```
   하단 탭 [악기 소리]
        │
        ▼
   악기 소리 목록
   ├── 🎧 듣기 준비 (오른쪽 위)
   ├── 📊 연습 기록 (오른쪽 위)
   ├── 🔊 듣고 고르기  → 악기 소리 하나를 듣고 넷 중 고르기 (세로)
   ├── 🎹 피아노       → 자유 연주 · 음 찾기 훈련 · 노래 연주 (가로)
   ├── 🎸 기타         → 자유 연주 · 음 찾기 훈련 (가로)
   └── 🥁 드럼         → 연주모드 · 듣기연습 퀴즈 (세로)
```

## 4. 피아노 · 기타 훈련의 공통 규칙

| 항목 | 내용 |
|---|---|
| 문제 | 음 하나를 들려줍니다. **다시 듣기**는 몇 번이든 됩니다 |
| 답 | 같은 음 건반 · 칸을 누릅니다. 누르는 쪽도 소리가 나서 비교하며 찾을 수 있습니다 |
| 정답 | 점수 +1 · 색종이 · 약 2초 뒤 다음 문제 자동 재생 |
| 오답 | 점수 −1 (0 아래로 안 감) · 같은 문제 그대로 |
| ⭐ 별 | 그 난이도에서 정답 **누적 3회** |
| ✔ 클리어 | 그 난이도에서 한 번의 훈련 중 **점수 5점** |
| 기록 | 미션 창에서만. 📊 연습 기록에는 나오지 않습니다 |

## 5. 어떤 순서로 해 볼까요?

1. 🎧 **듣기 준비**로 이어폰과 볼륨을 맞춥니다. 드럼의 킥드럼처럼 낮은 소리는 이어폰이 꼭 필요합니다.
2. **듣고 고르기**로 악기의 결(음색)을 구별해 봅니다.
3. **드럼** 연주모드에서 다섯 악기 소리를 익히고, 듣기연습으로 맞혀 봅니다.
4. **피아노 · 기타**를 자유롭게 쳐 본 뒤, 훈련 모드 **1단계(입문)** 부터 별과 클리어를 모아 보세요.
5. 피아노 **자유 모드**로 아는 노래(아리랑 · 나비야 · 반짝반짝 작은별 …)를 쳐 보세요.

> 이 탭의 연습은 **웰니스 연습**입니다. 병원 검사나 진단을 대신하지 않습니다.
