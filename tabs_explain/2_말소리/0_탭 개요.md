# 말소리 탭 개요

하단 두 번째 탭 **말소리**(💬 말풍선 아이콘)입니다.
**사람 말소리**를 알아듣는 연습이 모여 있습니다. 짧은 소리 → 한 글자 → 두 글자 → 문장으로 점점 길어집니다.

```
   하단 탭 [말소리]
        │
        ▼
   말소리 목록
   ├── 🎧 듣기 준비 (오른쪽 위)
   ├── 📊 연습 기록 (오른쪽 위)
   ├── 〰 소리 찾기     → 바다의 세 깊이로 또렷 / 흐릿 찾기 (4단계)
   ├── 🎤 소리 구분     → 음·우·아·이·쉬·스를 그림에서 고르기
   ├── 가 한 글자       → 한 글자 단어 4지선다          ┐
   ├── 가나 두 글자     → 두 글자 단어 4지선다          ├ 한국어 음성(TTS) 필요
   ├── ▦ 빙고          → 3×3 판에서 들은 단어 칠하기   ┘
   ├── 🃏 단어 카드     → 비슷한 두 단어를 번갈아 듣기
   └── 📝 문장 듣기     → 문장을 듣고 그림 3장 중 고르기
```

---

## 1. 목록 화면

```
┌───────────────────────────────┐
│ 말소리                  🎧  📊  │  ← 듣기 준비 · 연습 기록
│ 소리 찾기와 말 연습을 고릅니다 · │
│ 병원 검사가 아니에요             │
│ ┌───────────────────────────┐ │
│ │ (〰) 소리 찾기  소리를 찾는 바다│ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ (🎤) 소리 구분  들은 소리를   │ │
│ │       그림에서 고르는 연습    │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ (가) 한 글자  한 글자 단어를  │ │
│ │       듣고 보기에서 고르는 연습│ │
│ └───────────────────────────┘ │
│            ⋮ (두 글자 · 빙고 ·   │
│              단어 카드 · 문장 듣기)│
└───────────────────────────────┘
│  다른 소리 │ 말소리 │ 악기 소리 │ 설정 │
```

- 카드를 누르면 그 연습이 열립니다. 연습 안에서 **뒤로 가기**나 휴대폰 뒤로가기를 누르면 이 목록으로 돌아옵니다.
- **한 글자 · 두 글자 · 빙고**는 누르면 먼저 기기에 한국어 음성이 있는지 확인합니다. 확인하는 잠깐 동안 목록 카드가 눌리지 않습니다.
  음성이 없으면 [한국어 음성 안내](../0_공통/한국어%20음성%20안내%20가이드.md)가 열립니다.

## 2. 들어 있는 콘텐츠

| 콘텐츠 | 한 줄 설명 | 한 판 | 소리 | 기록 | 문서 |
|---|---|---|---|---|---|
| **소리 찾기** | 「삐—」와 단어로 높은·중간·낮은 소리 층의 또렷 / 흐릿 찾기 | 1~4단계 (24문항~) | 녹음 | 📊 「소리 찾기」 | [소리 찾기 가이드](소리%20찾기%20가이드.md) |
| **소리 구분** | 음·우·아·이·쉬·스 중 들은 소리를 그림에서 고르기 | 8문항 (무음 2 포함) | 녹음 | 📊 「소리 구분」 (하루 1건) | [소리 구분 가이드](소리%20구분%20가이드.md) |
| **한 글자** | 한 글자 단어를 듣고 한 소리만 다른 보기 4개 중 고르기 | 12 / 25문항 | TTS | 📊 「한 글자」 | [한 글자 가이드](한%20글자%20가이드.md) |
| **두 글자** | 두 글자 단어를 듣고 비슷한 단어가 섞인 보기 4개 중 고르기 | 12문항 (3장 차례로) | TTS | 📊 「두 글자」 | [두 글자 가이드](두%20글자%20가이드.md) |
| **빙고** | 들은 한 글자 단어를 3×3 판에서 칠해 한 줄 만들기 | 최대 18단어 | TTS | 없음 (놀이) | [빙고 가이드](빙고%20가이드.md) |
| **단어 카드** | 한 소리만 다른 두 단어를 번갈아 들으며 익히기 | 20장 | 녹음 | 익힌 카드만 | [단어 카드 가이드](단어%20카드%20가이드.md) |
| **문장 듣기** | 짧은 문장을 듣고 그림 3장 중 고르기 | 9 / 18문항 | 녹음 | 📊 「문장 듣기」 | [문장 듣기 가이드](문장%20듣기%20가이드.md) |

- **TTS**: 휴대폰의 한국어 음성 읽기. 기계 목소리입니다.
- **녹음**: 앱에 들어 있는 음성 파일. 휴대폰 음성 설정과 상관없습니다.

## 3. 오른쪽 위 아이콘

| 아이콘 | 이름 | 하는 일 | 문서 |
|---|---|---|---|
| 🎧 | 듣기 준비 | 연습 전에 소리가 잘 나는지, 볼륨이 편한지 확인 | [듣기 준비 가이드](../0_공통/듣기%20준비%20가이드.md) |
| 📊 | 연습 기록 | 연습 기록(통계) 화면. 이 탭에서 열면 **소리 찾기** 칸이 먼저 열립니다 | [연습 기록 가이드](../0_공통/연습%20기록%20가이드.md) |

소리 구분 · 한 글자 · 두 글자 · 문장 듣기는 연습 첫 화면에도 🎧 · 📊가 있어, 열면 그 연습 칸이 먼저 열립니다.

## 4. 공통으로 알아 두면 좋은 점

| 항목 | 내용 |
|---|---|
| 다시 듣기 | 소리 찾기·단어 카드를 뺀 나머지는 **한 번 듣고 고릅니다.** 다시 듣기 버튼이 없습니다 |
| 첫 소리 앞 뜸 | 시작 직후 소리를 놓치지 않게 첫 문항 앞에 약 0.7초 쉽니다 |
| 중지 | 소리 나는 중에 누르면 소리가 바로 멈추고 「연습 끝내기」를 묻습니다. 취소하면 그 소리를 처음부터 다시 들려줍니다 |
| 기록 조건 | 정해진 문항 수를 **끝까지** 풀어야 기록됩니다. 중간에 끝내면 결과 화면에서만 보입니다 |
| 앱을 내렸을 때 | 소리가 끊기고 진행이 멈춥니다. 듣지 못한 문항이 혼자 넘어가 오답이 되지 않습니다 |
| 보관 | 연습마다 최근 50판(소리 구분은 50일)까지 기기에 보관합니다 |

## 5. 어떤 순서로 해 볼까요?

1. 🎧 **듣기 준비**로 이어폰과 볼륨을 맞춥니다.
2. **소리 찾기**로 어느 높이의 소리가 흐릿한지 먼저 알아봅니다.
3. 매일 짧게 **소리 구분** 한 판 (하루 기록이 쌓입니다).
4. **한 글자 → 두 글자 → 문장 듣기** 순서로 길이를 늘려 갑니다.
5. 자꾸 틀리는 소리가 있으면 **단어 카드**로 짝을 번갈아 들어 보고, 쉬는 겸 **빙고**를 즐기세요.
6. 📊 **연습 기록**에서 연습마다 변화를 확인합니다.

> 이 탭의 연습은 **웰니스 연습**입니다. 병원 검사나 진단을 대신하지 않습니다.
