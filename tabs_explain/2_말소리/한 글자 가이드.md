# 한 글자 가이드

「말소리」 탭의 **한 글자**를 하는 방법을 안내합니다.
「귀 · 남 · 해」 같은 **한 글자 단어** 하나를 기계 목소리가 읽어 줍니다. **소리가 비슷한 보기 4개** 중에서 들은 단어를 고르는 연습입니다.
한 판은 **12문항** 또는 **25문항**이고, 끝까지 풀면 맞힌 비율이 기록됩니다.

> 들어가는 곳: **말소리** 탭 → **한 글자** 카드
> 나가는 곳: 첫 화면·결과 화면의 **뒤로 가기**, 또는 휴대폰 뒤로가기

```
   한 글자 카드
        │  (기기에 한국어 음성이 없으면 → 「한국어 음성이 없어요」 안내)
        ▼
   첫 화면: 12문항 / 25문항 고르기 → 시작
        │
        ▼
   단어 듣기 → 비슷한 보기 4개 중 고르기 → 맞았어요 / 아쉬워요 → 다음
        │  12번 또는 25번
        ▼
   「○개 중 ○개를 맞혔어요 · 맞힌 비율 약 ○○%」 → 기기에 기록
        │
        ▼
   📊 통계 「한 글자」에서 변화 보기
```

---

## 1. 들어가기 전에 — 한국어 음성

한 글자는 휴대폰의 **한국어 음성 읽기(TTS)** 로 단어를 읽습니다.
카드를 누르면 앱이 먼저 기기에 한국어 음성이 있는지 확인합니다. (확인하는 동안 목록 카드가 잠깐 눌리지 않습니다)

- 있으면 → 한 글자 첫 화면이 열립니다.
- 없으면 → 「**한국어 음성이 없어요**」 안내가 열립니다. 받는 방법은 [한국어 음성 안내](../0_공통/한국어%20음성%20안내%20가이드.md)를 보세요.

## 2. 첫 화면

```
┌───────────────────────────────┐
│ 한 글자                 🎧  📊  │  ← 듣기 준비 · 통계
│ 들은 단어를 보기에서 고르는 연습 ·│
│ 병원 검사가 아니에요             │
│ ┌───────────────────────────┐ │
│ │ 이렇게 연습해요              │ │
│ │ 한 글자 단어 하나를 읽어 줘요.│ │
│ │ 비슷한 소리 보기 네 개 중에서 │ │
│ │ 들은 단어를 고르면 됩니다.    │ │
│ │ 목소리는 기계음이라 사람 말과 │ │
│ │ 다를 수 있어요.              │ │
│ │ ┌──────────┬──────────┐   │ │
│ │ │  12문항   │  25문항   │   │ │  ← 문항 수 고르기
│ │ └──────────┴──────────┘   │ │     (처음에는 12문항)
│ └───────────────────────────┘ │
│     [  시작  ]  [ 뒤로 가기 ]    │
└───────────────────────────────┘
```

| 문항 수 | 이럴 때 |
|---|---|
| **12문항** | 짧게 하고 싶을 때. 몇 분이면 끝납니다 (처음 골라진 값) |
| **25문항** | 기록을 더 믿을 만하게 남기고 싶을 때 |

- 🎧 [듣기 준비](../0_공통/듣기%20준비%20가이드.md), 📊 [연습 기록](../0_공통/연습%20기록%20가이드.md)(「한 글자」 칸)
- 두 아이콘은 첫 화면과 결과 화면에서만 보입니다.

## 3. 한 문항의 흐름

```
┌───────────────────────────────┐
│ 한 글자                         │
│ ██████░░░░░░░░░░░░░░░░░░░░░░  │  ← 진행 막대
│             ▮▮▮                │
│   듣는 중… 소리가 끝난 뒤 고르세요 │
│  ┌───────────┐ ┌───────────┐  │
│  │    밀     │ │    빌     │  │  ← 보기 4개
│  └───────────┘ └───────────┘  │
│  ┌───────────┐ ┌───────────┐  │
│  │    물     │ │    민     │  │
│  └───────────┘ └───────────┘  │
│            [ 중지 ]             │
└───────────────────────────────┘
```

1. **시작**을 누르면 「잠시 뒤 들려 드려요」가 잠깐(0.7초) 나온 뒤 첫 단어를 읽습니다. (첫 문항에만 뜸이 있습니다)
2. 읽는 동안은 「듣는 중… 소리가 끝난 뒤 고르세요」이고 보기가 잠겨 있습니다.
3. 다 읽으면 「들은 단어를 고르세요」로 바뀝니다. 보기 4개 중 하나를 누릅니다.
4. 바로 결과가 나옵니다.
   - 맞았으면 「**맞았어요**」
   - 틀렸으면 「**아쉬워요 · 정답은 ○**」 그리고 **정답 보기에 파란 테두리**
5. 아래 버튼이 **다음 · 끝내기**로 바뀝니다. **다음**을 누르면 다음 단어를 읽습니다.

- **다시 듣기는 없습니다.** 한 번 듣고 고르는 연습입니다.
- 단어는 200개 단어 모음에서 **무작위로** 뽑고, 한 판 안에서는 겹치지 않습니다.

### 보기는 어떻게 만들어지나요?

오답 보기 3개는 정답과 **한 소리만 다른** 글자입니다. 문항마다 아래 셋 중 하나를 골라 만듭니다.

| 바뀌는 곳 | 예 (정답 「밀」) |
|---|---|
| 첫소리(초성) | 밀 → **빌 · 길** |
| 가운데 소리(중성) | 밀 → **물 · 멀** |
| 받침(종성) | 밀 → **민 · 밉** |

- 헷갈리기 쉬운 짝(예: ㄱ·ㄲ·ㅋ, ㅂ·ㅃ·ㅍ, ㅅ·ㅆ 같은 비슷한 첫소리, 가까운 모음, 비슷한 받침)을 먼저 씁니다.
- 위 표의 글자는 예시입니다. 실제 보기는 문항마다 다르게 만들어집니다.

### 중간에 멈추고 싶을 때

| 지금 상태 | 버튼 | 일어나는 일 |
|---|---|---|
| 읽는 중 | **중지** | 소리가 바로 멈추고 「연습 끝내기 — 여기서 끝낼까요?」. **취소**하면 그 단어를 **처음부터 다시** 읽습니다 |
| 고르는 중 (다 읽은 뒤) | **중지** | 같은 확인 창. **취소**하면 그대로 고르기로 돌아갑니다. **다시 읽어 주지 않습니다** |
| 답을 고른 뒤 | **끝내기** | 같은 확인 창 |

- 확인 창에서 **끝내기** → 결과 화면
- 휴대폰 뒤로가기는 진행 중에 같은 확인 창을 띄웁니다.
- 앱을 내리거나 전화가 오면 소리가 끊기고 진행이 멈춥니다.

> 「고르는 중」에 중지 → 취소로 다시 듣는 길을 막아 둔 이유: 기록이 **「한 번 듣고 고른 결과」** 이어야 지난 기록과 비교할 수 있기 때문입니다.

### 「단어를 읽지 못했어요」가 나올 때

음성 읽기가 실패하면 「단어를 읽지 못했어요. 보기를 고르거나 다시 시작해 주세요.」가 나오고 보기를 누를 수 있게 됩니다.
소리를 못 들었으니 끝내기를 눌러 다시 시작하는 것이 좋습니다.

## 4. 결과 화면

```
┌───────────────────────────────┐
│ 한 글자                 🎧  📊  │
│   ✓ 연습이 끝났어요              │
│ ┌───────────────────────────┐ │
│ │ 25개 중 20개를 맞혔어요      │ │
│ │ 맞힌 비율 약 80%            │ │
│ │ 연습 기록이에요. 청력 검사·   │ │
│ │ 진단 결과가 아니에요.         │ │
│ └───────────────────────────┘ │
│     [ ✓ 기기에 기록했어요 ]      │
│     [ 다시 연습 ]  [ 뒤로 가기 ] │
└───────────────────────────────┘
```

| 저장 문구 | 뜻 |
|---|---|
| **기기에 기록했어요** | 고른 문항 수(12 또는 25)를 끝까지 풀어서 기록했습니다 |
| **25개를 다 고르지 않아 기록에는 안 남겼어요** (또는 12개) | 중간에 끝내서 기록하지 않았습니다. 결과 화면에서만 보입니다 |
| 기록에 남기지 못했어요 | 저장 중 문제가 생겼습니다 |

- 중간에 끝내도 그때까지 푼 문항으로 「○개 중 ○개」는 보여 줍니다. 하나도 안 풀었으면 「연습이 짧아서 참고할 숫자가 없어요」.
- **다시 연습**은 같은 문항 수로 바로 새 판을 시작합니다. 문항 수를 바꾸려면 **뒤로 가기**로 나갔다가 다시 들어오세요.

## 5. 내 동작이 기록에 어떻게 남나요?

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 12문항 또는 25문항을 끝까지 풀었다 | 한 판 기록 1개: 날짜·시각, 맞힌 수 / 푼 수, 맞힌 비율 |
| 중간에 끝냈다 | **남지 않음** |
| 문항 하나를 맞혔다 / 틀렸다 | 그 판의 맞힌 수에만 더해집니다. 어떤 단어를 틀렸는지는 남지 않습니다 |

- 맞힌 비율은 **반올림한 정수**입니다. 예: 20/25 = 80%, 9/12 = 75%
- 기록은 **최근 50판**까지 보관됩니다.
- 12문항 판과 25문항 판은 **같은 목록**에 쌓입니다.

## 6. 통계 「한 글자」 읽기

📊 연습 기록에서 **한 글자** 칸을 고르면 아래가 보입니다.

```
┌───────────────────────────────┐
│ (가) 한 글자  기록 6회           │
│ ┌───────────────────────────┐ │
│ │ 맞힌 비율 변화              │ │  ① 기록 2회부터
│ │ 높을수록 더 많이 맞춤        │ │
│ │ 청력 검사가 아니에요.        │ │
│ │ 100 ┼───────────●          │ │
│ │  50 ┼──●───●               │ │
│ │   0 ┼─────────────         │ │
│ │ 10/1     기록 0~100%   10/20 │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 최근 연습                   │ │  ② 최근 8판
│ │ 10/20 14:05     20/25 · 약 80% │
│ │ 10/18 09:30      9/12 · 약 75% │
│ └───────────────────────────┘ │
│        한 글자 기록 지우기        │
└───────────────────────────────┘
```

- ① 그래프는 판마다 맞힌 비율을 날짜 순서로 잇습니다. 위로 갈수록 많이 맞힌 판입니다. 맨 오른쪽 크게 테두리 친 점이 최근 판입니다.
  - 보관된 판(최대 50판)을 **모두** 그립니다. ② 목록처럼 8판으로 자르지 않습니다.
  - 가로축은 판 번호가 아니라 **연습한 시각**입니다. 같은 날 여러 판을 하면 점이 붙고, 며칠 쉬면 간격이 벌어집니다.
  - 12판까지는 판마다 점이 찍힙니다. 그보다 많으면 첫 판과 최근 판에만 점이 찍히고 나머지는 선으로만 이어집니다.
  - 50판을 넘으면 가장 오래된 판부터 지워지므로 그래프 왼쪽 끝이 앞으로 밀려납니다.
- ② 한 줄이 한 판입니다. `20/25 · 약 80%` = 25문항 중 20개 맞힘.
- 12문항 판은 한 문항이 약 8%, 25문항 판은 4%라서 **12문항 판의 그래프가 더 크게 출렁입니다.** 변화를 볼 때는 같은 문항 수 판끼리 비교하세요.

## 7. 잘 하는 요령

- 보기 4개는 **한 소리만 다릅니다.** 첫소리 · 모음 · 받침 중 어디가 다른지 먼저 보기를 훑고, 그 부분에 귀를 모으세요.
- 받침이 다른 문항(민 · 밉 · 밀)은 끝소리를 끝까지 들어야 합니다.
- 기계 목소리라 사람 말과 다를 수 있습니다. 같은 기기로 꾸준히 하면 그 목소리에 익숙해져 비교가 쉬워집니다.
- 기록을 비교하려면 **문항 수를 하나로 정해** 두세요. (예: 평소에는 25문항)
- 이어폰 앞부분 잘림이 의심되면 [듣기 준비](../0_공통/듣기%20준비%20가이드.md)의 젠더 팁을 보세요. 한 글자 단어는 짧아서 첫소리가 잘리면 맞히기 어렵습니다.

## 8. 자주 묻는 질문

**Q. 다시 듣고 싶어요.**
이 연습은 한 번 듣고 고릅니다. 읽는 도중에 **중지 → 취소**를 누르면 그 단어를 처음부터 다시 읽지만, 다 읽은 뒤에는 다시 들을 수 없습니다.

**Q. 보기에 처음 보는 글자가 있어요.**
오답 보기는 정답과 한 소리만 바꿔 만들기 때문에 실제로 잘 쓰지 않는 글자가 나올 수 있습니다. 정답은 늘 실제 단어입니다.

**Q. 끝까지 안 했는데 통계에 없어요.**
고른 문항 수를 끝까지 푼 판만 기록됩니다.

**Q. 「한국어 음성이 없어요」가 떠요.**
[한국어 음성 안내](../0_공통/한국어%20음성%20안내%20가이드.md)를 따라 한국어 음성을 받은 뒤 **다시 확인**을 누르세요.

**Q. 이 결과가 어음 검사(WRS)인가요?**
아니요. 연습 기록입니다. 단어 목록도 병원 검사용 표준 목록과 같지 않습니다.
