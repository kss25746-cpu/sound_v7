# 빙고 가이드

「말소리」 탭의 **빙고**(화면 제목: 단어 빙고)를 하는 방법을 안내합니다.
3×3 판에 **한 글자 단어 9개**가 있습니다. 기계 목소리가 그중 하나를 읽어 주면 **들은 단어 칸**을 누릅니다. 맞히면 칸이 칠해지고, **가로 · 세로 · 대각선으로 한 줄**이 이어지면 끝납니다.
점수를 매기는 연습이 아니라 **편하게 즐기는 놀이**입니다. 기록은 남지 않습니다.

> 들어가는 곳: **말소리** 탭 → **빙고** 카드
> 나가는 곳: 첫 화면·결과 화면의 **뒤로 가기**, 또는 휴대폰 뒤로가기

```
   빙고 카드
        │  (기기에 한국어 음성이 없으면 → 「한국어 음성이 없어요」 안내)
        ▼
   첫 화면: 쉬운 판 / 비슷한 소리 고르기 → 시작
        │
        ▼
   단어 듣기 → 판에서 그 칸 누르기
        │  맞음 → 칸 칠해짐 · 틀림 → 그대로
        ▼
   다음 → 다음 단어 …   (최대 18번)
        │
        ├── 한 줄 완성 → 🎉 「한 줄이 이어졌어요」
        └── 18번 다 들음 → 「이번에는 한 줄이 안 나왔어요」
```

---

## 1. 들어가기 전에 — 한국어 음성

빙고는 휴대폰의 **한국어 음성 읽기(TTS)** 로 단어를 읽습니다.
기기에 한국어 음성이 없으면 「**한국어 음성이 없어요**」 안내가 열립니다. → [한국어 음성 안내](../0_공통/한국어%20음성%20안내%20가이드.md)

## 2. 첫 화면

```
┌───────────────────────────────┐
│ 단어 빙고                       │
│ 들은 단어를 판에서 눌러요 ·       │
│ 편하게 연습해요                  │
│ ┌───────────────────────────┐ │
│ │ 이렇게 놀아요                │ │
│ │ 3×3 판에 단어가 있어요. 들린 │ │
│ │ 칸을 누르면 칠해집니다.       │ │
│ │ 가로·세로·대각 한 줄이면      │ │
│ │ 끝나요. 맞히기 기록에는 안    │ │
│ │ 남아요.                     │ │
│ └───────────────────────────┘ │
│  ┌──────────┬────────────┐    │
│  │ 쉬운 판   │ 비슷한 소리  │    │  ← 판 고르기
│  └──────────┴────────────┘    │     (처음에는 쉬운 판)
│     [  시작  ]  [ 뒤로 가기 ]    │
└───────────────────────────────┘
```

| 판 | 판에 놓이는 단어 | 이럴 때 |
|---|---|---|
| **쉬운 판** | 서로 **소리가 많이 다른** 단어 9개 | 처음 할 때, 가볍게 즐길 때 |
| **비슷한 소리** | 첫소리 · 모음 · 받침 중 **한 소리만 다른** 비슷한 단어끼리 모은 9개 | 비슷한 소리 구별을 연습하고 싶을 때 |

- 빙고 화면에는 🎧 듣기 준비, 📊 통계 아이콘이 **없습니다.** 볼륨은 말소리 탭 목록의 🎧에서 먼저 맞추세요.
- 판의 단어는 [한 글자](한%20글자%20가이드.md)와 같은 단어 모음(200개)에서 뽑고, 판마다 새로 만들어집니다.

## 3. 게임 화면

```
┌───────────────────────────────┐
│ 단어 빙고                       │
│             ▮▮▮                │
│       들은 단어를 누르세요        │
│  [ 표시 3 / 9 ] [ 기회 14번 남음 ]│  ← 칠한 칸 · 남은 단어 수
│ ┌───────────────────────────┐ │
│ │ ┌─────┐ ┌─────┐ ┌─────┐  │ │
│ │ │ 귀  │ │█남██│ │ 해  │  │ │  ← 칠해진 칸 = 맞힌 칸
│ │ └─────┘ └─────┘ └─────┘  │ │
│ │ ┌─────┐ ┌─────┐ ┌─────┐  │ │
│ │ │ 밀  │ │█옷██│ │ 잔  │  │ │
│ │ └─────┘ └─────┘ └─────┘  │ │
│ │ ┌─────┐ ┌─────┐ ┌─────┐  │ │
│ │ │█댁██│ │ 겁  │ │ 시  │  │ │
│ │ └─────┘ └─────┘ └─────┘  │ │
│ └───────────────────────────┘ │
│            [ 중지 ]             │
└───────────────────────────────┘
```

### 한 번의 흐름

1. **시작**을 누르면 판이 나오고 바로 단어 하나를 읽습니다. 「듣는 중… 소리가 끝난 뒤 칸을 누르세요」
2. 다 읽으면 「들은 단어를 누르세요」. 판에서 그 단어 칸을 누릅니다.
3. 결과가 나옵니다.

| 누른 칸 | 보이는 것 | 판 |
|---|---|---|
| 맞음 | 「**맞았어요**」 · 칸이 톡 튀며 칠해집니다 | 칸이 칠해짐 |
| 틀림 | 「**아쉬워요 · 그 칸이 아니에요**」 | 아무 칸도 칠해지지 않음 |

4. **다음**을 누르면 다음 단어를 읽습니다.

- 읽어 주는 단어는 **아직 칠하지 않은 칸** 중에서 고릅니다. 이미 칠한 칸의 단어는 다시 나오지 않습니다.
- 틀렸을 때 **정답 칸은 알려 주지 않습니다.** 틀린 다음 단어는 방금 그 단어를 **피해서** 고르고, 놓친 단어는 나중에 다시 나올 수 있습니다.
- 이미 칠한 칸은 다시 누를 수 없습니다.
- **다시 듣기 버튼은 없습니다.**

### 위의 두 숫자

| 표시 | 뜻 |
|---|---|
| **표시 ○ / 9** | 지금까지 칠한 칸 수 |
| **기회 ○번 남음** | 앞으로 들을 수 있는 단어 수. 한 판에 **18번**까지 들을 수 있고, 단어를 하나 들을 때마다 1씩 줄어듭니다 |

### 판이 끝나는 경우

| 경우 | 결과 문구 |
|---|---|
| 칸을 칠해서 **한 줄이 완성**됐다 | 「**한 줄이 이어졌어요**」 (한 번에 두 줄이 이어지면 「두 줄이 이어졌어요」) |
| **18번**을 다 들었는데 한 줄이 없다 | 「이번에는 한 줄이 안 나왔어요」 |
| 중간에 **끝내기** | 그때 판 상태로 결과 |

- 한 줄은 가로 3줄 · 세로 3줄 · 대각선 2줄, 모두 8가지입니다.
- **한 줄이 완성되는 순간 바로 끝납니다.** 다음 버튼을 누를 필요가 없습니다.

### 중간에 멈추고 싶을 때

| 지금 상태 | 버튼 | 일어나는 일 |
|---|---|---|
| 읽는 중 / 고르는 중 | **중지** | 소리가 바로 멈추고 「연습 끝내기 — 여기서 끝낼까요?」 |
| 답을 고른 뒤 | **끝내기** | 같은 확인 창 |

- **끝내기** → 결과 화면
- **취소** → **같은 단어를 다시** 읽어 줍니다. 이때 **기회는 줄지 않습니다.**
- 휴대폰 뒤로가기는 진행 중에 같은 확인 창을 띄웁니다.

## 4. 결과 화면

```
┌───────────────────────────────┐
│ 단어 빙고                       │
│   ✓ 한 줄이 이어졌어요 🎉        │
│ ┌───────────────────────────┐ │
│ │  (판 — 완성된 줄이 차례로 튐) │ │
│ └───────────────────────────┘ │
│ ┌─────────┬─────────┬───────┐ │
│ │    1    │    5    │   8   │ │
│ │ 완성한 줄 │ 표시한 칸 │ 들은 단어│ │
│ └─────────┴─────────┴───────┘ │
│  ┌──────────┬────────────┐    │
│  │ 쉬운 판   │ 비슷한 소리  │    │  ← 다음 판 고르기
│  └──────────┴────────────┘    │
│   [ 다시 하기 ]  [ 뒤로 가기 ]   │
└───────────────────────────────┘
```

| 숫자 | 뜻 |
|---|---|
| **완성한 줄** | 이어진 줄 수 |
| **표시한 칸** | 칠한(맞힌) 칸 수 |
| **들은 단어** | 이번 판에 읽어 준 단어 수 (중지 → 취소로 다시 들은 것은 세지 않음) |

- 한 줄을 완성하면 판 위로 색종이가 날리고 완성된 줄 칸이 차례로 튑니다.
- 아래 토글로 판 종류를 바꾼 뒤 **다시 하기**를 누르면 그 판으로 새로 시작합니다.

---

## 5. 기록은 남나요?

**남지 않습니다.** 빙고는 맞힌 수·비율을 저장하지 않고, 📊 연습 기록에도 나오지 않습니다.
결과 화면의 세 숫자는 그 판에서만 보입니다.

---

## 6. 잘 하는 요령

- **들은 단어 수가 적을수록** 잘 들은 판입니다. 칸 3개로 한 줄을 만들면 가장 빠르게 끝납니다. (들은 단어 3)
- 「비슷한 소리」 판은 판 위 단어가 서로 한 소리씩만 다릅니다. 첫소리 · 모음 · 받침 중 **어디가 다른지** 먼저 판을 훑어 두세요.
- 틀려도 부담 갖지 마세요. 기록에 남지 않는 놀이입니다.
- 쉬운 판에서 자주 한 줄을 만들게 되면 「비슷한 소리」 판에 도전해 보세요.

---

## 7. 자주 묻는 질문

**Q. 틀렸는데 정답 칸이 어디인지 안 알려 줘요.**
빙고는 정답 칸을 보여 주지 않습니다. 놓친 단어는 나중에 다시 나올 수 있으니 그때 다시 찾아보세요.

**Q. 기회가 줄었는데 칸은 그대로예요.**
기회는 단어를 **들을 때마다** 줄어듭니다. 틀리면 칸은 칠해지지 않고 기회만 하나 쓴 것입니다.

**Q. 통계에서 빙고를 찾을 수 없어요.**
빙고는 기록을 남기지 않는 놀이라 통계에 없습니다. 기록을 남기려면 [한 글자](한%20글자%20가이드.md)나 [두 글자](두%20글자%20가이드.md)를 하세요.

**Q. 「단어를 읽지 못했어요」가 떠요.**
음성 읽기가 잠시 실패한 경우입니다. 끝내기 후 다시 시작해 보세요. 계속되면 [한국어 음성 안내](../0_공통/한국어%20음성%20안내%20가이드.md)를 확인하세요.
