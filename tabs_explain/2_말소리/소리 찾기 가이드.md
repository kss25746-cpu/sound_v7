# 소리 찾기 가이드

「말소리」 탭의 **소리 찾기**(화면 제목: 소리를 찾는 바다)를 하는 방법을 안내합니다.
소리를 **높이에 따라 바다의 세 깊이**로 나눕니다. 짧은 「삐—」 소리와 단어를 들으며 어느 깊이의 소리가 **또렷하고** 어느 깊이가 **흐릿한지** 찾아봅니다.
끝나면 **수심 지도**에 깊이별 결과가 나오고, 흐릿한 깊이만 골라 다시 연습할 수 있습니다.

> 들어가는 곳: **말소리** 탭 → **소리 찾기** 카드
> 나가는 곳: 첫 화면 왼쪽 위 **‹ 뒤로 가기**, 또는 휴대폰 뒤로가기

```
   소리를 찾는 바다 (첫 화면) → 여정 시작
        │
        ▼
   1단계 · 소리의 파동      「삐—」가 들렸나요?            9문항
        │
        ▼
   2단계 · 바다 둘러보기    들은 단어를 4개 중에서 고르기   15문항
        │  ── 모두 또렷 ───────────────────────────────┐
        ▼  흐릿한 깊이가 있으면                           │
   3단계 · 깊이 들어가기    흐릿한 깊이만, 같은 깊이 4개 중  │
        │  ── 다 회복 ─────────────────────────────────┤
        ▼  아직 흐릿하고, 또렷한 깊이도 있으면             │
   4단계 · 마주 보는 두 소리  한 소리만 다른 두 단어        │
        │                                              │
        ▼◀─────────────────────────────────────────────┘
   결과 · 수심 지도 (또렷 / 흐릿) → 기록 저장
        │
        └── 흐릿한 깊이 「연습」 → 그 깊이 단어만 다시 듣기
```

---

## 1. 바다의 세 깊이

이 연습은 소리를 **높낮이에 따라 세 층**으로 나눕니다. 위가 높은 소리, 아래가 낮은 소리입니다.

| 층 | 화면 표시 | 소리 높이 | 이 층에 드는 자음 | 1단계 「삐—」 |
|---|---|---|---|---|
| **수면층** | 수심 5m · 밝은 하늘색 | 높은 소리 · 고대역 (3,350 ~ 7,000 Hz) | ㄷ ㄸ ㅌ · ㅈ ㅉ ㅊ · ㅅ ㅆ | 4000 Hz |
| **중층** | 수심 40m · 파란색 | 중간 소리 · 중대역 (600 ~ 3,350 Hz) | ㄱ ㄲ ㅋ · ㅂ ㅃ ㅍ · ㅎ | 1000 Hz |
| **심해층** | 수심 120m · 짙은 남색 | 낮은 소리 · 저대역 (500 Hz 이하) | ㄴ ㅁ ㄹ | 250 Hz |

- 문제마다 **배경 바다 색**이 그 문항의 층으로 바뀝니다. 화면 위에 「수면층 · 수심 5m」처럼 지금 층이 나옵니다.
- 단어도 층마다 나뉘어 있습니다. 예: 심해층 「엄마 · 나무 · 노래」, 중층 「가방 · 바퀴 · 호박」, 수면층 「사탕 · 시소 · 치즈」
- 「깊이」는 화면 표현입니다. 실제 검사 결과가 아닙니다.

## 2. 첫 화면

```

│ ‹ 뒤로 가기                 📊  │  ← 탭 목록으로 · 통계
│                               │
│             〰〰               │
│        소리를 찾는 바다          │
│       병원 검사가 아니에요        │
│                               │
│   ┌───────────────────────┐   │
│   │      여정 시작          │   │  ← 1단계부터 시작
│   └───────────────────────┘   │
│ ┌───────────────────────────┐ │
│ │ 🧭 최근 탐사 기록  10월 20일 14:05│  ← 마지막 기록 (있을 때만)
│ │ ● 저대역 [또렷]             │ │
│ │ ● 중대역 [흐릿]             │ │
│ │ ● 고대역 [또렷]             │ │
│ │  [ 🧭 지난 결과 보기 ]      │ │  ← 그 결과 화면 다시 열기
│ └───────────────────────────┘ │
│        여정이 궁금해요 ⌄         │  ← 눌러서 네 단계 안내 펼치기
└───────────────────────────────┘
```

- 📊는 [연습 기록](../0_공통/연습%20기록%20가이드.md)을 「소리 찾기」 칸으로 엽니다.
- 「여정이 궁금해요」를 누르면 네 단계 안내와 「위가 높은 소리(수면), 아래가 낮은 소리(심해)예요」가 펼쳐집니다.
- 이 화면에는 🎧 듣기 준비 아이콘이 없습니다. 먼저 **말소리 탭 목록**의 🎧로 볼륨을 맞추고 들어오세요.

## 3. 단계별 방법

모든 단계의 화면 위에는 **단계 이름 · 지금 층**과 오른쪽에 **✕ 중단** 버튼이 있고, 아래에 진행 막대(「진행 · 3 / 9」)가 있습니다.

### 1단계 · 소리의 파동 (9문항)

```
┌───────────────────────────────┐
│ 1단계 · 소리의 파동      ✕ 중단 │
│ 중층 · 수심 40m                │
│                               │
│   버튼을 눌러 소리를 들어 보세요  │
│            ( ▶ )               │
│           소리 듣기             │
│                               │
│  [ 들렸어요 ]  [ 안 들렸어요 ]   │  ← 한 번 들은 뒤 나타남
│  진행 · 3 / 9  ███░░░░░░        │
└───────────────────────────────┘
```

1. 가운데 **소리 듣기** 버튼을 누르면 「삐—」 소리가 **1.2초** 납니다. (1단계는 자동으로 소리가 나지 않습니다)
2. 한 번 들으면 안내가 「이 소리가 들렸나요?」로 바뀌고 **들렸어요 · 안 들렸어요**가 나옵니다.
3. 버튼이 「다시 듣기」로 바뀌어 몇 번이든 다시 들을 수 있습니다.
4. 솔직하게 고르세요. 정답·오답 표시는 없고 바로 다음 문항으로 넘어갑니다.

- 세 층마다 **크기가 다른 소리 3개**(큰 소리 · 중간 · 작은 소리)씩, 모두 9문항이 섞여 나옵니다.
- 1단계 결과는 결과 화면의 **세부 점수**에만 「순음」으로 나옵니다. 최종 「또렷 / 흐릿」을 정하지는 않습니다.

### 2단계 · 바다 둘러보기 (15문항)

```
┌───────────────────────────────┐
│ 2단계 · 바다 둘러보기    ✕ 중단 │
│ 수면층                         │
│      들은 소리를 고르세요        │
│            ( ▶ )               │
│           다시 듣기             │
│     [ 오답 · 정답: 사탕 ]        │  ← 틀렸을 때만 잠깐
│  ┌──────┐ ┌──────┐            │
│  │ 🍬   │ │ 🦐   │            │  ← 보기 4개
│  │ 사탕 │ │ 새우 │            │     (그림 또는 글자)
│  └──────┘ └──────┘            │
│  ┌──────┐ ┌──────┐            │
│  │ 🌳   │ │ 👜   │            │
│  │ 나무 │ │ 가방 │            │
│  └──────┘ └──────┘            │
│  진행 · 5 / 15  ███░░░░░        │
└───────────────────────────────┘
```

1. 문항이 열리고 잠시 뒤 **단어가 자동으로** 한 번 들립니다.
2. 들은 단어를 **보기 4개** 중에서 고릅니다. 보기는 그림 카드이거나 글자 카드입니다.
3. 고르면 잠깐(0.7초) 기다렸다가 결과가 나옵니다.

| 고른 답 | 보이는 것 | 넘어가기까지 |
|---|---|---|
| 정답 | 고른 보기가 **초록색**으로 커집니다 | 약 0.9초 뒤 자동으로 다음 문항 |
| 오답 | 고른 보기는 **빨간색**, 정답은 초록색. 위에 「**오답 · 정답: ○○**」 | 약 2초 뒤 자동으로 다음 문항 |

- **다시 듣기**로 몇 번이든 다시 들을 수 있습니다. 소리를 들은 뒤에만 보기를 누를 수 있습니다.
- **3번 이상** 연달아 맞히면 「**○번 연속 맞았어요**」가 잠깐 나옵니다.
- 2단계 보기 4개는 **서로 다른 층**의 단어로 섞여 있습니다. (정답 1개 + 다른 층 단어 3개)
- 층마다 5문항씩 모두 15문항입니다.

**2단계 판정 (층마다 5문항)**

| 맞힌 수 | 판정 | 다음 |
|---|---|---|
| 4~5개 | 또렷 | 3단계에서 다시 보지 않습니다 |
| 3개 | 주의 | 3단계에서 다시 봅니다 |
| 0~2개 | 흐릿 | 3단계에서 다시 봅니다 |

세 층이 **모두 또렷**이면 3·4단계를 건너뛰고 바로 결과로 갑니다.

### 3단계 · 깊이 들어가기 (흐릿한 층마다 6문항)

시작 전에 안내 화면이 나옵니다.
「확인이 필요한 깊이만 다시 봅니다. 보기 네 개가 모두 같은 깊이에서 나오므로, 나머지를 지워서 맞히는 방법은 통하지 않습니다.」 → **계속 내려가기**

- 방법은 2단계와 같습니다. 단어가 자동으로 들리고, 4개 중에서 고릅니다.
- 다른 점: 보기 4개가 **모두 같은 층**의 단어입니다. 화면 위에 「같은 깊이의 네 그림」 또는 「같은 깊이의 네 단어」라고 나옵니다.
  - 예: 심해층 「나무 · 노래 · 나라 · 누나」 중에서 고르기 → 비슷한 소리끼리 구별해야 합니다.
- 2단계에서 주의·흐릿이었던 층만, 층마다 6문항입니다.

**3단계 판정 (층마다 6문항)**

| 맞힌 수 | 판정 |
|---|---|
| 5~6개 | 또렷 |
| 0~4개 | 흐릿 |

3단계에서 **모두 또렷**해졌거나, 비교할 **또렷한 층이 없으면** 4단계 없이 결과로 갑니다.

### 4단계 · 마주 보는 두 소리 (흐릿한 층마다 최대 6문항)

시작 전 안내: 「한 음소만 다른 두 단어를 나란히 냅니다. 약한 깊이와 잘 들리는 깊이를 직접 비교합니다.」 → **계속 내려가기**

```
┌───────────────────────────────┐
│ 4단계 · 마주 보는 두 소리  ✕ 중단│
│ 심해층 vs 중층                  │
│   ┌─────────────────────┐     │
│   │    두 그림 중 선택     │     │  ← 글자 카드면 「ㅁ / ㅎ
│   │ 들린 소리에 맞는 그림을 │     │     소리 하나만 달라요」
│   │ 고르세요              │     │
│   └─────────────────────┘     │
│            ( ▶ )               │
│  ┌──────────────────────────┐ │
│  │  🧄  마늘                 │ │  ← 보기 2개
│  └──────────────────────────┘ │
│  ┌──────────────────────────┐ │
│  │  ☁  하늘                 │ │
│  └──────────────────────────┘ │
│  심해층 비교 · 2 / 6            │
└───────────────────────────────┘
```

- 흐릿한 층 단어와 또렷한 층 단어 중 **한 소리만 다른 짝**이 나옵니다. 예: 마늘 ↔ 바늘, 머리 ↔ 허리, 가방 ↔ 가상
- 단어가 자동으로 들리고, **보기 2개** 중에서 고릅니다. 약 1초 뒤 자동으로 넘어갑니다.
- 짝이 적은 층은 문항이 6개보다 적을 수 있습니다.
- 4단계 점수는 **참고용**입니다. 세부 점수에 「대립쌍 ○/○」로만 남고, 최종 「또렷 / 흐릿」을 바꾸지 않습니다.

## 4. 중간에 멈추거나 끊겼을 때

| 상황 | 일어나는 일 |
|---|---|
| **✕ 중단** 또는 휴대폰 뒤로가기 | 소리가 멈추고 「**여정 끝내기** — 여기서 끝낼까요?」가 뜹니다 |
| └ 끝내기 | 첫 화면으로 돌아갑니다. **이번 여정은 기록되지 않습니다** |
| └ 취소 | 그 자리에서 이어 합니다 |
| 전화·알림·앱 내리기 | 소리가 멈추고 「**측정이 일시정지되었어요**」 창이 뜹니다. 지금 단계 이름이 나옵니다 |
| └ 측정 계속하기 | 그 문항부터 이어 합니다. 단어 문항은 소리가 다시 자동으로 납니다 |
| └ 측정 중단하고 메인으로 | 첫 화면으로 갑니다. 기록되지 않습니다 |

> 💡 **결과 화면까지 가야 기록됩니다.** 중간에 끝내면 그동안 푼 문항은 남지 않습니다.

## 5. 결과 화면

```
┌───────────────────────────────┐
│                            📊  │
│   중층이 흐릿하게 들렸어요        │  ← ① 결론 한 줄
│        ✓ 기록 저장됨             │
│ ┌───────────────────────────┐ │
│ │ ● 또렷 ● 흐릿  잘 들린 층은 또렷, 아니면 흐릿│
│ │ 0m ┌─────────────────────┐ │ │
│ │    │수심 5m 수면층 (3,350~7,000 Hz) [또렷]│  ← ② 수심 지도
│ │    │대표 자음 ㄷ ㄸ ㅌ ㅈ …  │ │ │     (층을 누르면 강조)
│ │    ├─────────────────────┤ │ │
│ │    │수심 40m 중층 (600~3,350 Hz) [흐릿]│
│ │    ├─────────────────────┤ │ │
│ │    │수심 120m 심해층 (≤ 500 Hz) [또렷]│
│ │    └─────────────────────┘ │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 다음에 할 일                │ │  ← ③ 다음 행동
│ │ 흐릿한 깊이 1곳만 연습해요.  │ │
│ │ ● 중층  흐릿     [▶ 연습]   │ │
│ │ ≡ 자세히 보기 ⌄            │ │
│ └───────────────────────────┘ │
│   [     다시 측정하기     ]     │
│   [       처음으로        ]     │
│  이 결과는 … 청력 진단(PTA/WRS)을│
│  대신하지 않습니다.              │
└───────────────────────────────┘
```

### ① 결론 한 줄

| 문구 | 뜻 |
|---|---|
| 모든 깊이가 또렷하게 들렸어요 | 세 층 모두 또렷 |
| ○○층이 흐릿하게 들렸어요 | 그 층(들)이 흐릿 |
| 모든 깊이가 흐릿하게 들렸어요 | 세 층 모두 흐릿 |

### ② 수심 지도

- 위에서 아래로 **수면층 → 중층 → 심해층**입니다. 층마다 이름, 소리 높이, **또렷**(초록) / **흐릿**(빨강) 배지, 대표 자음이 나옵니다.
- 왼쪽 눈금자에도 층마다 또렷 / 흐릿이 표시됩니다.
- 층을 누르면 그 층이 강조됩니다. 다시 누르면 풀립니다.

### ③ 다음에 할 일

| 결과 | 보이는 것 |
|---|---|
| 모두 또렷 | 「지금의 듣기 상태를 유지하려면 한 달에 한 번 다시 점검해 보세요.」 |
| 흐릿한 층이 있음 | 흐릿한 층마다 **▶ 연습** 버튼 (6절) |

**자세히 보기**를 누르면 흐릿한 층마다 아래가 펼쳐집니다.

| 층 | 안내 제목 | 무엇이 어려울 수 있나요 |
|---|---|---|
| 수면층 | 치찰음·마찰음 | ㅅ·ㅆ·ㅊ·ㅈ 같은 날카로운 소리가 흐릿해 다른 자음으로 들리기 쉬워요 |
| 중층 | 대화 명료도·폐쇄음 | ㄱ·ㅋ·ㅂ·ㅍ·ㅎ의 파열이 약해져 말이 덜 또렷할 수 있어요 |
| 심해층 | 비음·유음 | ㄴ·ㅁ·ㄹ 울림이 약해져 콧소리·연결음이 뭉개질 수 있어요 |

- **추천 연습 단어 쌍**: 「마늘 ↔ 바늘」 같은 짝을 누르면 **대립쌍 소리 비교** 창이 열립니다.
  두 단어를 하나씩 눌러 듣거나 **두 단어 이어서 듣기**로 차례로 들어 비교합니다. 「쌍 더 보기」로 짝을 더 볼 수 있습니다.
- **집중 음소**: 그 층의 자음 목록
- **세부 점수 보기**: 층마다 단계별 숫자

`순음: 모두 들림 · 스크리닝: 3/5 · 정밀: 4/6 · 대립쌍: 5/6`

| 글자 | 뜻 |
|---|---|
| 순음 | 1단계. **모두 들림**(3개 다) · **일부 놓침**(2개) · **대부분 놓침**(0~1개) |
| 스크리닝 ○/5 | 2단계 맞힌 수 |
| 정밀 ○/6 | 3단계 맞힌 수 (그 층이 3단계에 갔을 때만) |
| 대립쌍 ○/○ | 4단계 맞힌 수 (참고용, 4단계에 갔을 때만) |

### 결과 화면 버튼

| 버튼 | 하는 일 |
|---|---|
| 📊 | 연습 기록(소리 찾기 칸) 열기 |
| **다시 측정하기** | 1단계부터 새 여정 |
| **처음으로** | 소리 찾기 첫 화면으로 (휴대폰 뒤로가기도 같음) |

## 6. 흐릿한 층 연습

결과 화면 「다음에 할 일」의 **▶ 연습**을 누르면 그 층만 연습합니다.

1. 안내 화면: 「**연습 · 중대역** — 흐릿했던 중대역(600 ~ 3,350 Hz)의 단어들을 집중적으로 청취하며 귀의 감각을 깨워봅니다.」 → **계속 내려가기**
2. 3단계와 같은 방식으로 **그 층 단어 6문항**을 풉니다. (보기 4개가 모두 같은 층)
3. **틀린 문항은 맨 뒤에 한 번 더** 나옵니다. 화면 위에 「· 한 번 더」가 붙고 보기 순서가 바뀝니다.
4. 끝나면 「**중대역 연습 끝** — 6문제 중 4개 맞혔어요」 → **결과로 돌아가기**

- 「○문제 중 ○개」는 **처음 나온 6문항**만 셉니다. 「한 번 더」 문항은 세지 않습니다.
- 연습은 **기록에 남지 않습니다.** 수심 지도와 통계는 바뀌지 않습니다.
- 연습 중 위의 버튼은 「✕ 중단」 대신 **‹ 결과로 돌아가기**입니다. 누르면 확인 없이 바로 결과 화면으로 돌아갑니다.

## 7. 내 동작이 기록에 어떻게 남나요?

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 결과 화면까지 갔다 | 여정 1회: 날짜·시각, 층마다 단계별 점수, 최종 또렷 / 흐릿 |
| 중단 · 일시정지에서 메인으로 | **남지 않음** |
| 흐릿한 층 연습을 했다 | **남지 않음** |
| 1단계에서 「안 들렸어요」를 골랐다 | 세부 점수 「순음」에만 반영. 최종 판정은 바뀌지 않음 |
| 2·3단계에서 틀렸다 | 그 층 맞힌 수가 줄어 「주의 / 흐릿」 판정이 날 수 있음 |
| 4단계에서 틀렸다 | 세부 점수 「대립쌍」에만 반영. 최종 판정은 바뀌지 않음 |

- 기록은 **최근 50회**까지 기기에 보관됩니다.
- 첫 화면의 「최근 탐사 기록」 카드는 가장 마지막 여정입니다.

## 8. 통계 「소리 찾기」 읽기

📊 연습 기록에서 **소리 찾기** 칸을 고르면 아래 세 카드가 보입니다.

```
┌───────────────────────────────┐
│ ┌───────────────────────────┐ │
│ │ 누적 탐사 요약              │ │  ① 지금까지 몇 번 했는지
│ │ 총 탐사 5 회 │ 최근 탐사 10월 20일│
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 최근 수심별 청취 상태        │ │  ② 마지막 여정의 층별 결과
│ │              10월 20일 14:05 기준│
│ │ ● 수면층 · 고대역 (3,350 ~ 7,000 Hz) [또렷]│
│ │   기준 4000Hz · ㄷ ㄸ ㅌ …   │ │
│ │ ● 중층 · 중대역 (…)   [흐릿] │ │
│ │ ● 심해층 · 저대역 (…) [또렷] │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 탐사 기록 이력              │ │  ③ 최근 10회
│ │ 10월 20일 14:05 [저:또렷][중:흐릿][고:또렷]│
│ │ 10월 18일 09:30 [저:또렷][중:또렷][고:또렷]│
│ └───────────────────────────┘ │
└───────────────────────────────┘
```

| 카드 | 읽는 법 |
|---|---|
| ① 누적 탐사 요약 | 끝까지 마친 여정 수와 가장 최근 날짜 |
| ② 최근 수심별 청취 상태 | **가장 최근 1회**의 층별 결과. 기준 소리 높이와 그 층 자음 |
| ③ 탐사 기록 이력 | 한 줄이 한 번. `저` = 심해층(저대역), `중` = 중층, `고` = 수면층(고대역) |

- 판정 글자는 **또렷 · 주의 · 흐릿**입니다. (이력 줄에서는 앞 두 글자만)
- 여러 번 해서 같은 층이 **계속 흐릿**이면 그 층을 집중 연습하세요.

## 9. 잘 하는 요령

- 조용한 곳에서 **이어폰**으로 하세요. 작은 「삐—」와 높은 자음(ㅅ·ㅈ·ㅊ)은 스피커로는 잘 안 들립니다.
- 1단계는 **정직하게** 고르세요. 들린 것 같은지 애매하면 「다시 듣기」를 눌러 확인하세요.
- 2·3단계에서 헷갈리면 **다시 듣기**를 써도 됩니다. 몇 번 들어도 점수에 불리하지 않습니다.
- 결과에서 흐릿한 층이 나오면 **▶ 연습**과 **추천 연습 단어 쌍** 비교 듣기를 함께 해 보세요.
- 한 달에 한 번쯤 **다시 측정하기**로 변화를 확인하세요.

## 10. 자주 묻는 질문

**Q. 2단계 뒤에 바로 결과가 나왔어요.**
세 층이 모두 또렷하면 3·4단계를 건너뜁니다. 정상입니다.

**Q. 4단계가 안 나왔어요.**
3단계에서 모두 회복했거나, 비교할 또렷한 층이 없으면(모든 층이 흐릿) 4단계는 나오지 않습니다.

**Q. 4단계를 많이 틀렸는데 결과는 또렷이에요.**
4단계는 참고 점수라 최종 판정을 바꾸지 않습니다. 세부 점수의 「대립쌍」으로 확인하세요.

**Q. 연습을 했는데 통계가 그대로예요.**
흐릿한 층 연습은 기록에 남지 않습니다. 변화를 보려면 **다시 측정하기**로 여정을 새로 하세요.

**Q. 「주의」는 언제 나오나요?**
2단계에서 5개 중 3개를 맞힌 층입니다. 보통은 3단계를 거쳐 또렷 / 흐릿으로 바뀝니다.

**Q. 이 결과가 청력 검사인가요?**
아니요. 일상적 청능 훈련과 자가 점검용 기록입니다. 병원의 청력 진단(PTA/WRS)을 대신하지 않습니다.
