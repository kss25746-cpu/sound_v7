# 문장 듣기 가이드

「말소리」 탭의 **문장 듣기**를 하는 방법을 안내합니다.
「아버지가 전화 받아요」 같은 **짧은 문장**을 듣고, **그림 세 장** 중에서 들은 내용과 같은 그림을 고르는 연습입니다.
한 판은 **9문항** 또는 **18문항**이고, 끝까지 풀면 기록이 남습니다.

> 들어가는 곳: **말소리** 탭 → **문장 듣기** 카드
> 나가는 곳: 첫 화면·결과 화면의 **뒤로 가기**, 또는 휴대폰 뒤로가기

```
   첫 화면: 9문항 / 18문항 고르기 → 시작
        │
        ▼
   문장 듣기 → 그림 3장 중 고르기 → 맞았어요 / 아쉬워요 → 다음
        │  9번 또는 18번
        ▼
   「문장 ○개를 들었어요」 → 기기에 기록
        │
        ▼
   📊 통계 「문장 듣기」에서 맞힌 비율 변화 보기
```

---

## 1. 문장과 그림 9장

문장은 **누가(3명) × 무엇을 하나(3가지)** 를 엮은 9개입니다. 그림도 9장이 짝을 이룹니다.

| | 📞 전화 받아요 | 💊 약 먹어요 | ☂ 우산 써요 |
|---|---|---|---|
| **아버지가** | 아버지가 전화 받아요 | 아버지가 약 먹어요 | 아버지가 우산 써요 |
| **어머니가** | 어머니가 전화 받아요 | 어머니가 약 먹어요 | 어머니가 우산 써요 |
| **집배원이** | 집배원이 전화 받아요 | 집배원이 약 먹어요 | 집배원이 우산 써요 |

- 소리는 미리 만들어 둔 음성 파일입니다. 휴대폰의 한국어 음성 설정이 필요 없습니다.
- 보기 그림에는 **글자가 없습니다.** 그림만 보고 고릅니다.

### 문항의 두 종류

한 문항의 그림 세 장은 위 표의 **한 줄**이거나 **한 칸**입니다.

| 종류 | 그림 세 장 | 구별할 것 | 예 |
|---|---|---|---|
| **행동 고르기** | 같은 사람, 행동만 다름 (표의 가로 한 줄) | **무엇을 하나** | 아버지가 전화 / 약 / 우산 |
| **사람 고르기** | 같은 행동, 사람만 다름 (표의 세로 한 칸) | **누가** | 아버지 / 어머니 / 집배원이 약 먹어요 |

- 전체는 행동 고르기 9문항 + 사람 고르기 9문항 = **18문항**입니다.
- **18문항**을 고르면 18개 모두, **9문항**을 고르면 18개를 섞은 것 중 앞의 9개가 나옵니다.
- 문항 순서와 그림 세 장의 자리는 판마다 섞입니다.

## 2. 첫 화면

```
┌───────────────────────────────┐
│ 문장 듣기               🎧  📊  │  ← 듣기 준비 · 통계
│ 들은 문장을 그림에서 고르는 연습 ·│
│ 병원 검사가 아니에요             │
│ ┌───────────────────────────┐ │
│ │ 이렇게 연습해요              │ │
│ │ 짧은 문장을 들려 줘요. 그림   │ │
│ │ 세 장 중에서 들은 내용과 같은 │ │
│ │ 그림을 고르면 됩니다. 점수를  │ │
│ │ 매기는 검사가 아니에요.       │ │
│ │ ┌──────────┬──────────┐   │ │
│ │ │  9문항   │  18문항   │   │ │  ← 문항 수 (처음에는 9문항)
│ │ └──────────┴──────────┘   │ │
│ └───────────────────────────┘ │
│  (그림 6장 미리보기)             │  ← 9장 중 무작위 6장
│     [  시작  ]  [ 뒤로 가기 ]    │
└───────────────────────────────┘
```

- 아래 그림 6장은 **어떤 그림이 나오는지 미리 보는** 것입니다. 눌러도 아무 일이 없습니다.
- 🎧 [듣기 준비](../0_공통/듣기%20준비%20가이드.md), 📊 [연습 기록](../0_공통/연습%20기록%20가이드.md)(「문장 듣기」 칸)
- 두 아이콘은 첫 화면과 결과 화면에서만 보입니다.

## 3. 한 문항의 흐름

```
┌───────────────────────────────┐
│ 문장 듣기                       │
│ ████████░░░░░░░░░░░░░░░░░░░░  │  ← 진행 막대
│             ▮▮▮                │
│  들은 문장에 맞는 그림을 고르세요  │
│  ┌──────┐ ┌──────┐ ┌──────┐   │
│  │(그림1)│ │(그림2)│ │(그림3)│   │  ← 그림 3장
│  └──────┘ └──────┘ └──────┘   │
│            [ 중지 ]             │
└───────────────────────────────┘
```

1. **시작**을 누르면 「곧 들어요…」가 잠깐(0.7초) 나온 뒤 첫 문장이 나옵니다. (첫 문항에만 뜸이 있습니다)
2. 문장이 나오는 동안은 「듣는 중… 소리가 끝난 뒤 고르세요」이고 그림이 잠겨 있습니다.
3. 끝나면 「들은 문장에 맞는 그림을 고르세요」. 그림 하나를 누릅니다.
4. 결과가 나옵니다.
   - 맞았으면 「**맞았어요**」
   - 틀렸으면 「**아쉬워요 · 맞는 그림을 표시했어요**」 그리고 **정답 그림에 파란 테두리**
5. **다음**을 누르면 다음 문장이 나옵니다. **끝내기**로 그만둘 수도 있습니다.

- **다시 듣기는 없습니다.** 한 번 듣고 고르는 연습입니다.

### 중간에 멈추고 싶을 때

| 지금 상태 | 버튼 | 일어나는 일 |
|---|---|---|
| 문장 나오는 중 | **중지** | 소리가 바로 멈추고 「연습 끝내기 — 여기서 끝낼까요?」. **취소**하면 그 문장을 **처음부터 다시** 들려줍니다 |
| 고르는 중 (다 들은 뒤) | **중지** | 같은 확인 창. **취소**하면 그대로 고르기로. **다시 들려주지 않습니다** |
| 답을 고른 뒤 | **끝내기** | 같은 확인 창 |

- 확인 창에서 **끝내기** → 결과 화면
- 휴대폰 뒤로가기는 진행 중에 같은 확인 창을 띄웁니다.
- 앱을 내리거나 전화가 오면 소리가 끊기고 진행이 멈춥니다.

## 4. 결과 화면

```
┌───────────────────────────────┐
│ 문장 듣기               🎧  📊  │
│   ✓ 오늘 연습 끝                 │
│ ┌───────────────────────────┐ │
│ │ 문장 18개를 들었어요         │ │
│ │ 기기에 기록했어요            │ │
│ └───────────────────────────┘ │
│ [다시 연습] [처음으로] [뒤로 가기]│
└───────────────────────────────┘
```

결과 화면에는 **맞힌 개수나 비율이 나오지 않습니다.** 몇 문장을 들었는지만 알려 줍니다. 맞힌 비율은 📊 통계에서 봅니다.

| 문구 | 뜻 |
|---|---|
| **문장 ○개를 들었어요** + 기기에 기록했어요 | 고른 문항 수(9 또는 18)를 끝까지 풀어 기록했습니다 |
| **○개를 고르고 마쳤어요. ○개를 다 고르지 않아 기록에는 안 남겼어요** | 중간에 끝내서 기록하지 않았습니다 |
| 연습이 짧아서 기록할 내용이 없어요 | 한 문항도 고르지 않고 끝냈습니다 |
| 기록에 남기지 못했어요 | 저장 중 문제가 생겼습니다 |

| 버튼 | 하는 일 |
|---|---|
| **다시 연습** | 같은 문항 수로 바로 새 판 |
| **처음으로** | 첫 화면으로 (문항 수를 바꿀 수 있습니다) |
| **뒤로 가기** | 말소리 탭 목록으로 |

## 5. 내 동작이 기록에 어떻게 남나요?

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 9문항 또는 18문항을 끝까지 풀었다 | 한 판 기록 1개: 날짜·시각, 맞힌 수 / 푼 수, 맞힌 비율 |
| 중간에 끝냈다 | **남지 않음** |
| 문항 하나를 맞혔다 / 틀렸다 | 그 판의 맞힌 수에만 더해집니다. 어떤 문장을 틀렸는지는 남지 않습니다 |

- 맞힌 비율은 반올림한 정수입니다. 예: 16/18 = 89%, 8/9 = 89%
- 기록은 **최근 50판**까지 보관됩니다.
- 9문항 판과 18문항 판은 같은 목록에 쌓입니다.

## 6. 통계 「문장 듣기」 읽기

📊 연습 기록의 **문장 듣기** 칸은 [한 글자](한%20글자%20가이드.md)와 같은 모양입니다.

| 카드 | 읽는 법 |
|---|---|
| **맞힌 비율 변화** | 기록 2회부터. 판마다 맞힌 비율을 날짜 순서로 잇는 그래프. 위가 많이 맞힘 |
| **최근 연습** | 최근 8판. `10/20 14:05   16/18 · 약 89%` = 그 날짜·시각에 18문항 중 16개 맞힘 |

- 9문항 판은 한 문항이 약 11%, 18문항 판은 약 6%라 **9문항 판의 그래프가 더 크게 출렁입니다.** 같은 문항 수 판끼리 비교하세요.
- 그래프는 보관된 판(최대 50판)을 **모두** 그립니다. 최근 연습처럼 8판으로 자르지 않습니다.
- 가로축은 판 번호가 아니라 **연습한 시각**입니다. 같은 날 여러 판을 하면 점이 붙고, 며칠 쉬면 간격이 벌어집니다.
- 12판까지는 판마다 점이 찍힙니다. 그보다 많으면 첫 판과 최근 판에만 점이 찍히고 나머지는 선으로만 이어집니다.
- 50판을 넘으면 가장 오래된 판부터 지워지므로 그래프 왼쪽 끝이 앞으로 밀려납니다.

## 7. 잘 하는 요령

- 그림 세 장을 먼저 훑어 **사람이 다른지, 행동이 다른지** 확인하세요. 그러면 문장의 **앞부분(누가)** 과 **뒷부분(무엇을)** 중 어디에 귀를 모을지 정할 수 있습니다.
  - 사람만 다르면 → 「아버지가 / 어머니가 / 집배원이」
  - 행동만 다르면 → 「전화 받아요 / 약 먹어요 / 우산 써요」
- 단어 하나가 아니라 **문장 전체의 흐름**을 들으세요. 일상 대화를 알아듣는 연습입니다.
- 쉽게 다 맞힌다면 소음이 조금 있는 곳(거실 등)에서 해 보는 것도 좋은 연습입니다. 단, 기록을 비교할 때는 같은 환경끼리 비교하세요.

## 8. 자주 묻는 질문

**Q. 결과 화면에 점수가 없어요.**
결과 화면은 들은 문장 수만 보여 줍니다. 맞힌 비율은 📊 통계 「문장 듣기」에서 확인하세요.

**Q. 같은 문장이 또 나와요.**
문장이 9개뿐이라 18문항 판에서는 같은 문장이 **두 번**(한 번은 행동 고르기, 한 번은 사람 고르기) 나옵니다.

**Q. 다시 듣고 싶어요.**
이 연습은 한 번 듣고 고릅니다. 문장이 나오는 도중에 **중지 → 취소**를 누르면 처음부터 다시 들려주지만, 다 들은 뒤에는 다시 들을 수 없습니다.

**Q. 이 결과가 문장 인지 검사인가요?**
아니요. 연습 기록입니다. 병원 검사나 진단을 대신하지 않습니다.
