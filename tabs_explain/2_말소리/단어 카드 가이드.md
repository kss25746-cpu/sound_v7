# 단어 카드 가이드

「말소리」 탭의 **단어 카드**를 하는 방법을 안내합니다.
카드 한 장에 **소리가 비슷한 단어 두 개**(예: 물 / 불)가 있습니다. 두 단어를 눌러 **번갈아 들으며 차이를 익히는** 연습입니다.
문제를 맞히는 연습이 아니라, 스스로 듣고 넘기는 **학습 카드**입니다. 다 익힌 카드는 「학습완료」로 치워 둡니다.

> 들어가는 곳: **말소리** 탭 → **단어 카드** 카드
> 나가는 곳: 왼쪽 위 **← (나가기)** 버튼, 또는 휴대폰 뒤로가기

```
   단어 카드 (20장)
        │
        ▼
   카드 한 장: [단어1] VS [단어2]
        │  눌러서 하나씩 듣기 · 「전체 듣기」로 이어서 듣기
        ▼
   ◀ 이전 · ▶ 다음 으로 넘기기
        │
        ├── 익혔으면 「학습완료」 → 카드가 오른쪽 위 「○ 개 익힘」 배지로 날아감
        │                        (다음부터 목록에서 빠짐)
        ▼
   모두 학습완료 → 🏆 「학습을 완료하였습니다!」 → 처음부터
```

---

## 1. 화면 구성

```
┌───────────────────────────────┐
│ [←]   📚 단어 카드   [✔ 3 개 익힘]│  ← 나가기 · 제목 · 익힘 배지
│                               │
│  ●━━━━━━●─┼─┼─┼─┼─┼─┼─┼─┼─      │  ← 진행바 (눈금 = 카드 1장)
│          [ 2 / 17 ]            │  ← 지금 카드 / 남은 카드 수
│ ┌───────────────────────────┐ │
│ │ ┌────────┐     ┌────────┐ │ │
│ │ │   물   │ VS  │   불   │ │ │  ← 단어 두 개
│ │ │  ( ▶ ) │     │  ( ▶ ) │ │ │     (눌러서 듣기)
│ │ └────────┘     └────────┘ │ │
│ │     ∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿       │ │  ← 소리 나는 동안 파형
│ │     [ ▶ 전체 듣기 ]         │ │
│ └───────────────────────────┘ │
│                               │
│   ( ◀ )   [ 학습완료 ]   ( ▶ )  │  ← 하단 넘기기 버튼
└───────────────────────────────┘
```

| 부분 | 하는 일 |
|---|---|
| **← (왼쪽 위)** | 말소리 탭 목록으로 나갑니다 |
| **✔ ○ 개 익힘** | 학습완료한 카드 수. 1개 이상이면 눌러서 목록을 엽니다 (4절) |
| **진행바 · ○ / ○** | 남은 카드 중 몇 번째인지. 눈금 하나가 카드 한 장입니다 |
| **단어 두 개** | 누르면 그 단어 소리가 납니다 |
| **전체 듣기** | 단어1 → (잠깐) → 단어2를 이어서 들려줍니다 |
| **◀ · ▶** | 이전 · 다음 카드. 첫 카드에서는 ◀, 마지막 카드에서는 ▶가 흐리게 잠깁니다 |
| **학습완료** | 지금 카드를 「익힘」으로 치웁니다 |

- 카드를 **손가락으로 밀어 넘기는 기능은 없습니다.** ◀ · ▶ 버튼으로만 넘깁니다.
- 이 화면에는 🎧 듣기 준비, 📊 통계 아이콘이 없습니다.

---

## 2. 카드 듣는 법

1. 단어 하나를 누르면 그 단어 소리가 납니다. 소리가 나는 동안 그 단어 칸이 강조되고 아래에 **파형**이 움직입니다.
2. 다른 단어를 눌러 비교합니다. 몇 번이든 번갈아 들을 수 있습니다.
3. **전체 듣기**를 누르면 단어1을 들려주고, 끝나면 **0.3초** 쉬고 단어2를 들려줍니다.
   - 이어서 듣는 동안 버튼이 「재생 중...」으로 바뀌고, 지금 소리 나는 단어만 강조되고 다른 단어는 흐려집니다.
   - 전체 듣기 중에는 단어를 따로 누를 수 없습니다.

> 💡 처음에는 **글자를 보면서** 들어 차이를 익히고, 익숙해지면 **눈을 감고 전체 듣기**로 들어 어느 쪽이 먼저 나왔는지 떠올려 보세요.

---

## 3. 카드 목록 (20장)

카드는 아래 순서로 나옵니다. 앞 10장이 쉬운 짝, 뒤 10장이 조금 더 어려운 짝입니다.

| 쉬운 짝 (10장) | 조금 어려운 짝 (10장) |
|---|---|
| 물 / 불 | 머리 / 멀리 |
| 산 / 살 | 길 / 빌 |
| 코 / 쿠 | 칼 / 탈 |
| 사 / 싸 | 문 / 민 |
| 달 / 탈 | 돌 / 놀 |
| 눈 / 룬 | 손 / 돈 |
| 나 / 라 | 말 / 멀 |
| 밤 / 밥 | 비 / 피 |
| 고기 / 도기 | 닭 / 달 |
| 가 / 카 | 봄 / 몸 |

- 두 단어는 **한 소리만** 다릅니다. 예: 물 / 불은 첫소리(ㅁ · ㅂ), 밤 / 밥은 받침(ㅁ · ㅂ), 문 / 민은 모음(ㅜ · ㅣ)
- 소리는 미리 만들어 둔 음성 파일이라 휴대폰의 한국어 음성 설정이 필요 없습니다.

## 4. 학습완료와 익힘 목록

### 학습완료

**학습완료**를 누르면 지금 카드가 빙글 돌며 오른쪽 위 **익힘 배지**로 날아가 사라집니다.

- 그 카드는 **목록에서 빠지고**, 남은 카드 수(○ / ○의 뒤 숫자)가 1 줄어듭니다.
- 익힘 배지의 숫자가 1 늘어납니다.
- 이 기록은 **기기에 저장**되어, 화면을 나갔다 들어와도, 앱을 껐다 켜도 남습니다.

### 모두 익혔을 때

남은 카드가 없으면 카드 자리에 🏆 「**학습을 완료하였습니다!** 모든 카드를 성공적으로 학습했습니다.」와 **처음부터** 버튼이 나옵니다.
**처음부터**를 누르면 익힘 기록이 모두 지워지고 20장이 다시 나옵니다.

### 익힘 목록 (배지 누르기)

```
┌───────────────────────────────┐
│           ─────                │
│ 학습 완료된 카드 (3)        ✕   │
│ ┌───────────────────────────┐ │
│ │ 물 / 불           ↶ 되돌리기 │ │  ← 누르면 다시 학습 목록으로
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 산 / 살           ↶ 되돌리기 │ │
│ └───────────────────────────┘ │
│       [ 🔄 전체 다시 하기 ]      │  ← 익힘 기록 모두 지우기
└───────────────────────────────┘
```

| 하는 일 | 이렇게 하세요 |
|---|---|
| 한 장만 다시 공부하기 | 그 항목을 누릅니다. 목록에서 빠지고 **학습 카드 맨 뒤**에 다시 붙습니다 |
| 전부 처음부터 | **전체 다시 하기**. 익힘 기록이 모두 지워지고 20장이 처음 순서로 돌아옵니다 |
| 닫기 | ✕, 바깥 어두운 곳, 또는 휴대폰 뒤로가기 |

## 5. 내 동작이 기록에 어떻게 남나요?

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 단어를 듣기 · 전체 듣기 | 남지 않음 |
| ◀ · ▶로 넘기기 | 남지 않음. 화면을 나갔다 오면 **첫 카드**부터 다시 보입니다 |
| **학습완료** | 그 카드가 「익힘」으로 기기에 저장 |
| 익힘 목록에서 **되돌리기** | 그 카드의 익힘 표시가 지워짐 |
| **처음부터 · 전체 다시 하기** | 익힘 기록 전부 지워짐 |

- 단어 카드는 맞힌 수·비율이 없습니다. 📊 연습 기록에도 나오지 않습니다.
- 남는 것은 **어떤 카드를 익혔는지**뿐입니다.

---

## 6. 잘 하는 요령

- 한 카드에서 **두 단어를 3~4번씩 번갈아** 들어 보세요. 차이가 귀에 붙으면 학습완료.
- 「전체 듣기」를 듣고 **어느 쪽이 먼저였는지** 글자를 보지 않고 떠올려 보세요. 맞히면 그 카드는 익힌 것입니다.
- 쉬운 짝 10장을 먼저 익히고, 뒤쪽 어려운 짝으로 넘어가세요. 카드 순서도 그렇게 되어 있습니다.
- 다른 연습([두 글자](두%20글자%20가이드.md), [한 글자](한%20글자%20가이드.md))에서 자꾸 틀리는 소리가 있으면, 익힘 목록에서 그 소리가 든 카드를 **되돌려** 다시 들어 보세요.

## 7. 자주 묻는 질문

**Q. 카드를 밀어서 넘길 수 없나요?**
없습니다. 아래 ◀ · ▶ 버튼으로 넘기세요.

**Q. 나갔다 들어오니 첫 카드부터 나와요.**
보던 위치는 저장하지 않습니다. 익힌 카드는 빠진 채로 남으므로, 남은 카드의 첫 장부터 보입니다.

**Q. 학습완료를 잘못 눌렀어요.**
오른쪽 위 **익힘 배지**를 눌러 목록에서 그 카드를 누르면 되돌아옵니다. (학습 카드 맨 뒤에 붙습니다)

**Q. 익힘 배지를 눌러도 아무 일이 없어요.**
익힌 카드가 0개면 배지가 잠겨 있습니다.

**Q. 소리가 안 나요.**
[듣기 준비](../0_공통/듣기%20준비%20가이드.md)에서 기기 소리를 확인하세요. 단어 카드는 휴대폰 볼륨을 그대로 씁니다.
