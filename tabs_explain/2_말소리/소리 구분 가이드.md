# 소리 구분 가이드

「말소리」 탭의 **소리 구분**을 하는 방법을 안내합니다.
짧은 말소리 **6개 — 음 · 우 · 아 · 이 · 쉬 · 스** — 중 하나를 듣고, 어떤 소리였는지 **그림에서** 고르는 연습입니다.
가끔 **아무 소리도 나지 않는** 문항이 섞여 있습니다. 그때는 「못 들었어요」를 누릅니다.
하루에 한 번씩 하면 날짜별로 「6개 중 몇 개를 맞혔는지」가 쌓입니다.

> 들어가는 곳: **말소리** 탭 → **소리 구분** 카드
> 나가는 곳: 첫 화면·결과 화면의 **뒤로 가기**, 또는 휴대폰 뒤로가기

```
   첫 화면 「이렇게 연습해요」 → 시작
        │
        ▼
   소리 1초 듣기 (또는 1초 동안 아무 소리 없음)
        │  그림 6개 + 「못 들었어요」 중에서 고르기
        ▼
   맞았어요 / 아쉬워요 · 정답은 ○ → 다음   ── 8번 (소리 6 + 무음 2)
        │
        ▼
   「이번 기록에서 6개 중 ○개를 맞혔어요」 → 오늘 날짜로 기록
        │
        ▼
   📊 통계 「소리 구분」에서 날짜별 변화 · 자주 놓치는 소리 보기
```

---

## 1. 여섯 소리

| 화면 글자 | 소리 | 특징 |
|---|---|---|
| **음** | /m/ | 입을 다물고 내는 콧소리. 낮은 소리 |
| **우** | /u/ | 낮은 모음 |
| **아** | /a/ | 가운데 높이 모음 |
| **이** | /i/ | 높은 성분이 있는 모음 |
| **쉬** | /ʃ/ | 「쉬—」 하는 바람 소리. **높은 소리** |
| **스** | /s/ | 「스—」 하는 바람 소리. **가장 높은 소리** |

- 여섯 소리는 모두 **길이 1초, 크기가 같게** 맞춰져 있습니다. 길이나 크기로는 구분할 수 없습니다.
- 「무음」 문항도 **똑같이 1초** 기다립니다. 기다리는 시간으로 무음을 알아챌 수 없습니다.
- 통계 화면에서는 소리를 `/m/ · /u/ · /a/ · /i/ · /ʃ/ · /s/` 기호로 씁니다.

## 3. 한 문항의 흐름

```
┌───────────────────────────────┐
│ 소리 구분                       │
│ ████████░░░░░░░░░░░░░░░░░░░░  │  ← 진행 막대 (8칸)
│             ▮▮▮                │
│   듣는 중… 소리가 끝난 뒤 고르세요 │
│  ┌──────┐┌──────┐┌──────┐     │
│  │ (그림)││ (그림)││ (그림)│     │  ← 그림 6개
│  │  음  ││  우  ││  아  │     │     (자리는 늘 같음)
│  └──────┘└──────┘└──────┘     │
│  ┌──────┐┌──────┐┌──────┐     │
│  │ (그림)││ (그림)││ (그림)│     │
│  │  이  ││  쉬  ││  스  │     │
│  └──────┘└──────┘└──────┘     │
│  ┌───────────────────────────┐ │
│  │        못 들었어요          │ │  ← 소리가 안 났을 때
│  └───────────────────────────┘ │
│            [ 중지 ]             │
└───────────────────────────────┘
```

1. **시작**을 누르면 「곧 들어요…」가 잠깐(0.7초) 나온 뒤 첫 소리가 납니다. (첫 문항에만 뜸이 있습니다)
2. 소리가 나는 **1초** 동안은 「듣는 중… 소리가 끝난 뒤 고르세요」이고 보기가 잠겨 있습니다.
3. 소리가 끝나면 「들은 소리를 고르세요」로 바뀝니다. 그림 6개나 **못 들었어요** 중 하나를 누릅니다.
4. 바로 결과가 나옵니다.
   - 맞았으면 「**맞았어요**」
   - 틀렸으면 「**아쉬워요 · 정답은 ○**」 그리고 **정답 칸에 파란 테두리**가 생깁니다. (무음 문항이었다면 「정답은 못 들었어요」, 「못 들었어요」 버튼에 테두리)
5. 아래 버튼이 **다음 · 끝내기**로 바뀝니다. **다음**을 누르면 다음 문항 소리가 납니다.
6. 8번째 문항 뒤 **다음**을 누르면 결과 화면으로 갑니다.

- 한 판은 **8문항**입니다. 여섯 소리가 **한 번씩**, 그리고 **무음 2번**이 무작위 자리에 섞입니다. 첫 문항은 항상 소리입니다.
- 그림 6개의 **자리는 늘 같습니다.** 문제 순서만 섞입니다.
- **다시 듣기는 없습니다.** 한 번 듣고 고르세요.

### 중간에 멈추고 싶을 때

| 지금 상태 | 버튼 | 일어나는 일 |
|---|---|---|
| 소리 나는 중 / 고르는 중 | **중지** | 소리가 바로 멈추고 「연습 끝내기 — 여기서 끝낼까요?」 |
| 답을 고른 뒤 | **끝내기** | 같은 확인 창 |

- **끝내기** → 결과 화면으로 갑니다.
- **취소** → 이어 합니다. 중지로 멈췄다면 **그 문항 소리를 다시** 들려줍니다.
- 휴대폰 뒤로가기는 진행 중에 같은 확인 창을 띄웁니다.
- 앱을 내리거나 전화가 오면 소리가 끊기고 진행이 멈춥니다. 듣지 못한 문항이 혼자 넘어가지 않습니다.

## 4. 결과 화면

```
┌───────────────────────────────┐
│ 소리 구분               🎧  📊  │
│   ✓ 오늘 연습이 끝났어요         │
│ ┌───────────────────────────┐ │
│ │ 이번 기록에서 6개 중 5개를   │ │  ← 맞힌 소리 수
│ │ 맞혔어요                    │ │
│ │ 지난 기록보다 1개 늘었어요    │ │  ← 지난 날과 비교
│ │ 고음(/s/·/ʃ/)이 지난주보다   │ │  ← 높은 소리가 좋아졌을 때만
│ │ 좋아지고 있어요              │ │
│ │ 연습 기록이에요. 청력 검사·   │ │
│ │ 진단 결과가 아니에요.         │ │
│ └───────────────────────────┘ │
│     [ ✓ 기기에 기록했어요 ]      │
│ [다시 연습] [처음으로] [뒤로 가기]│
└───────────────────────────────┘
```

### 맞힌 수

「6개 중 ○개」는 **여섯 소리 문항만** 셉니다. 무음 2문항은 이 숫자에 들어가지 않습니다.

### 비교 문구

| 문구 | 언제 나오나요 |
|---|---|
| 지난 기록보다 ○개 늘었어요 / 줄었어요 | **오늘이 아닌 가장 최근 날짜** 기록과 비교했을 때 |
| 지난 기록과 같은 개수를 맞혔어요 | 그 날과 개수가 같을 때 |
| (비교 문구 없음) | 처음 기록하는 날 |
| 고음(/s/·/ʃ/)이 지난주보다 좋아지고 있어요 | **6일 이상 전** 기록보다 「쉬 · 스」를 더 많이 맞혔을 때만 |

### 저장 문구

| 문구 | 뜻 |
|---|---|
| **기기에 기록했어요** | 오늘 날짜로 기록했습니다 |
| **6음을 다 고르지 않아 날짜 기록에는 안 남겼어요** | 여섯 소리 문항을 다 풀기 전에 끝냈습니다. 맞힌 수도 나오지 않습니다 |
| 기록에 남기지 못했어요 | 저장 중 문제가 생겼습니다 |

### 결과 화면 버튼

| 버튼 | 하는 일 |
|---|---|
| **다시 연습** | 바로 새 판 시작 |
| **처음으로** | 첫 화면으로 |
| **뒤로 가기** | 말소리 탭 목록으로 |

## 5. 내 동작이 기록에 어떻게 남나요?

기록은 **하루에 하나**입니다.

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 여섯 소리 문항을 모두 풀었다 | **오늘 날짜** 기록: 여섯 소리 각각 맞음/틀림, 맞힌 수(0~6) |
| 같은 날 또 했다 | 오늘 기록을 **새 결과로 덮어씁니다.** 하루에 한 줄만 남습니다 |
| 여섯 소리를 다 풀기 전에 끝냈다 | **남지 않음** |
| 무음 문항에서 그림을 골랐다 / 「못 들었어요」를 골랐다 | 그 판 화면에만 맞음·틀림이 나옵니다. **기록에는 들어가지 않습니다** |
| 소리 문항에서 「못 들었어요」를 골랐다 | 그 소리를 **틀린 것**으로 기록 |

- 무음 문항은 **아무 소리나 찍지 않고 정말 들었는지** 확인하는 장치입니다.
- 날짜 기록은 **최근 50일**까지 보관됩니다.

> 💡 같은 날 여러 번 하면 **마지막 판**이 그날 기록이 됩니다. 연습 삼아 여러 번 한 뒤, 집중해서 한 판을 마지막으로 하세요.

## 6. 통계 「소리 구분」 읽기

📊 연습 기록에서 **소리 구분** 칸을 고르면 아래가 보입니다.

```
┌───────────────────────────────┐
│ (🎤) 소리 구분  기록 9회         │
│ ┌───────────────────────────┐ │
│ │ 최근 7번                    │ │  ① 7일치 기록이 생기면
│ │  ▁   ▁   ▂   ▁   ▆   ▇     │ │     소리마다 놓친 횟수
│ │ /m/ /u/ /a/ /i/ /ʃ/ /s/    │ │
│ │ 요즘 /ʃ/·/s/가 아쉬운 날이   │ │
│ │ 많아요                      │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 맞힌 개수 변화               │ │  ② 날짜별 맞힌 수
│ │ 높을수록 더 많이 맞춤         │ │     (0~6)
│ │  6 ┼──────●───●─────●      │ │
│ │  3 ┼──●                     │ │
│ │  0 ┼────────────────        │ │
│ │ 10/1      기록 0~6     10/20 │ │
│ └───────────────────────────┘ │
│      소리 구분 기록 지우기        │
└───────────────────────────────┘
```

### ① 최근 7번

- 날짜 기록이 **7개 이상** 쌓여야 나옵니다.
- **최근 7개 날짜** 동안 소리마다 **몇 번 틀렸는지**를 막대로 보여 줍니다. 막대가 높을수록 자주 놓친 소리입니다.
- 7번 중 **4번 이상** 틀린 소리가 있으면 막대가 강조되고 「**요즘 /○/가 아쉬운 날이 많아요**」가 나옵니다.
- 그런 소리가 없으면 문구는 나오지 않습니다.

### ② 맞힌 개수 변화

- 가로는 **날짜**, 세로는 그날 **맞힌 소리 수(0~6)** 입니다. 위로 갈수록 많이 맞힌 날입니다.
- 기록이 하루뿐이면 그래프 대신 「**내일 또 하면 선이 생겨요**」가 나옵니다.
- 맨 오른쪽 크게 테두리 친 점이 가장 최근 날입니다. 기록이 12개를 넘으면 중간 점은 숨기고 선만 이어집니다.
- 하루를 건너뛰면 그만큼 가로 간격이 벌어집니다.

## 7. 잘 하는 요령

- **매일 같은 시간, 같은 이어폰**으로 한 판씩 하세요. 날짜별 기록이라 꾸준할수록 그래프가 쓸모 있어집니다.
- 「쉬」와 「스」는 둘 다 바람 소리라 헷갈리기 쉽습니다. 「쉬」는 조금 더 낮고 넓게, 「스」는 더 높고 가늘게 들립니다.
- 「음」과 「우」도 낮은 소리끼리 헷갈리기 쉽습니다. 「음」은 입을 다문 콧소리입니다.
- 소리가 **정말 안 들렸으면** 망설이지 말고 「못 들었어요」를 누르세요. 찍어서 맞히는 것보다 정확한 기록이 됩니다.
- 통계 「최근 7번」에서 강조된 소리가 있으면, 그 소리가 든 말을 [두 글자](두%20글자%20가이드.md)·[빙고](빙고%20가이드.md)로도 연습해 보세요.

## 8. 자주 묻는 질문

**Q. 8문항인데 왜 「6개 중」이라고 나오나요?**
무음 2문항은 확인용이라 맞힌 수에 넣지 않습니다.

**Q. 오늘 두 번 했는데 기록은 하나예요.**
하루에 한 기록만 남습니다. 마지막 판으로 덮어씁니다.

**Q. 소리가 안 났는데 오답이래요.**
그 문항은 소리가 있었는데 들리지 않았을 수 있습니다. [듣기 준비](../0_공통/듣기%20준비%20가이드.md)로 볼륨을 확인하세요. 젠더가 소리 앞부분을 자를 수도 있습니다.

**Q. 「최근 7번」이 안 보여요.**
날짜 기록이 7개가 되어야 나옵니다. 하루에 한 번씩 7일을 채우세요.

**Q. 이 결과가 청력 검사인가요?**
아니요. 연습 기록입니다. 병원 검사나 진단을 대신하지 않습니다.
