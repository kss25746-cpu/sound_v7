# 두 글자 가이드

「말소리」 탭의 **두 글자**를 하는 방법을 안내합니다.
「편지 · 사람 · 그림」 같은 **두 글자 단어** 하나를 기계 목소리가 읽어 줍니다. 보기 4개 중에서 들은 단어를 고르는 연습입니다.
보기 중 하나는 **소리가 아주 비슷한 단어**(예: 편지 ↔ 먼지)입니다. 한 판은 **12문항**이고, 끝까지 풀면 맞힌 비율이 기록됩니다.

> 들어가는 곳: **말소리** 탭 → **두 글자** 카드
> 나가는 곳: 첫 화면·결과 화면의 **뒤로 가기**, 또는 휴대폰 뒤로가기

```
   두 글자 카드
        │  (기기에 한국어 음성이 없으면 → 「한국어 음성이 없어요」 안내)
        ▼
   첫 화면 「한 번은 12개예요」 → 시작
        │  이번 차례의 단어 목록(1·2·3장 중 하나)으로 12문항
        ▼
   단어 듣기 → 보기 4개 중 고르기 → 맞았어요 / 아쉬워요 → 다음   ── 12번
        │
        ▼
   「12개 중 ○개를 맞혔어요 · 맞힌 비율 약 ○○%」 → 기기에 기록
        │  다음 판은 다음 장 목록으로
        ▼
   📊 통계 「두 글자」에서 변화 보기
```

---

## 1. 들어가기 전에 — 한국어 음성

두 글자는 휴대폰의 **한국어 음성 읽기(TTS)** 로 단어를 읽습니다.
기기에 한국어 음성이 없으면 연습 대신 「**한국어 음성이 없어요**」 안내가 열립니다. → [한국어 음성 안내](../0_공통/한국어%20음성%20안내%20가이드.md)

## 2. 첫 화면

```
┌───────────────────────────────┐
│ 두 글자                 🎧  📊  │  ← 듣기 준비 · 통계
│ 들은 단어를 보기에서 고르는 연습 ·│
│ 병원 검사가 아니에요             │
│ ┌───────────────────────────┐ │
│ │ 이렇게 연습해요              │ │
│ │ 두 글자 단어 하나를 읽어 줘요.│ │
│ │ 비슷한 소리 보기 네 개 중에서 │ │
│ │ 들은 단어를 고르면 됩니다.    │ │
│ │ 한 번은 12개예요. 목소리는    │ │
│ │ 기계음이라 사람 말과 다를 수  │ │
│ │ 있어요.                     │ │
│ └───────────────────────────┘ │
│     [  시작  ]  [ 뒤로 가기 ]    │
└───────────────────────────────┘
```

- 문항 수는 **12개로 고정**입니다. (한 글자와 달리 고르는 칸이 없습니다)
- 🎧 [듣기 준비](../0_공통/듣기%20준비%20가이드.md), 📊 [연습 기록](../0_공통/연습%20기록%20가이드.md)(「두 글자」 칸)
- 두 아이콘은 첫 화면과 결과 화면에서만 보입니다.

---

## 3. 단어 목록 세 장

두 글자에는 **단어 목록이 세 장** 있고, 장마다 정답 단어 12개가 있습니다.

| 장 | 정답 단어 12개 |
|---|---|
| 1장 | 편지 · 달걀 · 시간 · 육군 · 신발 · 땅콩 · 안개 · 마음 · 허리 · 욕심 · 노래 · 저녁 |
| 2장 | 사람 · 토끼 · 병원 · 등대 · 논밭 · 과일 · 송곳 · 딸기 · 문제 · 나무 · 극장 · 가위 |
| 3장 | 그림 · 아들 · 팥죽 · 동생 · 목표 · 냄새 · 바다 · 자연 · 접시 · 권투 · 방석 · 느낌 |

- 한 판은 **한 장 전체**(12단어)를 섞은 순서로 냅니다.
- 판을 **끝까지 마칠 때마다 다음 장**으로 넘어갑니다. 1장 → 2장 → 3장 → 1장 …
- 중간에 끝낸 판은 기록되지 않으므로, 다음에 시작하면 **같은 장**이 다시 나옵니다.
- 화면에는 지금 몇 장인지 표시되지 않습니다.

## 4. 한 문항의 흐름

```
┌───────────────────────────────┐
│ 두 글자                         │
│ ██████░░░░░░░░░░░░░░░░░░░░░░  │  ← 진행 막대 (12칸)
│             ▮▮▮                │
│      들은 단어를 고르세요         │
│  ┌───────────┐ ┌───────────┐  │
│  │   먼지    │ │   땅콩    │  │  ← 보기 4개
│  └───────────┘ └───────────┘  │
│  ┌───────────┐ ┌───────────┐  │
│  │   편지    │ │   욕심    │  │
│  └───────────┘ └───────────┘  │
│            [ 중지 ]             │
└───────────────────────────────┘
```

1. **시작**을 누르면 「잠시 뒤 들려 드려요」가 잠깐(0.7초) 나온 뒤 첫 단어를 읽습니다.
2. 읽는 동안은 「듣는 중… 소리가 끝난 뒤 고르세요」이고 보기가 잠겨 있습니다.
3. 다 읽으면 「들은 단어를 고르세요」. 보기 4개 중 하나를 누릅니다.
4. 「**맞았어요**」 또는 「**아쉬워요 · 정답은 ○○**」(정답 보기에 파란 테두리)가 나옵니다.
5. **다음**을 누르면 다음 단어를 읽습니다. **끝내기**로 그만둘 수도 있습니다.

- **다시 듣기는 없습니다.** 한 번 듣고 고르는 연습입니다.

### 보기 4개의 구성

| 보기 | 어떤 단어 | 예 (정답 「편지」) |
|---|---|---|
| 정답 | 읽어 준 단어 | **편지** |
| 비슷한 오답 | 정답과 소리가 아주 비슷한 단어 (짝이 정해져 있음) | **먼지** |
| 다른 오답 2개 | 같은 장의 **다른 정답 단어** 중, 정답·비슷한 오답과 **글자가 겹치지 않는** 것 | 땅콩 · 욕심 |

- 그래서 실제로 헷갈리는 것은 **정답과 비슷한 오답 사이**입니다. 다른 두 개는 소리가 많이 달라 쉽게 지울 수 있습니다.
- 비슷한 오답 짝 예: 달걀 ↔ 달력, 마음 ↔ 마을, 사람 ↔ 사랑, 토끼 ↔ 도끼, 가위 ↔ 바위, 바다 ↔ 바닥

### 중간에 멈추고 싶을 때

| 지금 상태 | 버튼 | 일어나는 일 |
|---|---|---|
| 읽는 중 | **중지** | 소리가 바로 멈추고 「연습 끝내기 — 여기서 끝낼까요?」. **취소**하면 그 단어를 **처음부터 다시** 읽습니다 |
| 고르는 중 (다 읽은 뒤) | **중지** | 같은 확인 창. **취소**하면 그대로 고르기로. **다시 읽어 주지 않습니다** |
| 답을 고른 뒤 | **끝내기** | 같은 확인 창 |

- 확인 창에서 **끝내기** → 결과 화면
- 휴대폰 뒤로가기는 진행 중에 같은 확인 창을 띄웁니다.
- 앱을 내리거나 전화가 오면 소리가 끊기고 진행이 멈춥니다.

## 5. 결과 화면

```
┌───────────────────────────────┐
│ 두 글자                 🎧  📊  │
│   ✓ 연습이 끝났어요              │
│ ┌───────────────────────────┐ │
│ │ 12개 중 10개를 맞혔어요      │ │
│ │ 맞힌 비율 약 83%            │ │
│ │ 연습 기록이에요. 청력 검사·   │ │
│ │ 진단 결과가 아니에요.         │ │
│ └───────────────────────────┘ │
│     [ ✓ 기기에 기록했어요 ]      │
│     [ 다시 연습 ]  [ 뒤로 가기 ] │
└───────────────────────────────┘
```

| 저장 문구 | 뜻 |
|---|---|
| **기기에 기록했어요** | 12문항을 끝까지 풀어 기록했습니다. 다음 판은 다음 장 |
| **12개를 다 고르지 않아 기록에는 안 남겼어요** | 중간에 끝냈습니다. 다음 판도 같은 장 |
| 기록에 남기지 못했어요 | 저장 중 문제가 생겼습니다 |

- **다시 연습**을 누르면 바로 새 판을 시작합니다. 방금 기록했다면 **다음 장**으로 시작합니다.

## 6. 내 동작이 기록에 어떻게 남나요?

| 내가 한 일 | 기록에 남는 것 |
|---|---|
| 12문항을 끝까지 풀었다 | 한 판 기록 1개: 날짜·시각, 맞힌 수/12, 맞힌 비율, (안 보이는) 장 번호 |
| 중간에 끝냈다 | **남지 않음**. 다음에 같은 장이 나옵니다 |
| 문항 하나를 맞혔다 / 틀렸다 | 그 판의 맞힌 수에만 더해집니다. 어떤 단어를 틀렸는지는 남지 않습니다 |

- 맞힌 비율은 반올림한 정수입니다. 한 문항이 약 8%입니다. (예: 10/12 = 83%, 9/12 = 75%)
- 기록은 **최근 50판**까지 보관됩니다.

## 7. 통계 「두 글자」 읽기

📊 연습 기록의 **두 글자** 칸은 [한 글자](한%20글자%20가이드.md)와 같은 모양입니다.

| 카드 | 읽는 법 |
|---|---|
| **맞힌 비율 변화** | 기록 2회부터. 판마다 맞힌 비율을 날짜 순서로 잇는 그래프. 위가 많이 맞힘 |
| **최근 연습** | 최근 8판. `10/20 14:05   10/12 · 약 83%` = 그 날짜·시각에 12문항 중 10개 맞힘 |

- 장마다 단어가 달라 **장에 따라 쉬움·어려움이 조금 다를 수** 있습니다. 세 판(세 장)을 한 묶음으로 보면 흐름을 읽기 쉽습니다.
- 그래프는 보관된 판(최대 50판)을 **모두** 그립니다. 최근 연습처럼 8판으로 자르지 않습니다.
- 가로축은 판 번호가 아니라 **연습한 시각**입니다. 같은 날 여러 판을 하면 점이 붙고, 며칠 쉬면 간격이 벌어집니다.
- 12판까지는 판마다 점이 찍힙니다. 그보다 많으면 첫 판과 최근 판에만 점이 찍히고 나머지는 선으로만 이어집니다.
- 50판을 넘으면 가장 오래된 판부터 지워지므로 그래프 왼쪽 끝이 앞으로 밀려납니다.

---

## 8. 잘 하는 요령

- 보기를 먼저 훑어 **소리가 비슷한 두 단어**를 찾으세요. 정답은 대부분 그 둘 중 하나입니다.
- 비슷한 짝은 **한 글자의 첫소리나 받침**이 다릅니다. (편지 ↔ 먼지: 첫소리, 바다 ↔ 바닥: 받침) 그 부분에 귀를 모으세요.
- 세 장을 한 바퀴 돌 때마다 같은 단어가 다시 나옵니다. 단어를 외워서 맞히기보다 **소리 차이를 듣는 데** 집중하세요.
- 같은 기기, 같은 이어폰으로 하면 기록을 비교하기 쉽습니다.

## 9. 자주 묻는 질문

**Q. 같은 단어가 또 나와요.**
단어 목록이 세 장이라 세 판마다 같은 장이 돌아옵니다. 중간에 끝내면 같은 장이 바로 다시 나옵니다.

**Q. 문항 수를 바꿀 수 있나요?**
아니요. 두 글자는 12문항 고정입니다. 25문항까지 하고 싶다면 [한 글자](한%20글자%20가이드.md)를 이용하세요.

**Q. 지금 몇 장인지 알 수 있나요?**
화면에는 나오지 않습니다. 앱이 마지막으로 마친 장 다음 장을 알아서 냅니다.

**Q. 「한국어 음성이 없어요」가 떠요.**
[한국어 음성 안내](../0_공통/한국어%20음성%20안내%20가이드.md)를 따라 받은 뒤 **다시 확인**을 누르세요.

**Q. 이 결과가 어음 검사인가요?**
아니요. 연습 기록입니다. 단어 목록도 병원 검사용 표준 목록과 같지 않습니다.
