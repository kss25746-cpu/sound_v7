# 설정 가이드

하단 네 번째 탭 **설정**(⚙ 톱니 아이콘)을 안내합니다.
내 계정을 확인하고 **로그아웃**하거나 **회원탈퇴**하는 화면입니다. 앱을 처음 켤 때 나오는 **로그인 화면**도 함께 설명합니다.

> 들어가는 곳: 하단 탭 **설정**
> 나가는 곳: 다른 하단 탭을 누르면 됩니다

```
   앱 켜기
     │  로그인 기록이 없으면
     ▼
   로그인 화면 ── Google / 카카오로 계속하기
     │  로그인되면 (다음부터는 바로 앱이 열림)
     ▼
   하단 탭 4개 ── … ── [설정]
                          ├── 로그아웃 → 로그인 화면으로
                          └── 회원탈퇴 → 로그인 화면으로
```

---

## 1. 로그인 화면

```
┌───────────────────────────────┐
│                               │
│          사운드퀘스트            │
│  게임처럼 즐겁게 시작하는 청능 훈련 │
│                               │
│ ┌───────────────────────────┐ │
│ │ G  Google 계정으로 계속하기  │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 💬 카카오 계정으로 계속하기  │ │
│ └───────────────────────────┘ │
└───────────────────────────────┘
```

- **Google** 또는 **카카오** 계정 중 하나로 로그인합니다. 버튼을 누르면 그 서비스의 로그인 창이 열립니다.
- 로그인에 성공하면 하단 탭 4개가 있는 앱 화면이 열립니다. 처음 보이는 탭은 **다른 소리**입니다.
- 한 번 로그인하면 기기에 기억되어, **다음에 앱을 켤 때는 로그인 화면 없이** 바로 열립니다.
- 로그인 창에서 취소하면 로그인 화면에 그대로 남습니다.

## 2. 설정 화면

```
┌───────────────────────────────┐
│ 설정                            │
│ ┌───────────────────────────┐ │
│ │ (👤)  사용자 님              │ │  ← ① 내 프로필
│ │       [ 카카오 로그인 ]       │ │     (어느 계정으로 로그인했는지)
│ └───────────────────────────┘ │
│ 계정 설정                        │
│ ┌───────────────────────────┐ │
│ │ 로그아웃                  › │ │  ← ② 로그아웃
│ │───────────────────────────│ │
│ │ 회원탈퇴                  › │ │  ← ③ 회원탈퇴 (빨간 글자)
│ └───────────────────────────┘ │
│                               │
│        사운드퀘스트 v1.0.0       │  ← 앱 버전
└───────────────────────────────┘
│  다른 소리 │ 말소리 │ 악기 소리 │ 설정 │
```

### ① 내 프로필

| 표시 | 뜻 |
|---|---|
| **사용자 님** | 이름 자리. 지금은 누구나 「사용자 님」으로 보입니다 |
| **Google 로그인** / **카카오 로그인** | 어느 계정으로 로그인했는지 |
| 소셜 로그인 | 로그인 종류를 알 수 없을 때 |

### ② 로그아웃

1. **로그아웃**을 누르면 「**로그아웃** — 정말 로그아웃 하시겠습니까?」가 뜹니다.
2. **로그아웃**을 누르면 계정 연결을 끊고 **로그인 화면**으로 돌아갑니다. **취소**하면 그대로 남습니다.

- 로그아웃해도 **이 기기에 저장된 연습 기록은 그대로** 남습니다. 다시 로그인하면 이어서 볼 수 있습니다.

### ③ 회원탈퇴

1. **회원탈퇴**를 누르면 「**회원 탈퇴** — 탈퇴 시 모든 학습 및 훈련 기록이 영구히 삭제됩니다. 정말 탈퇴하시겠습니까?」가 뜹니다.
2. **탈퇴하기**를 누르면 서버에 탈퇴를 요청합니다.

| 결과 | 보이는 것 |
|---|---|
| 성공 | 「**알림** — 회원탈퇴가 완료되었습니다.」 → 로그인 화면으로. Google · 카카오 계정과 앱의 연결도 끊깁니다 |
| 실패 | 「**오류** — 탈퇴 처리에 실패했습니다. 다시 시도해 주세요.」 → 설정 화면에 그대로. 인터넷 연결을 확인하고 다시 시도하세요 |

> **주의:** 회원탈퇴는 되돌릴 수 없습니다.
> 지금 앱에서는 회원탈퇴가 **서버의 계정 정보**를 지우고 로그인을 끊습니다. **이 기기에 저장된 연습 기록**(📊 연습 기록, 별 · 클리어 등)은 이 동작으로 지워지지 않습니다. 기기의 기록을 지우려면 📊 연습 기록 화면의 「○○ 기록 지우기」나 동물 소리 게임의 「전체 초기화」를 쓰세요.

## 3. 기록은 어디에 저장되나요?

| 기록 | 저장 위치 | 지우는 방법 |
|---|---|---|
| 📊 연습 기록 (높낮이 · 소리 찾기 · 소리 구분 · 한 글자 · 두 글자 · 문장 · 듣고 고르기) | 이 기기 | [연습 기록](../0_공통/연습%20기록%20가이드.md) 화면에서 종목별 「기록 지우기」 |
| 동물 소리 게임 별 · 클리어, 강화학습 내 통계 | 이 기기 | 동물 소리 게임 목록의 「전체 초기화」 (피아노 · 기타 별 · 클리어도 함께 지워짐) |
| 피아노 레벨별 기록 · 별 · 클리어 | 이 기기 | 피아노 미션 창의 「초기화」 |
| 기타 레벨별 기록 · 별 · 클리어 | 이 기기 | 기타 미션 창의 「초기화」 |
| 단어 카드 익힘 | 이 기기 | 단어 카드 익힘 목록의 「전체 다시 하기」 |
| 로그인 정보 | 이 기기 + 서버 | 로그아웃 · 회원탈퇴 |

- 연습 기록은 **이 기기에만** 저장됩니다. 다른 휴대폰에서 같은 계정으로 로그인해도 기록이 따라가지 않습니다.
- 앱을 지우면 기기에 저장된 기록도 함께 사라집니다.

---

## 4. 자주 묻는 질문

**Q. 이름이 「사용자 님」으로만 나와요.**
지금 앱은 이름 자리에 누구나 「사용자 님」을 보여 줍니다.

**Q. 다른 계정으로 바꾸고 싶어요.**
**로그아웃** 후 로그인 화면에서 다른 계정을 고르세요.

**Q. 로그아웃하면 연습 기록이 사라지나요?**
아니요. 기록은 기기에 남아 있습니다.

**Q. 탈퇴가 계속 실패해요.**
탈퇴는 인터넷으로 서버에 요청합니다. 인터넷 연결을 확인하고 잠시 뒤 다시 시도하세요.
